## UC-1 盘后反思 `serves: FR-1`

- **用例角色**：投资脑（agent-dh）、调度框架。
- **前置条件**：有到期计划；agent-dh 在线。
- **交互流程**：1) 15:35 调度触发；2) 组四输入包；3) /wake（event=plan_reflection）；4) agent 五问作答写回；5) overdue 归零。
- **异常流**：agent 离线 → overdue+1，下周期重试；包缺段 → 标 missing。
- **后置条件**：plan_reflections 一行 + last_reflected_at 更新。
- **完成标志**：日志 woken≥1，报告落库。

## UC-2 减仓批次 `serves: FR-2`

- **用例角色**：用户、系统。
- **前置条件**：计划含两批 reduce，持仓存在。
- **交互流程**：1) 第一批触发；2) agent 卖 1/3；3) 回执带 plan_id；4) 批次 0 退役 + 事件；5) 计划仍 holding；6) 第二批触发卖完 → 全批退役 → closed。
- **异常流**：卖 80% 跨两批 → 顺序退役两批；找不到批次 → degraded 事件；回执重放 → 幂等。
- **后置条件**：events 有两条 fill（batch 0/1）。
- **完成标志**：查询能看到两批进度且规则全部退役。

## UC-3 消息离场 `serves: FR-3`

- **用例角色**：投资脑、用户。
- **前置条件**：持仓标的；消息扫描在跑。
- **交互流程**：1) critical 命中；2) 建 P1 待办（evidence.source=news）；3) /wake；4) agent 判断：破坏→patch/close 离场；不破坏→close(ignored)+next_condition。
- **异常流**：24h 重复 → 不建单；非持仓 → 只通知；源不可用 → 不建单。
- **后置条件**：watch_todos 一行有终态。
- **完成标志**：待办可查且终态非空。
