## 🔍 问题分析

### 为什么交叉验证优秀但测试集差？

#### 1. **数据泄露** ⚠️⚠️⚠️

```python
# 当前的交叉验证
tscv = TimeSeriesSplit(n_splits=3)

# 问题：可能在特征预处理时用了全量数据
scaler.fit_transform(df[feature_cols])  # ❌ 用了测试集数据
```

**应该**:
```python
# 正确做法：在每个fold内独立处理
for train_idx, val_idx in tscv.split(X):
    scaler = StandardScaler()
    X_train_scaled = scaler.fit_transform(X[train_idx])
    X_val_scaled = scaler.transform(X[val_idx])  # 只用训练集的参数
```

#### 2. **时间窗口不匹配** ⚠️

- 交叉验证：3折，每折约43,000样本
- 最终测试：25,903样本（20%）

测试集可能恰好在一个特殊的市场环境（如单边下跌），导致所有策略失效。

#### 3. **标签问题** ⚠️

```
标签统计: mean=0.004741
```

标签均值为正（0.47%），说明市场整体上涨。模型可能学到了"做多偏向"，但测试集市场环境不同。
