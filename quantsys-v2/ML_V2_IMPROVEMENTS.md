## 🔬 改进的科学依据

### 1. 样本量与IC稳定性

根据统计学原理：
```
IC标准差 ∝ 1/√n
```

样本量增加4倍（50→200），IC标准差理论上降低50%：
```
0.19 × 0.5 = 0.095
```

### 2. 超额收益与Alpha

```
总收益 = Alpha + Beta × 市场收益
超额收益 = Alpha（剥离Beta）
```

使用超额收益可以：
- 降低市场噪声
- 提升IC的信噪比
- 更准确地衡量选股能力

### 3. 特征丰富度与预测能力

根据机器学习理论：
```
模型容量 ∝ 特征数量
过拟合风险 ∝ 特征数量 / 样本量
```

V2中：
- 特征增加：14 → 30 (2.1倍)
- 样本增加：16,500 → 预计60,000+ (3.6倍)
- 特征/样本比: 降低，降低过拟合风险
