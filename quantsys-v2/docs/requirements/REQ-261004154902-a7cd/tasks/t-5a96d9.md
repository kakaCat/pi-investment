研发子卡：调度失败从「只告诉一个不在线的服务」变成「有人会被通知」，且不再用刷屏的方式通知。

### 完成项

- 调度任务失败第一次有了通向人的线：两条失败分支都经统一出口外发（此前只上报给已下线的 Agent OS）
- Agent OS 不可达不再制造假警报：按开关分流——既定关闭状态下只留痕并计数，真开着却连不上才告警；日志按事件与任务限频，堵掉刷屏源头
- 告警覆盖面补齐：失败巡检的扫描集合从 9 个固定任务扩到含库表里 11 张启用任务，并合并近三天失败记录与告警投递失败
- 告警内容补字段：规则被停用、被跳过、数据未覆盖、投递失败这些「没做成的动作」现在会进消息正文
- 空转不再算成功：计数全为 0 且仍有缺口（如「成功 0 只、未覆盖 5271 只」）判为失败
- 发信失败不再静默：发信返回值被消费，失败记账并带回巡检
