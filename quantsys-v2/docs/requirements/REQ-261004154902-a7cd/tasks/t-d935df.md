### 完成项

- 新增只读盘点器：按当前 cron 语义（标准 cron + 本地时区，复用既有翻译函数）推算每个启用任务的最近应跑时刻，与运行记录比对，输出 ok / missed / unknown 三态，判不出来一律 unknown

- 探活新增两条判据：调度开关检查与关键任务心跳；并把结论写进探针 JSON
- 新判据默认处于观察模式（只记账与留痕、不外发），开关与理由写进代码注释
- 自带跨进程节流：同一漏跑只提醒一次，避免重演历史上 504 条误报的告警疲劳
- 配置改动护栏：应跑时刻早于该任务最近一次变更的不计为漏跑，避免把停机/改配置期间的旧坑算到账号上
