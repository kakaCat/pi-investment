# 用例设计（REQ-261005210015-1603）

判定一律以**渲染后的文本**为准（`_summarize_result(result)` + 标题前缀），不依赖实现细节。
下面 UC-1 的数字取生产真实形态（E5/E6），UC-2/3 另设构造数据。

## UC-1 有产出（对照场景，防止"修完就只会报警"）（serves: FR-2, FR-3）

**触发**：`computed_ok > 0`，`idle_streak == 0`。

```
✅ 每日任务完成：evolution_fitness
B链账户行为双侧捕获 fitness 续采（RFC 012 P3，8/14 断点恢复；账户行为域，非策略参数进化）
耗时: 1.4 秒
有效 3（样本不足 1 / 无成交 1 / 数据缺口 0）
```

**判定**：标题为 `✅`、**不含**"无有效产出"字样、**不含**"连续 … 次无有效产出"。
理由（R1/R3）：任务本来就有正常的日子，改造不得把它变成恒报警——"如实"是双向的。

## UC-2 首次零产出（serves: FR-3, FR-5）

**触发**：`computed_ok == 0`，`idle_streak == 1`，`last_ok_window_end = 2026-09-12`。

```
⚠️ 每日任务完成（无有效产出）：evolution_fitness
B链账户行为双侧捕获 fitness 续采（RFC 012 P3，8/14 断点恢复；账户行为域，非策略参数进化）
耗时: 1.2 秒
有效 0（样本不足 1 / 无成交 4 / 数据缺口 0）｜本次无有效产出（最近有效：2026-09-12）
```

**判定**：⚠️ 前缀 + `本次无有效产出`（不写"连续"）；台账仍 `success`。

## UC-3 连续空转（2026-10-05 的真实场景）（serves: FR-1, FR-2, FR-3, FR-5）

**触发**：`computed_ok == 0`，`idle_streak == 2`（10-05 与 10-02 的 ok 数都是 0，E6）。

```
⚠️ 每日任务完成（无有效产出）：evolution_fitness
B链账户行为双侧捕获 fitness 续采（RFC 012 P3，8/14 断点恢复；账户行为域，非策略参数进化）
耗时: 1.2 秒
有效 0（样本不足 2 / 无成交 3 / 数据缺口 0）｜已连续 2 次无有效产出（最近有效：2026-09-12）
```

**对照现状**（同一批数据的今天）：

```
✅ 每日任务完成：evolution_fitness
…
耗时: 0.0 分钟
detail[computed=5]        ← 读者得不到"0 条有效"这个事实
```

**判定**：`⚠️` + `已连续 2 次无有效产出（最近有效：2026-09-12）` + `耗时: 1.2 秒`；
且文本**不含** `detail[computed=`（不再出现内部字段 dump）。

**为什么这条最重要**：它就是用户 20:35 收到的那张卡片的"真话版"；20+ 天的空转正是靠这条被看见的。

## UC-4 空转统计不可用（降级路径）（serves: FR-5, FR-6）

**触发**：`list_recent_window_ok_counts` 或 `get_last_ok_window_end` 抛错（DB 抖动 / 连接问题）。

```
⚠️ 每日任务完成（无有效产出）：evolution_fitness
…
耗时: 1.2 秒
有效 0（样本不足 2 / 无成交 3 / 数据缺口 0）｜空转统计不可用
```

**判定**：① 文案含 `空转统计不可用`；② `logger.error` 有一条（响亮）；③ **任务仍记 success**
（因为 handler 未抛异常）——报告写不出来不允许把采集判死。

## UC-5 其他任务不受影响（回归场景）（serves: FR-2）

**触发**：`evening_pipeline` 的既有返回形态（顶层 `kline_sync` / `factor_compute` 子字典，无 `summary`）。

**判定**：渲染文本与改造前**逐字一致**（仍是 `kline_sync[...]` 形态的子字典段）。
理由：FR-2 只允许 fitness 摘要变人话；其余任务换个格式收益为零、回归面却很大。

## 场景-条款映射（serves: FR-1, FR-2, FR-3, FR-5）

| 场景 | FR | 判定锚点 |
|---|---|---|
| UC-1 | FR-1、FR-2、FR-3 | `✅`；`有效 3（…）`；`耗时: 1.4 秒` |
| UC-2 | FR-3、FR-5 | `⚠️`；`本次无有效产出` |
| UC-3 | FR-1、FR-2、FR-3、FR-5 | `⚠️`；`已连续 2 次…（最近有效：2026-09-12）`；`1.2 秒`；无 `detail[computed=` |
| UC-4 | FR-5 | `空转统计不可用` + error 日志 + 仍 success |
| UC-5 | FR-2 | 既有文本逐字不变 |
