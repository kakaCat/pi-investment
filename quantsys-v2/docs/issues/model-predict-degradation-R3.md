# R3: model_predict 恒等输出问题诊断报告

## 现象
所有股票 model_predict 返回完全相同的预测：probability=0.4659, predicted_class=0, confidence=low

## 根因分析
1. **模型训练时间**：最新xgboost模型训练于 2026-06-03（2.5个月前）
2. **特征污染**：训练期间老管线因子（大写）已停滞（5/20），模型可能学习了失效特征
3. **Regime变化**：市场结构2.5个月内可能漂移，模型未更新
4. **症状**：典型的模型退化——学会"无论输入什么都返回均值"（0.4659≈50%）

## 测试证据
```bash
# 600519, 000001, 600737 三只股票返回完全相同预测
curl -X POST http://localhost:5001/api/ml/predict \
  -d '{"symbols":["600519","000001","600737"], "model_type":"xgboost"}'
# → 所有 probability: 0.4659, class: 0
```

## 修复方案
**需要重新训练模型**（非trivial修复）：
1. 等待 R2（历史回填）完成，提供充足训练数据
2. 使用R0+R1修复后的新鲜因子（含资金流）训练
3. model_train 指定新特征集（避免依赖已删除的大写因子）
4. model_evaluate 验证新模型消除了退化

## 临时缓解
- model_predict 工具描述已明确"置信度低时不宜作为重仓依据"
- 用户可通过 confidence=low 识别无效预测
