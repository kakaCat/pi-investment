## 📖 快速开始

### 使用示例

```python
# 导入因子计算器
from quantlib.factors.momentum import MomentumFactors
from quantlib.factors.pattern_recognition import PatternRecognitionFactors
from quantlib.factors.cycle import CycleFactors

# 准备 K 线数据
klines = [
    {'open': 100, 'high': 105, 'low': 95, 'close': 102, 'volume': 1000000},
    # ... 更多数据
]

# 计算动量因子
momentum = MomentumFactors()
rsi = momentum.rsi14(klines)
print(f"RSI14: {rsi['value']}")  # RSI14: 65.23

# 识别 K 线形态
pattern = PatternRecognitionFactors()
hammer = pattern.cdl_hammer(klines)
print(f"Hammer: {hammer['metadata']['signal']}")  # Hammer: bullish

# 分析市场周期
cycle = CycleFactors()
trend_mode = cycle.ht_trendmode(klines)
print(f"Mode: {trend_mode['metadata']['mode']}")  # Mode: trend
```

### 策略集成

```python
# 策略代码中直接使用因子
# 所有 103 个因子在策略执行时自动注入到 DataFrame

# 多因子组合策略
df['momentum_signal'] = (df['rsi14'] < 30) & (df['macd'] > 0)
df['trend_signal'] = (df['adx'] > 25) & (df['di_plus'] > df['di_minus'])
df['pattern_signal'] = df['cdl_hammer'] > 0
df['cycle_signal'] = df['ht_trendmode'] == 1

df['buy'] = df['momentum_signal'] & df['trend_signal'] & df['pattern_signal'] & df['cycle_signal']
df['sell'] = df['rsi14'] > 70
```
