## 技术债务分析

### 根本原因

1. **历史遗留代码**: Flask→FastAPI 迁移过程中，许多路由函数直接搬运未重构
2. **快速迭代**: 功能优先，代码质量欠账
3. **缺少 Code Review**: 复杂度和长度没有门禁控制
4. **动态策略系统**: 需要 exec() 支持用户自定义策略代码

### 系统性改进建议

1. **CI 门禁**
   - 复杂度检查: >15 自动失败
   - 函数长度: >80 行警告
   - 类大小: >15 方法警告

2. **重构模式库**
   - 建立标准重构模式文档
   - 新代码强制使用模式

3. **策略沙箱**
   - 实现安全的策略执行环境
   - 替代 exec() 的声明式 DSL

4. **配置中心化**
   - 提取所有魔法数字到配置
   - 统一管理阈值和参数
