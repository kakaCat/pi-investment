### 已实现的功能

#### 1. Micro-compaction ✅
**功能**: 每轮清空旧的工具调用结果，只保留最近 N 个
```typescript

  messages: AgentMessage[],
  options: CompactionOptions = {}
): void
```
- 保留最近 `keepRecentToolResults` 个工具结果
- 超过 `minLengthToCompact` 才压缩
- 清空旧结果为 `[Compacted: toolName result (N chars)]`

#### 2. Safe Split Point ✅
**功能**: 查找安全的分割点，避免在 assistant(tool_calls) 与 toolResult 之间分割
```typescript
export function findSafeSplitPoint(
  messages: AgentMessage[],
  proposedSplitIndex: number
): number
```

#### 3. Tool Result TTL ✅
**功能**: 工具结果按 TTL 分级，不同工具保留时长不同
