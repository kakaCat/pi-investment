--------------------------------------------

   - 位置: quant/engine/risk_rules.py:323

   - 功能: Beta暴露检查

   - 位置: quant/engine/risk_rules.py:387

   - 功能: 组合波动率检查
   - 阈值: 年化波动率 ≤ 30% (可配置)
   - 严重级别: warning
   - 位置: quant/engine/risk_rules.py:425

【市场风险规则 - 3个】

   - 位置: quant/engine/risk_rules.py:476

6. check_vix_level
   - 功能: 波动率指数检查
   - 阈值: VIX代理值 ≤ 30 (可配置)
   - 严重级别: warning
   - 位置: quant/engine/risk_rules.py:527

7. check_market_breadth
   - 功能: 市场广度检查 (涨跌家数比)
   - 阈值: 上涨比例 ≥ 30% (可配置)

三、压力测试框架
=============================================================================

【核心文件】
- quant/engine/stress_test.py (新建, 400+ 行)

【预定义压力测试场景 - 6个】
--------------------------------------------
1. SCENARIO_MARKET_DROP_10
   - 市场下跌10% (温和调整)

2. SCENARIO_MARKET_DROP_20
   - 市场下跌20% (严重调整)

3. SCENARIO_MARKET_DROP_30
   - 市场下跌30% (极端熊市)

4. SCENARIO_2015_CRASH
   - 2015股灾回放
   - 市场: -40%, 科技: -50%, 券商: -45%

5. SCENARIO_2020_COVID
   - 2020疫情冲击
   - 市场: -15%, 消费: -25%, 医药: +10%

6. SCENARIO_SECTOR_ROTATION
   - 行业轮动
   - 周期: +20%, 成长: -15%

【压力测试引擎功能】
--------------------------------------------
1. run_scenario(scenario)
   - 运行单个压力测试场景
   - 返回: 当前组合价值、压力后价值、损失金额、损失比例、持仓影响明细

2. run_all_scenarios()
   - 运行所有预定义场景
   - 返回: 所有场景结果 + 汇总统计 (最差/最佳场景、平均损失)

3. run_historical_replay(start_date, end_date)
   - 历史情景回放
   - 返回: 组合收益率、指数收益率、最大回撤、波动率、夏普比率

八、使用示例
=============================================================================

【基础风控检查】
--------------------------------------------
from services.risk_service import RiskService

svc = RiskService()

# 使用扩展风控 (默认)
result = svc.pre_trade_check("000001.SZ", "buy", 1000)

# 仅使用核心风控
result = svc.pre_trade_check("000001.SZ", "buy", 1000, enable_extended_checks=False)

print(f"风控通过: {result['passed']}")
print(f"检查项数: {len(result['checks'])}")
print(f"失败项数: {len(result['failures'])}")

【压力测试】
--------------------------------------------
from quant.engine.stress_test import StressTestEngine, SCENARIO_MARKET_DROP_20

engine = StressTestEngine(ds)

# 运行单个场景
result = engine.run_scenario(SCENARIO_MARKET_DROP_20)
print(f"当前组合价值: {result['current_portfolio_value']}")
print(f"压力后价值: {result['stressed_portfolio_value']}")
print(f"预估损失: {result['total_loss']} ({result['loss_percentage']:.1%})")

# 运行所有场景
all_results = engine.run_all_scenarios()
print(f"最差场景: {all_results['summary']['worst_scenario']}")
print(f"最大损失: {all_results['summary']['worst_loss']:.1%}")

# 历史回放
replay = engine.run_historical_replay("2025-01-01", "2025-03-31")
print(f"组合收益: {replay['portfolio_return']:.2%}")
print(f"最大回撤: {replay['max_drawdown']:.2%}")
print(f"夏普比率: {replay['sharpe_ratio']:.2f}")
