## ⚠️ 已知问题

### 高优先级问题

#### 1. 期权策略API不一致 (21个测试失败)
**问题**: Greeks计算器方法名不匹配
- 代码调用: `calculate_all_greeks()`
- 实际方法: `calculate_greeks()`

**影响**: 波动率套利策略所有测试失败

**解决方案**: 
```python
# 已修复：统一使用 calculate_greeks()
greeks = self.greeks_calculator.calculate_greeks(S, K, T, r, sigma, option_type)
```

#### 2. 对称正交化维度问题 (4个测试失败)
**问题**: QR分解返回的DataFrame维度不匹配
- 期望: (200, 8)
- 实际: (200, 200)

**影响**: 对称正交化相关测试失败

**解决方案**: 修复DataFrame构造逻辑，保持列数与输入一致

### 中优先级问题

#### 3. 边界条件处理不一致
**问题**: 空数据、零窗口等边界条件处理不统一

**影响**: 2个GPU测试失败

**建议**: 统一边界条件处理策略

#### 4. GPU测试环境
**问题**: GPU不可用导致3个测试跳过

**影响**: 无法验证GPU/CPU计算一致性

**建议**: 在CI/CD中配置GPU环境
