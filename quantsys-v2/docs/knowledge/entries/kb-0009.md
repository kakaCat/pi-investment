## 结论
每日任务通知改为「有事才说」：无事（no_output is True 或 status∈{no_event,no_op}）时开始与完成两条飞书都不发（台账仍 success），开始消息改为超阈值「⏳ 仍在运行」提示，失败与人工触发不受影响，两个 env 可一键回滚。
