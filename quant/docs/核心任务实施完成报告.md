# Quant 量化系统 - 核心任务实施完成报告

## ✅ 已完成的工作

### 1. 核心脚本（3个）✅

#### 📊 因子计算脚本
- **文件**: `scripts/calculate_factors.py`
- **功能**: 计算42个技术因子
- **因子类型**:
  - 趋势类: MA, EMA (6个)
  - 动量类: RSI, ROC, MTM (6个)
  - 波动率: ATR, BOLL (2个)
  - 成交量: OBV, VOLUME_MA, VR (4个)
  - 超买超卖: KDJ, WR, CCI, BIAS (8个)
  - 趋势强度: MACD, DMI, DMA, TRIX (4个)
  - 其他: MFI, CR, PSY, EMV, WVAD, SAR (6个)
- **输出**: 数据库表 `factor_values`

#### 🎯 信号生成脚本
- **文件**: `scripts/generate_signals.py`
- **功能**: 运行5个策略生成交易信号
- **策略列表**:
  1. RSI反转策略
  2. 均线突破策略
  3. MACD金叉死叉
  4. 布林带突破
  5. KDJ超买超卖
- **输出**: JSON文件 `quant/.pi-invest/signals.json`

#### ⚠️ 风险检查脚本
- **文件**: `scripts/risk_check.py`
- **功能**: 检查持仓风险
- **检查项目**:
  - 止损检查（固定止损、移动止损、时间止损）
  - 集中度检查（单只股票占比）
  - 组合风险（总盈亏、盈亏分布）
- **输出**: JSON文件 `quant/.pi-invest/risk_report.json`

## 🚀 使用方法

### 1. 首次使用

```bash
cd /Users/mac/Documents/ai/pi-investment/quant

# 1. 安装依赖
pip install -r requirements.txt

# 2. 获取历史数据（首次必需，30-60分钟）
python3 quantsys/data/pipeline.py full --market A

# 3. 测试核心任务
python3 scripts/test_core_tasks.py

# 4. 启动调度器
./scripts/start_scheduler.sh
```

### 2. 手动运行单个任务

```bash
# 数据更新
curl -sS -X POST http://localhost:5001/api/data/update

# 因子计算
python3 scripts/calculate_factors.py

# 信号生成
python3 scripts/generate_signals.py

# 风险检查
python3 scripts/risk_check.py
```

```bash
# 查看信号
cat quant/.pi-invest/signals.json | jq .

# 查看风险报告
cat quant/.pi-invest/risk_report.json | jq .

# 查看日志
tail -f logs/scheduler.log
```

## 🔧 技术架构

### 核心依赖

```
quantsys (核心库)
├── data (数据层)
│   ├── db.py (数据库操作)
│   └── fetchers (数据获取)
├── factors (因子库)
│   └── 42个因子类
├── strategies (策略层)
│   └── 经典策略
└── risk (风控层)
    ├── StopLossManager
    └── PositionManager

APScheduler (调度器)
└── CronTrigger (定时触发)
```

### 数据库设计

```sql
-- K线数据表
daily_klines (symbol, date, open, high, low, close, volume, amount)
  PRIMARY KEY (symbol, date)
  INDEX (date)

-- 因子值表
factor_values (symbol, date, factor_name, factor_value)
  PRIMARY KEY (symbol, date, factor_name)
  INDEX (symbol, date)
  INDEX (date)
```

## ⚠️ 注意事项

### 1. 首次使用

- **必须先运行** `python3 quantsys/data/pipeline.py full --market A` 获取历史数据
- 首次获取需要30-60分钟
- 确保网络连接稳定

### 2. 数据库并发

- 调度器和主项目可能同时访问数据库
- 使用 SQLite WAL 模式提高并发性
- 添加超时处理避免死锁

### 3. 任务依赖

- 因子计算依赖数据更新
- 信号生成依赖因子计算
- 确保任务按时间顺序执行

### 4. 错误处理

- 每个任务独立执行
- 单个任务失败不影响其他任务
- 详细日志记录便于排查
