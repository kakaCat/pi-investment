**核心功能:**
```python
class BacktestEngine:
    def run(self, strategy, start_date, end_date, initial_capital):
        """
        事件驱动回测:
        1. 逐日遍历数据
        2. 处理涨跌停/停牌
        3. 计算滑点/佣金
        4. 更新持仓和权益
        5. 生成权益曲线
        """
        for date in date_range(start_date, end_date):
            # 更新持仓市值
            self._update_positions(date)
            
            # 处理挂单
            self._process_orders(date)
            
            # 策略计算信号
            signals = strategy.on_bar(date)
            
            # 风控检查
            if self._risk_check(signals):
                orders = self._generate_orders(signals)
                self.pending_orders.extend(orders)
            
            # 记录权益
            self._record_equity(date)
```

- [ ] 停牌处理 (跳过停牌日)
