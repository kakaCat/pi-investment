## 📝 注意事项

### 1. 数据库并发
- 调度器和主项目可能同时访问数据库
- 使用 SQLite 的 WAL 模式提高并发性
- 添加数据库锁超时处理

### 2. 任务依赖
- 确保任务按时间顺序执行
- 数据更新 → 因子计算 → 信号生成
- 如果前置任务失败，后续任务应跳过

### 3. 错误处理
- 每个任务独立执行
- 一个任务失败不影响其他任务
- 记录详细错误日志

### 4. 性能优化
- 因子计算可能耗时较长（300只股票 × 42个因子）
- 考虑并行计算（multiprocessing）
- 缓存中间结果
