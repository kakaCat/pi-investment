# Quant 量化系统 - 完整使用指南

## 📦 系统概述

Quant 量化系统是一个完整的量化交易工作流，包含：
- **数据层**: 自动更新沪深300成分股数据
- **因子层**: 计算42个技术因子
- **策略层**: 5个经典交易策略
- **风控层**: 持仓风险检查和止损管理
- **调度层**: Python定时任务自动化

## 📋 核心任务详解

### 1️⃣ 数据更新 (`/api/data/update` 或 `quantsys/data/pipeline.py update-klines`)

**时间**: 每天 16:00（收盘后）  
**功能**: 更新沪深300成分股的最新K线数据  
**耗时**: 5-10分钟

**手动运行**:
```bash
# 方式1: 通过 API 触发（需先启动 API 服务）
curl -sS -X POST http://localhost:5001/api/data/update

# 方式2: 直接运行数据管道
python3 quantsys/data/pipeline.py update-klines
```

**输出**:
- 数据库: `quantsys/data/stocks.db` (daily_klines表)
- 日志: 显示更新的股票数量和最新日期

---

### 2️⃣ 因子计算 (calculate_factors.py)

**时间**: 每天 16:30（数据更新后）  
**功能**: 计算所有股票的42个技术因子  
**耗时**: 10-20分钟（300只股票）

**手动运行**:
```bash
python3 scripts/calculate_factors.py
```

**计算的因子**:
- **趋势类**: MA5, MA10, MA20, MA60, EMA12, EMA26
- **动量类**: RSI6, RSI12, RSI24, ROC12, MTM6, MTM12
- **波动率**: ATR14, BOLL(上轨/中轨/下轨)
- **成交量**: OBV, VOLUME_MA5, VOLUME_MA10, VR26
- **超买超卖**: KDJ(K/D/J), WR10, WR6, CCI14, BIAS
- **趋势强度**: MACD(DIF/DEA/MACD), DMI, DMA, TRIX
- **其他**: MFI14, CR26, PSY12, EMV14, WVAD, SAR

**输出**:
- 数据库: `quantsys/data/stocks.db` (factor_values表)
- 日志: 显示计算成功/失败的股票数量

---

### 3️⃣ 信号生成 (generate_signals.py)

**时间**: 每天 17:00（因子计算后）  
**功能**: 基于因子运行策略，生成交易信号  
**耗时**: 5-10分钟

**手动运行**:
```bash
python3 scripts/generate_signals.py
```

**策略列表**:
1. **RSI反转策略**: RSI < 30 买入，RSI > 70 卖出
2. **均线突破策略**: MA5 上穿 MA20 买入，下穿卖出
3. **MACD策略**: MACD金叉买入，死叉卖出
4. **布林带策略**: 价格触及下轨买入，上轨卖出
5. **KDJ策略**: KDJ超卖买入，超买卖出

**输出**:
- 文件: `quant/.pi-invest/signals.json`
- 格式:
```json
{
  "generated_at": "2026-05-18T17:00:00",
  "date": "2026-05-18",
  "summary": {
    "total": 45,
    "buy": 28,
    "sell": 17
  },
  "signals": [
    {
      "symbol": "000001",
      "strategy": "RSI反转",
      "signal": "BUY",
      "reason": "RSI超卖 (25.34 < 30)",
      "price": 12.50,
      "confidence": 0.85,
      "date": "2026-05-18",
      "timestamp": "2026-05-18T17:00:00"
    }
  ]
}
```

---

### 4️⃣ 风险检查 (risk_check.py)

**时间**: 每天 09:00（开盘前）  
**功能**: 检查持仓风险，生成预警报告  
**耗时**: 1-2分钟

**手动运行**:
```bash
python3 scripts/risk_check.py
```

**检查项目**:
1. **止损检查**: 
   - 固定止损: -8%
   - 移动止损: 从最高点回撤 -10%
   - 时间止损: 持仓超过30天且亏损

2. **集中度检查**:
   - 单只股票占比 > 30%: 高风险预警
   - 单只股票占比 > 20%: 中风险预警

3. **组合风险**:
   - 总亏损 > 10%: 组合预警
   - 盈亏分布统计
   - 最大亏损持仓

**输出**:
- 文件: `quant/.pi-invest/risk_report.json`
- 格式:
```json
{
  "generated_at": "2026-05-18T09:00:00",
  "holdings_count": 5,
  "stop_loss_checks": [...],
  "concentration": {...},
  "portfolio_risk": {...},
  "alerts": {
    "stop_loss": [...],
    "concentration": [...],
    "portfolio": false
  }
}
```

## 📊 数据库结构

### stocks.db

**表1: daily_klines** (K线数据)
```sql
CREATE TABLE daily_klines (
    symbol TEXT,
    date TEXT,
    open REAL,
    high REAL,
    low REAL,
    close REAL,
    volume REAL,
    amount REAL,
    PRIMARY KEY (symbol, date)
);
```

**表2: factor_values** (因子值)
```sql
CREATE TABLE factor_values (
    symbol TEXT,
    date TEXT,
    factor_name TEXT,
    factor_value REAL,
    PRIMARY KEY (symbol, date, factor_name)
);
```

```bash
SELECT 
    date,
    COUNT(DISTINCT symbol) as stocks,
    COUNT(DISTINCT factor_name) as factors
```

## 🛠️ 故障排查

### 问题1: 数据更新失败

**症状**: `/api/data/update` 或 `quantsys/data/pipeline.py update-klines` 报错或无数据

**解决**:
```bash
# 检查网络连接
ping baidu.com

# 检查数据库
sqlite3 quantsys/data/stocks.db "SELECT COUNT(*) FROM daily_klines;"

# 重新获取股票列表和K线数据
python3 quantsys/data/pipeline.py full --market A
```

### 问题2: 因子计算失败

**症状**: `calculate_factors.py` 报错

**解决**:
```bash
# 检查数据是否存在
sqlite3 quantsys/data/stocks.db "SELECT MAX(date) FROM daily_klines;"

# 检查因子库
python3 -c "from quantsys.factors import MA; print(MA(5))"

# 单独测试一只股票
python3 -c "
from quantsys.data.db import Database
from quantsys.factors import MA
import pandas as pd

db = Database('quantsys/data/stocks.db')
conn = db._get_connection()
df = pd.read_sql_query('SELECT * FROM daily_klines WHERE symbol=\"000001\" ORDER BY date DESC LIMIT 100', conn)
print(MA(5).calculate(df))
"
```

### 问题3: 信号生成失败

**症状**: `generate_signals.py` 无信号或报错

**解决**:
```bash
# 检查因子是否存在
sqlite3 quantsys/data/stocks.db "SELECT COUNT(*) FROM factor_values;"

# 检查最新日期
sqlite3 quantsys/data/stocks.db "SELECT MAX(date) FROM factor_values;"

# 手动查看某只股票的因子
sqlite3 quantsys/data/stocks.db "SELECT * FROM factor_values WHERE symbol='000001' LIMIT 10;"
```

### 问题4: 调度器无法启动

**症状**: `scheduler.py` 报错

**解决**:
```bash
# 检查依赖
pip list | grep apscheduler

# 重新安装
pip install --upgrade apscheduler

# 测试调度器
python3 scripts/test_scheduler.py
```

```python
    # 计算逻辑

with Pool(4) as pool:  # 4个进程
    results = pool.map(calculate_one_stock, symbols)
```

```sql
-- 启用 WAL 模式（提高并发）
PRAGMA journal_mode=WAL;

-- 增加缓存

CREATE INDEX IF NOT EXISTS idx_klines_date ON daily_klines(date);
```
