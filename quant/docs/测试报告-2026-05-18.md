## 🔍 发现的问题

### 1. 数据覆盖不足 ⚠️

**问题**: 数据库中只有7只股票有足够的历史数据（60天以上）

**原因**: 
- 数据库包含5518只股票代码
- 但大部分股票没有K线数据或数据不足

**建议**:
- 运行 `python3 quantsys/data/pipeline.py full --market A` 获取 A 股股票列表和历史 K 线数据
- 或者只针对有数据的股票进行分析

### 2. 部分因子计算失败 ⚠️

**问题**: OBV 和 EMV 因子在某些股票上计算失败

**错误信息**:
```
unsupported operand type(s) for +: 'float' and 'NoneType'
division by zero
```

**原因**: 数据中存在 None 值或零值

**影响**: 轻微，不影响整体功能

**建议**: 在因子计算前增加数据清洗步骤

## 📝 使用建议

### 1. 生产环境部署

```bash
# 1. 获取完整数据
python3 quantsys/data/pipeline.py full --market A

# 2. 测试所有任务
python3 scripts/test_core_tasks.py

# 3. 后台启动调度器
nohup python3 scripts/scheduler.py > logs/scheduler.log 2>&1 &

# 4. 查看进程
ps aux | grep scheduler.py

# 5. 监控日志
tail -f logs/scheduler.log
```

### 2. 日常维护

```bash
# 查看最新信号
cat quant/.pi-invest/signals.json | jq '.signals[] | select(.signal == "BUY")'

# 查看因子统计
sqlite3 quantsys/data/stocks.db "
SELECT date, COUNT(DISTINCT symbol) as stocks, COUNT(*) as records
FROM factor_values
GROUP BY date
ORDER BY date DESC
LIMIT 10;
"

# 手动触发任务
python3 scripts/calculate_factors.py
python3 scripts/generate_signals.py
python3 scripts/risk_check.py
```

### 3. 故障排查

```bash
# 检查数据库
sqlite3 quantsys/data/stocks.db "SELECT COUNT(*) FROM daily_klines;"

# 检查日志
grep "ERROR" logs/scheduler.log

# 重启调度器
pkill -f scheduler.py
nohup python3 scripts/scheduler.py > logs/scheduler.log 2>&1 &
```
