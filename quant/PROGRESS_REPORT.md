## 🚀 核心功能演示

### 1. 熔断机制

```python
from quantsys.risk import CircuitBreaker, CircuitBreakerConfig

# 创建熔断器
config = CircuitBreakerConfig(
    daily_loss_limit=0.05,      # 单日亏损5%熔断
    consecutive_loss_limit=3,   # 连续3次亏损熔断
    max_drawdown_limit=0.20     # 最大回撤20%熔断
)
breaker = CircuitBreaker(config)

# 检查熔断
should_halt, level, reason = breaker.check(portfolio, recent_trades)

if should_halt:
    print(f"🚨 熔断触发: {reason}")
    # 停止所有交易
```

### 2. 风险事件记录

```python
from quantsys.risk import RiskEventLogger

logger = RiskEventLogger()

# 记录熔断事件
logger.record_circuit_break(
    strategy_id='ma_cross',
    reason='连续亏损3次',
    trigger_type='consecutive_loss',
    trigger_value=3,
    threshold=3
)

# 查询统计
stats = logger.get_overall_statistics()
print(f"总熔断次数: {stats['total_circuit_breaks']}")
```

### 3. 策略组合器

```python
from quantsys.strategies.combiner import StrategyCombiner, CombinerConfig

# 创建组合器（VOTE模式）
config = CombinerConfig(
    mode='vote',
    weights={'ma_cross': 1.5, 'rsi': 1.0, 'bollinger': 0.8}
)
combiner = StrategyCombiner(config)

# 组合多个策略的信号
combined_signals, metadata = combiner.combine_signals(signals)

print(f"买入得分: {metadata['buy_score']}")
print(f"卖出得分: {metadata['sell_score']}")
print(f"胜出方向: {metadata['winner']}")
```
