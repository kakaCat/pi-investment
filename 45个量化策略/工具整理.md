 ### 第一级：立刻移除（零风险）                                                                                                                         
                                                                                                                                                        
 ```                                                                                                                                                    
   claude_code       — CLI 未安装，已注释，彻底删文件

 ```                                                                                                                                                    
                                                                                                                                                        
 ### 第二级：合并到 quant_cli（减少冗余）                                                                                                               
                                                                                                                                                        
 ```                                                                                                                                                    
   signal_execution        → 用 quant_cli executions.* / signal.* 替代                                                                                  
   strategy_optimize       → 用 quant_cli strategy.optimize 替代                                                                                        
   strategy_batch_validate → 用 quant_cli backtest.batch 替代                                                                                           
   algo_execute            → 移除（机构功能，无人用）                                                                                                   
 ```
