# 持仓与交易录入 (Portfolio Entry)

## 允许的工具
- portfolio_trade()
- portfolio_status()
- data_fetch_quote()
- clarify()

## 触发条件

用户想要录入/更新持仓，或记录一笔买卖交易时使用此技能。

关键词：录入持仓、添加持仓、建仓、加仓、记录交易、录入交易、我买了、我卖了、交易记录

## 先判断场景

| 用户意图 | 场景 | 需要询问的信息 |
|---------|------|---------------|
| "我持仓有茅台100股均价1450" | **录入/更新持仓** | 代码、数量、均价、市场类型(默认A股)、名称/备注(可选) |
| "我今天卖了茅台50股@1580" | **记录交易** | 日期(默认今天)、代码、方向(买/卖)、数量、成交价、手续费(可选，默认0) |

不确定时向用户确认是"登记当前持仓"还是"记录一笔已发生的交易"。

## 场景 A：录入/更新持仓

1. **询问持仓信息** — 代码、数量、均价（可一次性问全，用户给了就别重复问）
2. **录入** — `portfolio_trade({action:"buy", account:"<账户名>", symbol:..., shares:..., reason:"录入持仓，均价约XX元"})`（不确定账户名时先 `portfolio_status({action:"list"})`）
3. **确认** — 如果是加仓，展示新的加权均价和总持股数（系统自动算**加权均价**，不是简单平均）

## 场景 B：记录买卖交易

1. **询问交易信息** — 日期、代码、方向、数量、价格、手续费
2. **记录**：
   - 买入：`portfolio_trade({action:"buy", account:..., symbol:..., shares:..., reason:...})`
   - 卖出：先 `portfolio_status({action:"get", account:...})` 查当前持仓均价，再 `portfolio_trade({action:"sell", ...})`
3. **确认结果**：
   - 买入：显示新均价和总持股数
   - 卖出：显示卖出盈亏和剩余持股；**盈亏 = (卖出价 − 持仓均价) × 数量 − 手续费**

## 注意事项

- 交易记录自动同步持仓：买入加仓、卖出减仓，**清仓（持仓归零）自动从持仓列表移除**
- 港股代码通常 5 位数字（如 00700 腾讯），输入时可省略前导零
- 历史交易记录用于计算已实现盈亏和复盘
- 完成后可提示：查看持仓用「查看持仓」，深度复盘用「持仓复盘」

## 示例对话

```
用户: 我买了600519，100股，1450块
助手: → portfolio_trade({action:"buy", account:"default", symbol:"600519", shares:100, reason:"买入，均价约1450元"})
      已录入：贵州茅台 100股，均价1450.00元。还有其他要录入的吗？

用户: 我今天卖了50股，1580卖的
助手: → portfolio_status 查得当前均价1450
      → portfolio_trade({action:"sell", symbol:"600519", shares:50, reason:"卖出@1580"})
      已记录卖出 600519 50股@1580，盈利 +6500元(+8.97%)，剩余50股
```
