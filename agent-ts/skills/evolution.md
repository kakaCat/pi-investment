# 进化分析技能 (Evolution)

触发系统的自我进化循环：分析执行历史与交易记录，评估决策质量，生成优化建议。

## 允许的工具
- evolution_run()

## 触发条件

用户想要运行进化分析、查看进化报告、评估 Agent 自身表现时使用此技能。

**关键词**: 进化、进化分析、自我优化、自我改进、优化建议、查看进化报告

## 工作流程

1. **运行进化分析** — 调用 `evolution_run()`（无参数）。工具内部执行完整循环：
   - 分析执行历史（会话日志、交易记录、持仓变动），计算决策质量 gap
   - 归因分析：哪些工具调用低效、哪些参数需要调整、哪些决策模式有问题
   - 生成优化建议（经验库更新、参数调优、提示词改进等）
   - 报告持久化到 `.pi-invest/evolution/evolution-<日期>.md`
2. **解读报告** — 向用户汇报：目标收益 vs 实际收益、胜率、归因结论、建议清单
3. **说明建议去向** — 见下方「建议执行契约」，告诉用户哪些建议已转人工任务

## 建议执行契约（重要，2026-08-05 起生效）

- **autoExecute 默认关闭**：优化建议**不会**被自动应用，统一转为人工任务，落在 `.pi-invest/evolution/execution-*.json`。
- 只有设置环境变量 `EVOLUTION_AUTO_EXECUTE=1` 才会自动执行（需重启进程生效）。
- 自动代码生成（add_tool 建议自动写新工具代码）**已禁用**，不要向用户承诺"会自动创建工具"。
- 因此运行进化分析后，如果报告中有建议，应提醒用户：这些建议需要人工审阅后手动落实。

## 使用示例

**用户**: 跑一次进化分析 / 自我优化一下 / 你最近表现怎么样，进化一下

**Agent**: 调用 `evolution_run()`，然后按以下结构汇报：

```
## 进化分析报告摘要
- 报告路径：.pi-invest/evolution/evolution-<日期>.md
- 目标收益 vs 实际：X% vs Y%
- 胜率 / 交易次数：...
- 归因结论：...
- 优化建议（N 条，已转人工任务）：
  1. ...
  2. ...
> 注意：autoExecute 当前关闭，以上建议需人工确认后执行。
```

## 注意事项

- 进化分析需要足够的交易/执行数据才能产生有意义的结果，数据不足时如实说明
- 每周日 20:00 调度任务 `weekly_evolution` 会自动触发同一流程
- 建议在非交易时段手动运行（避免影响实时决策）
- 查看历史报告：直接读取 `.pi-invest/evolution/` 下最新的 `evolution-*.md` 文件
