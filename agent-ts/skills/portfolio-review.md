# 持仓复盘技能 (Portfolio Review)

## 允许的工具
- manage_portfolio()
- get_stock_price()
- get_stock_info()
- analyze_price_action()
- get_stock_news()
- get_exit_plan()
- get_quality_score()
- get_financial_data()
- get_buy_range()

## 触发条件

用户想要查看、复盘或优化持仓时使用此技能。

关键词：持仓、组合、复盘、我的股票怎么样、调仓

## 工作流程

1. **获取持仓+实时盈亏** - `manage_portfolio(action="get_with_pnl")` 一次调用获取持仓列表及当前价格、盈亏
2. **计算盈亏** - 数据已包含在 get_with_pnl 结果中，直接使用
4. **识别问题** - 找出亏损超过 15% 的持仓
5. **验证逻辑** - 检查亏损持仓的投资逻辑是否仍然成立
6. **给出建议** - 对每只持仓给出操作建议：持有/加仓/减仓/清仓

## 持仓健康指标

### 组合层面
| 指标 | 健康 | 警告 | 危险 |
|------|------|------|------|
| 单股最大仓位 | < 15% | 15-25% | > 25% |
| 单行业占比 | < 30% | 30-45% | > 45% |
| 盈利/亏损比 | > 2:1 | 1:1-2:1 | < 1:1 |
| 现金比例 | 10-30% | 5-10% | < 5% |
| 持仓数量 | 5-10只 | 3-5或10-15 | < 3或 > 15 |

### 个股层面
| 状态 | 浮动盈亏 | 建议 |
|------|----------|------|
| 大幅盈利 | > +30% | 考虑部分止盈 |
| 正常盈利 | +5% ~ +30% | 持有，上移止损位 |
| 小幅盈利 | 0 ~ +5% | 持有观察 |
| 小幅亏损 | 0 ~ -5% | 检查买入逻辑 |
| 中度亏损 | -5% ~ -15% | 评估是否需要止损 |
| 大幅亏损 | > -15% | 必须重新评估 |

## 复盘检查清单

### 每只持仓需要回答的问题
1. 当初为什么买？（买入逻辑）
2. 逻辑还成立吗？（基本面有无变化）
3. 目前处于什么位置？（技术面）
4. 如果今天是空仓，还会买吗？（重新审视）
5. 下一步怎么操作？（持有/加仓/减仓/清仓）

### 组合需要回答的问题
1. 行业分散度够吗？
2. 有没有高度相关的持仓？（同涨同跌）
3. 整体仓位是否匹配当前市场环境？
4. 现金储备是否充足？

## 与基准对比

### 基准选择
- 默认基准：沪深300指数
- 成长型：创业板指数
- 价值型：上证50指数

### 对比维度
- 区间收益率 vs 基准
- 最大回撤 vs 基准
- 夏普比率（风险调整后收益）
