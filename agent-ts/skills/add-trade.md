# 录入交易 (Add Trade)

## 允许的工具
- portfolio_trade()
- portfolio_status()
- data_fetch_quote()
- clarify()

## 触发条件

用户想要记录一笔买入或卖出交易时使用此技能。

关键词：录入交易、记录交易、/add-trade、我卖了、我买了、交易记录

## 工作流程

1. **询问交易信息** - 向用户逐步询问：
   - 交易日期（默认今天，格式 YYYY-MM-DD）
   - 股票代码
   - 交易方向：买入 或 卖出
   - 成交数量（股数）
   - 成交价格（元）
   - 手续费（可选，默认0）
   - 备注（可选）

2. **调用工具**：
   - 先调用 `portfolio_trade` 记录到持仓：
     - 买入：`portfolio_trade({action:"buy", account:"<账户名>", symbol:..., shares:..., reason:"..."})`
     - 卖出：先 `portfolio_status({action:"get", account:"<账户名>"})` 查看当前持仓，再 `portfolio_trade({action:"sell", account:"<账户名>", symbol:..., shares:..., reason:"..."})`
   - 不确定账户名时先 `portfolio_status({action:"list"})` 确认

3. **确认结果** - 展示交易记录和持仓变化：
   - 买入：显示新的均价和总持股数
   - 卖出：显示卖出盈亏（卖出价 vs 持仓均价）和剩余持股

4. **询问是否继续** - 问是否还有其他交易需要记录

## 盈亏计算（卖出时）

- 盈亏金额 = (卖出价 - 持仓均价) × 卖出数量 - 手续费
- 盈亏比例 = 盈亏金额 / (持仓均价 × 卖出数量) × 100%

## 注意事项

- 交易记录会自动同步更新持仓（买入加仓，卖出减仓/清仓）
- 如果卖出后持仓归零，则自动从持仓列表移除
- 历史交易记录用于计算已实现盈亏和复盘

## 示例对话

```
用户: /add-trade
助手: 记录一笔交易，交易日期？(默认今天 2026-03-21)
用户: 回车（用今天）
助手: 股票代码？
用户: 600519
助手: 买入还是卖出？
用户: 卖出
助手: 卖出数量？
用户: 50
助手: 成交价格？
用户: 1580
→ 查询当前持仓均价（如1450），计算盈亏：(1580-1450)×50 = +6500元（+8.97%）
→ 更新持仓：剩余50股，均价不变
→ 返回: 已记录卖出 600519 50股@1580，盈利 +6500元(+8.97%)，剩余50股
```
