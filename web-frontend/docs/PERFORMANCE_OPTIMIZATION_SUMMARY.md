## 使用指南

### 开发环境

1. 确保 `.env.development` 已配置
2. 运行 `npm run dev`
3. 打开浏览器控制台查看性能日志
4. 使用 `window.__PERFORMANCE_MONITOR__.printReport()` 查看详细报告

### 生产构建

1. 更新 `.env.production` 中的 API 地址
2. 运行 `npm run build`
3. 检查 `dist` 目录的构建产物
4. 使用 `npm run preview` 预览

### 性能监控

```javascript
// 完整性能报告
window.__PERFORMANCE_MONITOR__.printReport()

// 页面性能指标
window.__PERFORMANCE_MONITOR__.getMetrics()

// API 性能统计
window.__PERFORMANCE_MONITOR__.getAPIStats()

// 内存使用情况
window.__PERFORMANCE_MONITOR__.getMemoryUsage()
```
