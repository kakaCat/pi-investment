# 进化分析技能 (Evolution)

## 允许的工具
- evolution_run()

## 触发条件

用户想要运行进化分析、查看Agent表现是否需要优化时使用此技能。

关键词：进化、进化分析、自我优化、优化、调整能力

## 工作流程

1. **运行进化分析** - `evolution_run()` 执行完整的进化流程
2. **输出报告** - 向用户展示进化报告，包含：
   - 表现差距（目标 vs 实际）
   - 归因分析（目标不合理 vs 能力不足）
   - 优化建议（新增/移除工具、参数调整、经验更新）

## 输出格式

进化报告直接由 `evolution_run()` 生成，Agent 将结果原样呈现给用户。

## 使用示例

### 示例 1: 用户主动请求

**用户**: "运行进化分析，看看我这周表现如何"

**Agent 响应**:
```
好的，我来运行进化分析。
[调用 evolution_run()]
[展示报告内容]
```

### 示例 2: 定期自动运行

系统每周日 23:00 自动触发，Agent 会：
1. 收集本周数据
2. 生成进化报告
3. 通过飞书通知用户

### 示例 3: 查询历史经验

当 Agent 需要参考历史决策模式时，可以使用 `query_experience()` 工具（不在本 skill 中，但相关）。

## 注意事项

- 进化分析需要至少 3 笔交易数据才能产生有意义的结果
- 报告中的优化建议需要用户审核后才能应用
- 建议每周运行一次，保持持续改进
