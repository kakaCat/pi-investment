## 📚 经验总结（完整版）

### 1. SQL 参数占位符
❌ `:field::jsonb` → ✅ `CAST(:field AS jsonb)`

### 2. 表结构验证
✅ **先查表结构再写代码**，避免 90% 字段不匹配

### 3. JSONB 字段处理
- Python: `json.dumps(dict_value)`
- SQL: `CAST(:field AS jsonb)`

### 4. 外键约束
- 测试前创建依赖记录
- 示例：portfolio_holdings → stocks

### 5. CHECK 约束
- 如 `quantity > 0`
- 先查询，再决定 DELETE/UPDATE

### 6. UNIQUE 约束
- 生成唯一标识符
- fixture 自动清理

### 7. 可选字段
- 必须显式设置 `None`
