## 🎯 3个必会功能

### 功能1: 查看市场情绪 (1分钟)

**用途**: 判断今天适不适合买股票

```bash
curl http://127.0.0.1:5001/api/market/sentiment | jq .
```

**看什么**:
- `sentimentLevel`: 
  - `fear` / `extreme_fear` → ✅ 适合买入
  - `greed` / `extreme_greed` → ⚠️ 谨慎追高
- `recommendation`: 直接告诉你怎么做

**例子**:
```json
{
  "sentimentLevel": "fear",
  "recommendation": "市场恐慌，可关注优质标的逢低布局机会"
}
```
→ 今天可以找机会买入！

---

### 功能2: 筛选好股票 (2分钟)

**用途**: 从5000+股票中找到优质标的

```bash
# 找低PE、高ROE的股票
curl "http://127.0.0.1:5001/api/stocks/screen?max_pe=15&min_roe=0.15&limit=10" | jq .
```

**参数说明**:
- `max_pe=15`: PE小于15（低估）
- `min_roe=0.15`: ROE大于15%（盈利能力强）
- `limit=10`: 只返回10只

**结果**:
```json
{
  "matched": 10,
  "stocks": [
    {
      "symbol": "002818",
      "name": "富森美",
      "pe": 13.21,
      "roe": 6.7,
      "reason": "低PE(13.2), 高ROE(670.0%)"
    }
  ]
}
```

---

### 功能3: 评估单只股票 (1分钟)

**用途**: 详细分析一只股票

```bash
# 分析招商银行
curl http://127.0.0.1:5001/api/stock/600036/score | jq .
```

**看什么**:
- `totalScore`: 总分
  - ≥80: ✅ 优秀
  - 70-79: 🔶 良好
  - <60: ⚠️ 一般
- `grade`: 等级 (A+最好，D最差)
- `signals`: 系统建议

## 💡 实战：找一只好股票 (5分钟流程)

### Step 1: 看市场 (30秒)

```bash
curl -s http://127.0.0.1:5001/api/market/sentiment | jq '.data.sentimentLevel'
```

输出: `"neutral_positive"` → 市场偏乐观，可以操作

### Step 2: 筛选 (1分钟)

```bash

curl -s "http://127.0.0.1:5001/api/stocks/screen?max_pe=20&min_roe=0.15&limit=5" | jq '.data.stocks[] | {symbol, name, pe, roe}'
```

输出:
```json
{"symbol": "002818", "name": "富森美", "pe": 13.21, "roe": 6.7}
{"symbol": "002078", "name": "太阳纸业", "pe": 12.88, "roe": 2.94}
```

### Step 3: 详细分析 (每只1分钟)

```bash
# 分析富森美
curl -s http://127.0.0.1:5001/api/stock/002818/score | jq '.data | {totalScore, grade}'
```

输出: `{"totalScore": 75.0, "grade": "B+"}` → 不错！

```bash
# 看资金流向
curl -s http://127.0.0.1:5001/api/stock/002818/fund-flow | jq '.data.summary.trend'
```

输出: `"inflow"` → 主力在买！

```bash
# 看估值
curl -s http://127.0.0.1:5001/api/stock/002818/pe-percentile | jq '.data.percentile'
```

输出: `25.5` → 处于历史低位（25%分位数）

### Step 4: 决策

✅ 评分75分（B+）  
✅ 资金流入  
✅ 估值低位（25%分位）

→ **可以关注，找机会买入！**

## 🐍 Python脚本（复制即用）

### 完整选股脚本

```python
import requests
import json

BASE_URL = "http://127.0.0.1:5001"

def find_good_stocks():
    """完整的选股流程"""
    
    # 1. 检查市场情绪
    print("📊 市场情绪检查...")
    sentiment = requests.get(f"{BASE_URL}/api/market/sentiment").json()
    level = sentiment['data']['sentimentLevel']
    print(f"   情绪: {level}")
    print(f"   建议: {sentiment['data']['recommendation']}\n")
    
    # 2. 筛选股票
    print("🔍 筛选股票...")
    params = {
        'max_pe': 20,
        'min_roe': 0.15,
        'limit': 10
    }
    stocks = requests.get(f"{BASE_URL}/api/stocks/screen", params=params).json()
    print(f"   找到 {stocks['data']['matched']} 只股票\n")
    
    # 3. 逐个分析
    print("📈 详细分析...")
    candidates = []
    
    for stock in stocks['data']['stocks'][:5]:  # 只看前5只
        symbol = stock['symbol']
        name = stock['name']
        
        # 获取评分
        score_data = requests.get(f"{BASE_URL}/api/stock/{symbol}/score").json()
        if not score_data.get('success'):
            continue
            
        score = score_data['data']['totalScore']
        
        # 获取资金流向
        flow_data = requests.get(f"{BASE_URL}/api/stock/{symbol}/fund-flow?days=5").json()
        if not flow_data.get('success'):
            continue
            
        trend = flow_data['data']['summary']['trend']
        
        # 获取估值
        pe_data = requests.get(f"{BASE_URL}/api/stock/{symbol}/pe-percentile").json()
        if not pe_data.get('success'):
            continue
            
        percentile = pe_data['data']['percentile']
        
        print(f"\n   {symbol} {name}")
        print(f"   评分: {score:.1f}")
        print(f"   资金: {trend}")
        print(f"   估值: {percentile:.1f}%分位")
        
        # 综合判断
        if score >= 70 and trend == 'inflow' and percentile < 40:
            candidates.append({
                'symbol': symbol,
                'name': name,
                'score': score,
                'trend': trend,
                'percentile': percentile
            })
            print("   ✅ 推荐关注！")
    
    # 4. 总结
    print(f"\n🎯 找到 {len(candidates)} 只推荐股票:")
    for c in candidates:
        print(f"   {c['symbol']} {c['name']} (评分{c['score']:.1f}, 估值{c['percentile']:.1f}%)")

if __name__ == "__main__":
    find_good_stocks()
```

### 运行脚本

```bash
python find_stocks.py
```

## ⚡ 效率技巧

### 1. 保存常用命令

创建 `~/.bashrc` 别名:

```bash
alias qmarket='curl -s http://127.0.0.1:5001/api/market/sentiment | jq'
alias qscreen='curl -s "http://127.0.0.1:5001/api/stocks/screen?max_pe=15&min_roe=0.15&limit=10" | jq'
alias qscore='curl -s http://127.0.0.1:5001/api/stock/$1/score | jq'
```

使用:
```bash
qmarket  # 查看市场
qscreen  # 筛选股票
qscore 600036  # 评分
```

### 2. 批量分析脚本

```bash
#!/bin/bash
# batch_analyze.sh

symbols=("600036" "600519" "000858")

for symbol in "${symbols[@]}"; do
  echo "=== $symbol ==="
  curl -s "http://127.0.0.1:5001/api/stock/$symbol/score" | jq '.data.totalScore'
done
```

## ❓ 快速排错

### 问题1: 服务启动失败

**症状**: `Connection refused`

**解决**:
```bash
# 检查端口占用
lsof -i :5001

# 杀掉旧进程
pkill -f "python.*server.py"

# 重新启动
python api/server.py
```

### 问题2: 返回空数据

**症状**: `"data": []`

**原因**: 筛选条件太严格

**解决**: 放宽条件
```bash
# 太严格
curl "...?max_pe=5&min_roe=0.30"  # 几乎没有股票符合

# 合理
curl "...?max_pe=20&min_roe=0.15"
```

### 问题3: 响应慢

**症状**: 等待超过5秒

**原因**: 
- 评分计算耗时（遍历所有股票）
- 数据库查询慢

**解决**:
- 减少 `limit` 参数
- 添加 `min_score` 预筛选
