## 💡 技术亮点

### 1. FastAPI依赖注入

```python
@router.get("/pools")
async def list_pools(
    service: StockPoolAsyncService = Depends(get_pool_service)
):
    pools = await service.list_pools()
    return {"success": True, "data": pools}
```
