#### 页面2：图表研究（增强现有"股票研究"）⭐⭐⭐

**改造目标**：把现有的"股票研究"页面改造成专业的图表研究工具

**需要增加的功能**：
1. **交互式图表工具**
   - 画线工具（趋势线、水平线、斐波那契）
   - 标注工具（文字、箭头、矩形）
   - 测量工具（距离、涨跌幅）

2. **多周期切换**
   - 1分钟、5分钟、15分钟、30分钟、1小时
   - 日线、周线、月线

3. **技术指标叠加**
   - 主图指标：MA、布林带、SAR
   - 副图指标：MACD、RSI、KDJ、成交量

4. **K线形态识别**
   - 自动识别：锤子线、十字星、吞没形态
   - 手动标注：支撑位、阻力位

5. **对比图表**
   - 多股票对比
   - 与指数对比

6. **⭐ 买卖点标注（核心功能）**
   - 在K线图上直接标注量化系统的买卖点
   - 买入点：绿色向上箭头 ↑
   - 卖出点：红色向下箭头 ↓
   - 观望点：灰色圆点 •
   - 悬停显示详细信息：
     - 日期、价格、置信度
     - 信号原因（RSI、MACD等）
     - 操作者（Agent-v2 / 用户）
     - 执行状态（已执行/待审批/已拒绝）
     - 当前盈亏（如果已执行）
   - 可筛选显示：
     - 所有买卖点 / 仅Agent / 仅我的
     - 仅已执行 / 仅待审批
     - 时间范围（30天/90天/1年/全部）
   - 点击买卖点可查看完整分析过程
   - 可标记错误的买卖点用于改进策略

**页面布局**：
