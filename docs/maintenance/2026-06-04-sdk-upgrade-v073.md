**日期**: 2026-06-04

## 问题描述

### 原始错误
```
TypeError: message.content is not iterable
    at estimateTokens (/Users/mac/Documents/ai/pi-investment/node_modules/@mariozechner/pi-coding-agent/src/core/compaction/compaction.ts:260:33)
```

在 TUI Footer 组件渲染时，尝试估算上下文 token 数量时崩溃。

### 升级后的新错误
```
❌ 启动失败: this.runtimeHost.setBeforeSessionInvalidate is not a function
```

升级到 v0.72.1/v0.73.1 后，InteractiveMode 初始化时调用了不存在的方法。

## 解决方案

### 1. SDK 版本升级
```bash
npm install @mariozechner/pi-agent-core@0.73.1 \
            @mariozechner/pi-ai@0.73.1 \
            @mariozechner/pi-coding-agent@0.73.1 \
            @mariozechner/pi-tui@0.73.1
```

**注意**: 这些包已被弃用，官方建议迁移到 `@earendil-works/*` 命名空间。

### 2. 修复 readTool 导入

**v0.58.4 (旧版)**:
```typescript
import { readTool } from "@mariozechner/pi-coding-agent";
```

**v0.73.1 (新版)**:
```typescript
import { createReadTool } from "@mariozechner/pi-coding-agent";

const readTool = createReadTool();
```

### 3. 修复 InteractiveMode 构造

**v0.58.4 (旧版)**:
```typescript
const mode = new InteractiveMode(session);
await mode.run();
```

**v0.73.1 (新版)**:
```typescript
import { InteractiveMode, AgentSessionRuntime } from "@mariozechner/pi-coding-agent";

const runtime = new AgentSessionRuntime(
  session,
  { cwd: process.cwd() },
  async () => ({ session })
);
const mode = new InteractiveMode(runtime);
await mode.run();
```

## API 变更详解

### AgentSessionRuntime 类

v0.73 引入了 `AgentSessionRuntime` 作为 session 和 UI mode 之间的中间层：

```typescript
class AgentSessionRuntime {
  constructor(
    _session: AgentSession,
    _services: { cwd: string },
    createRuntime: () => Promise<{ session: AgentSession }>
  )
  
  setBeforeSessionInvalidate(callback: () => void): void
  setRebindSession(callback: () => Promise<void>): void
  
  get session(): AgentSession
  get services(): any
  get cwd(): string
}
```

`InteractiveMode` 不再直接接收 `session`，而是接收 `runtimeHost`（即 `AgentSessionRuntime` 实例）。
