# 动态因子权重智能选股系统 - 快速入门

## 🎯 功能概述

根据因子有效性（IC/IR）动态调整权重，自适应市场环境，构建高质量股票池。

**核心优势**：
- ✅ 自适应市场风格（牛市/熊市/震荡市）
- ✅ 自动降低失效因子权重
- ✅ 数据驱动（基于历史IC/IR）
- ✅ 提高选股质量和稳定性

## 💡 关键洞察

### 1. 权重配置对评分影响显著

同一只股票在不同权重配置下，评分差异可达 **10-15 分**。

### 2. 股票特性匹配场景很重要

- **技术面强** → 技术主导场景评分高（五粮液 +4）
- **基本面好** → 价值投资场景评分高（贵州茅台 +7）
- **资金面活跃** → 短线交易场景评分高（中国平安 +6）

### 3. 动态权重能自动优化

系统通过分析因子有效性（IC/IR），自动发现：
- 当前市场哪类因子更有效
- 哪些股票在当前环境下更具优势
- 如何配置权重以最大化选股质量

## 🛠️ 技术细节

### 权重计算算法

**IR-based（推荐）**：
```
weight_i = IR_i / sum(IR_j)
```

**示例**：
```
技术面 IR = 1.2 → 权重 = 1.2 / 2.4 = 50%
基本面 IR = 0.8 → 权重 = 0.8 / 2.4 = 33%
资金面 IR = 0.4 → 权重 = 0.4 / 2.4 = 17%
```

## 🔧 常见问题

### Q1: 为什么我的因子分析失败了？

**A**: 可能原因：
1. 数据不足（< 3个月）
2. 股票池过小（< 10只）
3. 因子名称错误

**解决**：检查日志，增加分析期或股票池大小。

### Q2: 动态权重和固定权重差别大吗？

**A**: 差别显著！演示结果显示：
- 贵州茅台：基本面主导 vs 默认 = 65 vs 58 (+12%)
- 五粮液：技术主导 vs 默认 = 58 vs 54 (+7%)

### Q3: 多久重新分析一次因子？

**A**: 建议：
- 每月重新分析（定期调仓）
- 市场风格切换时立即分析
- 关注因子衰减警告

### Q4: 如何选择 weight_algorithm？

**A**:
- **ir_based**（推荐）：数据充足、因子多样
- **rating_based**：快速评估、数据稀疏
