## 💻 实际效果演示

### 多数据源 Failover

```python
manager = DataSourceManager()

# 自动尝试 AkShare → EastMoney → Sina
result = manager.get_realtime_quote(["600000.SH", "000001.SZ"])

# 结果：
✓ 成功获取 2 个股票行情
  600000.SH: 浦发银行 - ¥929.0
  000001.SZ: 平安银行 - ¥1103.0

各数据源成功率:
  akshare: 0/1 (0.0%)      # 失败
  eastmoney: 1/1 (100.0%)  # 自动切换成功
  
✓ 缓存命中! # 第二次请求直接从缓存返回
```

### 缓存效果

```
第一次请求: API 调用 (~100ms)
第二次请求: 缓存命中 (<1ms)
性能提升: 100倍
```

### 熔断器保护

```
失败 1 次: 继续尝试
失败 2 次: 继续尝试
失败 3 次: 熔断器打开 ⚡
60 秒后: 尝试恢复
```
