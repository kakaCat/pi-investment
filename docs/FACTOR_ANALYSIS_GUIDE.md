# 因子分析功能使用指南

## 📊 功能概述

因子分析功能帮助你理解量化模型的决策逻辑，回答以下问题：
- **哪些因子最重要？** 模型主要依赖哪些指标做预测
- **为什么推荐这只股票？** 具体是哪些因子起作用
- **如何对比多只股票？** 从因子角度看哪只更优

## 🎯 三大核心功能

### 1. 查看因子重要性（整体）

**问AI**：
```
哪些因子最重要？
模型主要看重什么指标？
查看因子重要性排名
```

**返回示例**：
```markdown
## 📊 因子重要性分析

总因子数: 25
核心因子数: 8 (贡献80%预测能力)

### 🏆 Top 15 最重要因子

| 排名 | 因子名称 | 重要性 | 占比 | 累计 |
|------|---------|--------|------|------|
| 1 | RSI | 0.1523 | 15.23% | 15.23% |
| 2 | MA5/MA20 | 0.1245 | 12.45% | 27.68% |
| 3 | MACD_DIF | 0.0987 | 9.87% | 37.55% |
...

### 💡 解读
- 前 8 个因子贡献了 80% 的预测能力
- RSI 是最重要的因子，贡献 15.23%
- 前3个因子合计贡献 37.55%
```

---

### 2. 分析单只股票（详细）

**问AI**：
```
分析000001的因子
为什么推荐600036？
茅台的关键因子是什么？
```

**返回示例**：
```markdown
## 📊 000001 因子分析

**分析日期**: 2026-05-18
**当前价格**: ¥10.86

### 🎯 预测结果
- **方向**: 📈 看涨
- **上涨概率**: 68.50%
- **置信度**: 37.00%

### 🔍 关键因子贡献

| 因子 | 当前值 | 贡献度 | 方向 |
|------|--------|--------|------|
| RSI | 18.2900 | 0.0856 | 📈 看涨 |
| MA5/MA20 | 0.9850 | 0.0623 | 📈 看涨 |
| Volume_Ratio | 0.7200 | 0.0234 | 📉 看跌 |
| MACD_DIF | 0.0150 | 0.0198 | 📈 看涨 |
| Price/MA5 | 1.0120 | 0.0167 | 📈 看涨 |

### 💡 解读
- 📈 强烈看涨信号
- RSI=18.3 超卖，看涨因素
- 均线空头排列，看涨因素
- 成交量萎缩，看跌因素

### 📖 因子说明
- **RSI**: RSI相对强弱指标：<30超卖，>70超买
- **MA5/MA20**: 短期均线比：>1短期强势，<1短期弱势
- **Volume_Ratio**: 成交量比率：>1.2放量，<0.8缩量
```

### 3. 对比多只股票（选股）

**问AI**：
```
对比000001和600036的因子
这几只股票哪个更好：000001, 600036, 600519
帮我从茅台、五粮液、泸州老窖中选一只
```

**返回示例**：
```markdown
## 📊 股票因子对比分析

分析日期: 2026-05-18
对比数量: 2 只

### 🏆 预测排名

| 排名 | 股票 | 价格 | 上涨概率 | 方向 | 置信度 |
|------|------|------|----------|------|--------|
| 1 | 600036 | ¥37.47 | 75.20% | 📈 | 50.40% |
| 2 | 000001 | ¥10.86 | 68.50% | 📈 | 37.00% |

### 🔍 详细分析

#### 1. 600036 - 📈 看涨
**关键因子**:
- 📈 RSI: 10.37 (贡献: 0.1250)
- 📈 BB_Position: 0.15 (贡献: 0.0890)
- 📈 KDJ_K: 12.50 (贡献: 0.0670)

#### 2. 000001 - 📈 看涨
**关键因子**:
- 📈 RSI: 18.29 (贡献: 0.0856)
- 📈 MA5/MA20: 0.99 (贡献: 0.0623)
- 📉 Volume_Ratio: 0.72 (贡献: -0.0234)

### 💡 投资建议
- **首选**: 600036 (上涨概率 75.20%)
- **关键优势**: 📈 强烈看涨信号、RSI=10.4 超卖
- **避免**: 无（两只都看涨）
```

## 🚀 使用场景

### 场景1：验证买入信号
```
用户: 为什么推荐买入000001？
AI: [调用 analyze_stock_factors]
    显示：RSI超卖(18.3) + 布林带下轨 → 反弹机会
```

### 场景2：选股决策
```
用户: 茅台和五粮液哪个更好？
AI: [调用 compare_stock_factors]
    对比：茅台上涨概率72%，五粮液68% → 推荐茅台
```

### 场景3：理解模型
```
用户: 你的模型主要看什么指标？
AI: [调用 get_feature_importance]
    显示：RSI(15%) > MA均线(12%) > MACD(10%)
```

### 场景4：追踪因子变化
```
用户: 000001的RSI现在多少？
AI: [调用 analyze_stock_factors]
    显示：RSI=18.3（昨天30.5）→ 超卖加剧
```

## ⚠️ 注意事项

1. **需要训练好的模型**
   - 模型路径：`quant/quantsys/ml/models/xgboost_model.pkl`
   - 如果没有，先运行：`cd quant && python -m quantsys.ml.training.trainer`

2. **需要股票数据**
   - 数据库路径：`quant/quantsys/data/stocks.db`
   - 包含K线数据和因子数据

3. **SHAP库（可选）**
   - 安装：`pip install shap`
   - 提供更准确的因子贡献分析
   - 不安装也能用，会使用简化算法
