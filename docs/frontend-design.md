## 设计理念

### 核心定位

```
Agent = 量化分析员（员工）
人 = 投资经理（领导）
Web = 项目管理平台
```

### 设计原则

1. **双角色平等**
   - 领导可以自己分析、下单
   - Agent可以自动分析、提交审批
   - 两者使用完全相同的工具

2. **透明可追溯**
   - Agent的每个操作都有日志
   - 每个决策都可以复现验证
   - 所有审批都有记录

3. **清晰的权限边界**
   - Agent可以：分析、生成信号、提交申请
   - Agent不能：直接下单（需要审批）
   - 领导可以：所有操作 + 审批Agent的申请

## 交互流程

### 流程1：Agent提交买入申请

```
1. Agent分析600519
   ↓ POST /api/agent/log-action (记录操作)
   ↓ POST /api/snapshot/save (保存数据快照)
   
2. Agent生成买入建议
   ↓ POST /api/agent/record-decision (记录决策)
   
3. Agent创建订单
   ↓ POST /api/order/create (status='pending')
   
4. 前端显示待审批通知
   ↓ GET /api/order/get-pending
   
5. 领导查看分析详情
   ↓ GET /api/agent/get-log-detail
   
6. 领导批准
   ↓ POST /api/order/approve
   
7. 系统执行订单
   ↓ POST /api/order/execute
   ↓ POST /api/portfolio/update-position
```

### 流程2：领导复现Agent的分析

```
1. 领导点击"我来复现"
   ↓ GET /api/agent/get-log-detail (获取Agent的分析参数)
   ↓ GET /api/snapshot/get (获取当时的数据快照)
   
2. 前端使用相同的参数调用分析API
   ↓ POST /api/analysis/technical
   ↓ POST /api/analysis/fundamental
   
3. 前端对比结果
   ↓ POST /api/agent/compare-decision
   
4. 领导标记反馈
   ↓ POST /api/agent/update-feedback
```

### 流程3：领导自己分析股票

```
1. 领导输入股票代码
   ↓ GET /api/stock/quote?symbol=600519
   
2. 领导选择分析模块
   ↓ POST /api/analysis/technical
   ↓ POST /api/analysis/fundamental
   ↓ POST /api/sentiment/fund-flow
   
3. 前端计算综合评分
   
4. 领导生成交易计划
   ↓ POST /api/order/create (submitted_by='user')
   
5. 直接执行（无需审批）
   ↓ POST /api/order/execute
   ↓ POST /api/portfolio/update-position
```

## 数据流设计

### 实时数据更新

```typescript
// WebSocket连接
const ws = new WebSocket('ws://localhost:8000/ws');

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  
  switch (data.type) {
    case 'agent_action':
      // Agent有新操作，更新工作日志
      store.commit('addAgentLog', data.payload);
      break;
      
    case 'order_pending':
      // 有新的待审批订单
      store.commit('addPendingOrder', data.payload);
      notification.warning('有新的待审批订单');
      break;
      
    case 'position_update':
      // 持仓更新
      store.commit('updatePosition', data.payload);
      break;
      
    case 'price_update':
      // 价格更新
      store.commit('updatePrice', data.payload);
      break;
  }
};
```

### 状态管理

```typescript
// store/index.ts
export const useMainStore = defineStore('main', {
  state: () => ({
    // 账户信息
    account: {
      total_value: 0,
      cash: 0,
      positions: []
    },
    
    // Agent状态
    agent: {
      status: 'running',
      last_activity: null,
      logs: []
    },
    
    // 待审批订单
    pendingOrders: [],
    
    // 当前分析的股票
    currentStock: null,
    
    // 用户分析结果
    userAnalysis: null,
    
    // Agent分析结果
    agentAnalysis: null
  }),
  
  actions: {
    async fetchPositions() {
      const res = await api.get('/portfolio/get-positions');
      this.account.positions = res.data.positions;
    },
    
    async fetchPendingOrders() {
      const res = await api.get('/order/get-pending');
      this.pendingOrders = res.data.orders;
    },
    
    async approveOrder(orderId: string, feedback: string) {
      await api.post('/order/approve', {
        order_id: orderId,
        action: 'approve',
        approved_by: 'user',
        feedback
      });
      await this.fetchPendingOrders();
```
