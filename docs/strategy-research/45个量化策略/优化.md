缺口诊断：数据富足，赚钱能力贫乏                                                                                                                       
                                                                                                                                                        
 ### ⚫ 核心缺失 #1：策略研发闭环断裂（最致命）                                                                                                         
                                                                                                                                                        
 当前工作流：                                                                                                                                           
                                                                                                                                                        
 ```                                                                                                                                                    
   手写代码 → 回测 → 看数字 → 手改代码 → 再回测 → ...                                                                                                   
 ```                                                                                                                                                    
                                                                                                                                                        
 这本质上是蒙眼扔飞镖。应该有的闭环：                                                                                                                   
                                                                                                                                                        
 ```                                                                                                                                                    
   选股池 → 因子计算 → 策略生成 → 回测 → 参数优化 → 样本外验证 → 记入知识库                                                                             
     ↑                                                                      ↓                                                                           
     └──────────────────── 吸取经验，迭代 ─────────────────────────────────┘                                                                            
 ```                                                                                                                                                    
                                                                                                                                                        
 具体缺什么：                                                                                                                                           
 - 自动参数搜索：刚才 RSI<45 vs RSI<40、止盈+15% vs +20%，这些应该让机器自己搜，不是人脑猜                                                              
 - 策略性能数据库：V1/V2 的结果应该自动存档，下次做电力行业策略可以一键查"上次电力行业什么思路有效"                                                     
 - 样本外验证：训练期 2023-2024，验证期 2025 → 防止过拟合                                                                                               
                                                                                                                                                        
 ### ⚫ 核心缺失 #2：回测引擎太单薄（只能回测指标公式）                                                                                                 
                                                                                                                                                        
 当前只能回测 indicator 模式：df["buy"] = ... df["sell"] = ...                                                                                          
                                                                                                                                                        
 无法实现的策略类型：                                                                                                                                   
                                                                                                                                                        
 ┌──────────────────────────┬─────────────────────────┬─────────────────────┐                                                                           
 │ 策略                     │ 需要的能力              │ 现状                │                                                                           
 ├──────────────────────────┼─────────────────────────┼─────────────────────┤                                                                           
 │ PE < 12 的电力股每月轮动 │ 估值时间序列 + 组合回测 │ ❌                  │                                                                           
 ├──────────────────────────┼─────────────────────────┼─────────────────────┤                                                                           
 │ 股息率 >3.5% 买入持有    │ 分红数据                │ ❌ 没有分红数据     │                                                                           
 ├──────────────────────────┼─────────────────────────┼─────────────────────┤                                                                           
 │ 水电 vs 火电夏季轮动     │ 子行业标签 + 日历调度   │ ❌                  │                                                                           
 ├──────────────────────────┼─────────────────────────┼─────────────────────┤                                                                           
 │ 破净电力股（PB<1）买入   │ PB 时间序列             │ ⚠️ 有当前PB无历史PB │                                                                           
 ├──────────────────────────┼─────────────────────────┼─────────────────────┤                                                                           
 │ 财报季超预期策略         │ 盈利预测数据            │ ❌                  │                                                                           
 └──────────────────────────┴─────────────────────────┴─────────────────────┘                                                                           
                                                                                                                                                        
 这些都是电力行业真正该用的策略类型。你让我写 indicator 代码我写了，但它注定无法工作，因为电力股的赚钱逻辑不在均线和 RSI 里。                           
                                                                                                                                                        
 ### ⚫ 核心缺失 #3：策略类型单一                                                                                                                       
                                                                                                                                                        
 当前只有一种策略类型：indicator（OHLCV → buy/sell 列）                                                                                                 
                                                                                                                                                        
 缺少：                                                                                                                                                 
 - 因子排位策略：每月按 PE/ROE/股息率排位，买前 3，卖后 3                                                                                               
 - 组合轮动策略：设定标的池，定时调仓到最优                                                                                                             
 - 事件驱动策略：除息日买入、季报超预期买入                                                                                                             
                                                                                                                                                        
 ### ⚫ 核心缺失 #4：知识无法累积                                                                                                                       
                                                                                                                                                        
 刚才分析了 10 只电力股的基本面 → 回测了 5 只 → 这些都是宝贵经验，但：                                                                                  
 - 没有写入经验库（memory_write 只能存文本片段，不能结构化存储策略性能）                                                                                
 - 下次你要做"银行业策略"时，无法从"电力行业策略设计经验"中迁移学习                                                                                     
 - 每次对话都是重新开始                                                                                                                                 
                                                                                                                                                        
 ### ⚫ 核心缺失 #5：没有实盘追踪回路                                                                                                                   
                                                                                                                                                        
 信号生成 → 回测 → 但信号是否真的有效？                                                                                                                 
 - 没有 paper trading（模拟交易）能力                                                                                                                   
 - 没有信号跟踪（今天说买，30天后看结果）                                                                                                               
 - signal-test 系列 endpoint 存在但从未和 agent 工具集成
