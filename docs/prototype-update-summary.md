## 📝 技术细节

### 页面命名规范
- 页面ID格式：`page-{name}`
- 导航data属性：`data-page="{name}"`
- 页面默认隐藏：`class="page"`
- 当前页面显示：`class="page visible"`

### 样式保持一致
- 使用Tailwind CSS
- 卡片：`bg-white rounded-xl shadow-sm border border-slate-200 p-5`
- 按钮：`px-4 py-2 bg-blue-600 text-white rounded-lg`
- 颜色主题：蓝色主题（#3b82f6）

### JavaScript交互
- 页面切换：通过导航链接的`data-page`属性
- 现有的`showPage()`函数会处理页面切换
- 保持与现有页面相同的交互模式
