## 1. 一句话统一

**盈利引擎是"生产线"**（M0-M8 业务流水线，回答怎么挣钱）；**Autonomy 线是"生产线的自我改进机制"**（L1-L4 元能力，回答系统怎么自己变强）。两者的唯一接口是**基因组（genome）**——引擎每个环节按基因组规则运转，引擎的盈亏经验经 M6 回流，被 Autonomy 蒸馏成新规则写回基因组。

```
        ┌─────────────────────────────────────────────────┐
        │  基因组 genome（宪法/原则/规则/教训，g17）         │
        │  ★ 两线唯一接口：引擎读它决策，Autonomy 改写它     │
        └────────▲─────────────────────────────┬──────────┘
                 │ 塑造决策行为                  │ 蒸馏进化写回
┌────────────────┴─────────────┐   ┌──────────▼───────────┐
│  盈利引擎（业务线· WHAT）      │   │  Autonomy（元能力·HOW）│
│  M0数据→M1感知→M2选股→M3信号  │   │  L1记忆→L2分析→L3进化  │
│  →M4仓位→M5执行→盈亏          │──▶│  →L4元学习            │
│      ↑ M6 学习飞轮（复盘归因）  │   │  lifecycle 自修复/调度  │
└─────────────────────────────┘   └──────────────────────┘
```

## 4. 核心循环

```
引擎产生经验 → Autonomy 炼成规则 → 规则进基因组 → 基因组升级引擎行为 → 更好的经验
M6（业务复盘）管"记住"；evolution（元进化）管"改进"；共享同一 experience 基座。
```
