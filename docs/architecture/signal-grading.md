## 1. 分级定义

| 级别 | 定义 | 仓位动作 | 决策要求 |
|---|---|---|---|
| **A 级** | 多维度共振：主线/池共识 + 技术面信号 + 资金面流入 + 基本面无雷，至少 3 个独立维度同向 | 标准仓（按 regime_position_limit 上限内全额度） | 走完整 R-001 确认链 + reason 标注 A 级 |
| **B 级** | 2 个维度同向，或 3 维中有 1 维轻微矛盾 | 半仓 | 走 R-001 链 + reason 标注 B 级及矛盾点 |
| **C 级** | 单一维度信号（如纯技术反弹、纯消息面），或高维矛盾 | **只观察不交易**（可入 watchlist/盯盘规则） | 记录观察理由，禁止下单 |

### 维度清单（判定依据）
1. **主线/池维度**：标的属于当日落库主线（market:mainline）或三池共识
2. **技术面维度**：策略信号（已验证策略）、关键位突破/支撑、量价形态
3. **资金面维度**：主力资金流向、北向、量能状态
4. **基本面维度**：PE/ROE/盈利质量无雷，排雷（manipulation_detect）通过
5. **环境维度**：regime 仓位映射合规（R-006）、无熔断（R-007）

A 级 = 维度 1+2+3 或 1+2+4 同向且无维度 5 冲突。

## 2. 历史信号回溯分级示例（验收用 3 例）

### 例 1：今世缘 603369（2026-08-13 止盈，+13.2%）→ 回溯定级 **A 级**
- 维度 1：三池共识入选 ✅
- 维度 4：PE 分位 8.5% 极度低估 ✅
- 维度 2：RSI 超买给出退出信号 ✅（退出侧共振）
- 结果：+13.2%（经验库 id 54）。**教训：A 级的退出同样要分级执行——T+1 阻断 2 天损失 1.5% 收益。**

### 例 2：通威/TCL中环/扬农化工信号（2026-08-13，全部放弃）→ 回溯定级 **C 级（正确不交易）**
- 维度 1：均不在任何候选池 ❌；信号强度 N/A ❌
- 维度 5：满仓无空间、风格与当时成长市不匹配 ❌
- 结果：未交易，避免了低质量信号（经验 id 49/50）。**C 级信号的价值是"敢放弃"。**

### 例 3：紫金矿业 601899（2026-08-14 单日 -4.08%，未抄底）→ 回溯定级 **C 级观察（正确等待）**
- 维度 2：下跌途中无企稳信号 ❌（不接飞刀原则）
- 维度 1：主线内标的 ✅ 但池 churn 极端化信号失真 ❌
- 结果：保持 72.5% 现金等待，规避不确定性（经验 id 72）。**恐慌底现金即仓位。**

## 3. 与工具链的接线

- 信号来源：`strategy_execute(signal)`、`opportunity_scan`、`mainline_stocks` 映射、盯盘规则触发
- 每笔信号落库追踪：`signal_track`（M3-3），5/10/20 日后回看胜率
- 分级结论写入交易 `reason`（R-005）：如「A级：主线白银+技术突破+主力流入」
- 验证门（RFC 008）对 A/B 级信号的后续表现做规则级归因（远期）

## 4. 纪律

- C 级不产生任何委托，只允许观察记录
- 连续 3 个 A 级信号后续 10 日胜率 <50% → 触发分级标准复审（经验蒸馏议程）
