## ✅ 功能 1: 经验库查询工具

### 实现文件
- `src/services/intelligence/experience-query.ts` - 查询逻辑
- `src/infrastructure/tools/query-experience-tool.ts` - Agent 工具定义

### 核心功能
```typescript
// Agent 调用示例
query_experience({
  scenario: "MACD金叉且成交量放大",
  symbol: "600519",           // 可选：指定股票
  conditions: ["RSI>70"],     // 可选：条件过滤
  limit: 5                    // 返回结果数量
})
```

### 返回信息
- 历史案例的胜率和平均收益
- 具体的成功/失败案例
- 基于历史数据的建议（aggressive/moderate/cautious/avoid）
- 置信度评分

### 匹配算法
1. **文本相似度匹配** - Jaccard 相似度
2. **条件过滤** - 支持条件列表匹配
3. **置信度过滤** - 默认 >= 0.5
4. **股票代码过滤** - 可选
5. **综合排序** - 相似度 40% + 置信度 60%

- ✅ Agent 可直接调用

## ✅ 功能 2: Session 分析器

### 实现文件
- `src/services/intelligence/session-analyzer.ts` - Session 日志解析和工具效能计算

### 核心功能
```typescript
// 自动分析 Session 日志
analyzeSessionsAndCalculateEfficiency(
  piDir,
  trades,
  windowDays  // 时间窗口
)
```

### 分析流程
1. **加载 Session 日志** - 从 `.pi-invest/sessions/` 目录
2. **解析工具调用** - 提取工具名称、参数、结果
3. **关联交易结果** - 匹配 Session 与交易（3天内）
4. **计算效能指标**:
   - `call_count` - 调用次数
   - `decisions_after_call` - 决策次数
   - `win_rate` - 胜率
   - `avg_return` - 平均收益
   - `avg_tokens` - 平均 Token 消耗
   - `cost_per_call` - 每次调用成本
   - `roi` - 投资回报率
   - `rating` - 评级 (1-5)

### 评级标准
- ⭐⭐⭐⭐⭐ (5): ROI > 100 且胜率 > 70%
- ⭐⭐⭐⭐ (4): ROI > 50 且胜率 > 60%
- ⭐⭐⭐ (3): ROI > 0 且胜率 > 50%
- ⭐⭐ (2): ROI > -50
- ⭐ (1): ROI < -50
