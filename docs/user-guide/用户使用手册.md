## 系统简介

quantsys-v2 是一个完整的量化投资决策支持系统，提供从市场分析到个股研判的全流程工具。

### 核心功能

**六维度分析体系**:
- 🌍 **市场环境分析**: 判断市场情绪和阶段
- 🔍 **股票批量筛选**: 多条件快速筛选
- 📊 **个股综合评分**: 4维度智能打分
- 💰 **资金流向追踪**: 主力资金动向
- 💎 **估值水平判断**: PE历史分位数
- 👥 **股东结构分析**: 内部交易、基金持仓

### 系统特点

- ✅ **11个功能模块** 全覆盖
- ✅ **秒级响应** 高性能
- ✅ **多维度分析** 全面准确
- ✅ **自动化评分** 省时省力
- ✅ **智能信号** 辅助决策

## 快速开始

### 安装和启动

```bash
# 进入项目目录
cd quantsys-v2

# 启动后端服务
python api/server.py

# 服务运行在: http://localhost:5001
```

### 第一个API调用

```bash
# 查看市场情绪
curl http://localhost:5001/api/market/sentiment

# 获取股票评分
curl http://localhost:5001/api/stock/600036/score
```

## 功能使用指南

### 1. 判断市场环境

**使用场景**: 每天交易前，先看市场整体情绪

**API**: `GET /api/market/sentiment`

**操作步骤**:
1. 调用市场情绪API
2. 查看 `sentimentLevel` (情绪等级)
3. 查看 `marketPhase` (市场阶段)
4. 参考 `recommendation` (操作建议)

**解读指南**:

| 情绪等级 | 说明 | 建议 |
|---------|------|------|
| extreme_fear | 极度恐慌 | ✅ 寻找优质标的逢低布局 |
| fear | 恐慌 | ✅ 关注低估股票 |
| neutral | 中性 | 🔶 正常操作 |
| greed | 贪婪 | ⚠️ 注意风险控制 |
| extreme_greed | 极度贪婪 | ⚠️ 谨慎追高，考虑减仓 |

**实例**:
```python
sentiment = get_market_sentiment()
if sentiment['sentimentLevel'] == 'extreme_fear':
    print("市场恐慌，寻找机会")
elif sentiment['sentimentLevel'] == 'extreme_greed':
    print("市场过热，注意风险")
```

### 2. 批量筛选股票

**使用场景**: 从5000+股票中快速找到符合条件的标的

**API**: `GET /api/stocks/screen`

**操作步骤**:
1. 设定筛选条件
2. 调用筛选API
3. 查看匹配结果
4. 对结果进一步分析

**常用筛选条件**:

| 条件 | 参数 | 推荐值 |
|------|------|--------|
| PE低估 | max_pe | 15-20 |
| 高盈利 | min_roe | 0.15-0.20 |
| 低负债 | max_debt_ratio | 0.3-0.5 |
| 大盘股 | min_market_cap | 500+ |
| 高评分 | min_score | 70+ |

**预设策略**:

**价值股筛选**:
```bash
curl "http://localhost:5001/api/stocks/screen?max_pe=15&min_roe=0.15&max_debt_ratio=0.3&limit=20"
```

**成长股筛选**:
```bash
curl "http://localhost:5001/api/stocks/screen?min_score=70&min_roe=0.10&limit=20"
```

**大盘蓝筹**:
```bash
curl "http://localhost:5001/api/stocks/screen?min_market_cap=500&exclude_st=true&limit=20"
```

### 3. 个股综合评分

**使用场景**: 快速评估个股质量

**API**: `GET /api/stock/{symbol}/score`

**操作步骤**:
1. 输入股票代码
2. 查看总分和等级
3. 查看各维度得分
4. 参考交易信号

**评分解读**:

| 等级 | 分数 | 说明 | 建议 |
|------|------|------|------|
| A+ | 90+ | 优秀 | ✅ 强烈关注 |
| A | 80-89 | 良好 | ✅ 可考虑买入 |
| B+ | 70-79 | 中上 | 🔶 继续观察 |
| B | 60-69 | 中等 | 🔶 谨慎 |
| C | 50-59 | 一般 | ⚠️ 回避 |
| D | <50 | 较差 | ⚠️ 不建议 |

**维度分析**:
- **技术面 (40%)**: RSI, MACD, 均线, 布林带
- **基本面 (30%)**: PE, ROE, 负债率, PB
- **动量 (20%)**: 涨跌幅, 成交量, 连续上涨
- **质量 (10%)**: 毛利率, 净利率, 现金流

**实例**:
```python
score = get_stock_score("600036")
if score['totalScore'] >= 70:
    print("优质股票，可考虑")
    if score['technicalScore'] > 60:
        print("技术面较好")
```

### 4. 资金流向分析

**使用场景**: 追踪主力资金动向

**API**: `GET /api/stock/{symbol}/fund-flow?days=5`

**操作步骤**:
1. 查看主力净流入
2. 分析资金结构
3. 查看连续流入天数
4. 参考交易信号

**关键指标**:

| 指标 | 说明 | 看多信号 |
|------|------|---------|
| 主力净流入 | 主力资金进出 | >0 且持续 |
| 连续流入天数 | 持续性 | ≥3天 |
| 超大单占比 | 机构参与 | >50% |
| 资金结构 | 机构/散户 | institutional |

**信号解读**:

| 信号类型 | 说明 | 操作 |
|---------|------|------|
| strong_inflow | 主力持续大幅流入 | ✅ 买入信号 |
| accumulation | 机构吸筹 | ✅ 低位建仓 |
| distribution | 机构出货 | ⚠️ 注意风险 |
| outflow_warning | 主力大幅流出 | ⚠️ 建议回避 |

**实例**:
```python
flow = get_fund_flow("600036", days=10)
if flow['summary']['consecutiveInflowDays'] >= 5:
    if flow['summary']['totalMainNetInflow'] > 10000:
        print("资金持续流入，关注")
```

### 5. 估值判断

**使用场景**: 判断当前是否低估

**API**: `GET /api/stock/{symbol}/pe-percentile?years=3`

**操作步骤**:
1. 查看当前PE
2. 查看历史分位数
3. 查看估值等级
4. 制定买入策略

**分位数解读**:

| 分位数 | 说明 | 建议 |
|--------|------|------|
| 0-10% | 极度低估 | ✅✅ 强烈买入 |
| 10-25% | 低估 | ✅ 可以买入 |
| 25-40% | 偏低 | 🔶 继续观察 |
| 40-60% | 合理 | 🔶 正常持有 |
| 60-75% | 偏高 | ⚠️ 谨慎 |
| 75-90% | 高估 | ⚠️ 考虑减仓 |
| 90-100% | 极度高估 | ⚠️⚠️ 建议卖出 |

**定投策略**:
```python
def calculate_invest_amount(symbol):
    pe = get_pe_percentile(symbol)
    percentile = pe['percentile']
    
    if percentile < 20:
        return 3000  # 低估时加倍
    elif percentile < 40:
        return 2000  # 偏低时正常
    elif percentile < 60:
        return 1000  # 合理时减少
    else:
        return 0     # 高估时暂停
```

### 7. 股东分析

#### 内部交易

**使用场景**: 了解公司内部人信心

**API**: `GET /api/stock/{symbol}/insider-trades?days=30`

**看多信号**:
- 高管/董事持续增持
- 增持金额较大
- 多人增持

**看空信号**:
- 高管/董事减持
- 减持比例大
- 集中减持

#### 基金持仓

**使用场景**: 了解机构配置

**API**: `GET /api/stock/{symbol}/fund-holdings`

**看多信号**:
- 持有基金数量多
- 知名基金持有
- 持仓比例增加

#### 股东变化

**使用场景**: 分析筹码集中度

**API**: `GET /api/stock/{symbol}/holder-changes`

**解读**:
- decreasing: 股东户数减少，筹码集中 ✅
- stable: 股东户数稳定 🔶
- increasing: 股东户数增加，筹码分散 ⚠️

## 实战场景

### 场景1: 每日选股流程

**步骤**:

1. **判断市场环境** (1分钟)
   ```python
   sentiment = get_market_sentiment()
   print(f"市场情绪: {sentiment['sentimentLevel']}")
   print(f"操作建议: {sentiment['recommendation']}")
   ```

2. **批量筛选** (2分钟)
   ```python
   # 根据市场环境调整策略
   if sentiment['sentimentLevel'] in ['fear', 'extreme_fear']:
       # 恐慌时找低估值
       stocks = screen_stocks(max_pe=10, min_roe=0.20)
   else:
       # 正常时找优质股
       stocks = screen_stocks(min_score=70, max_pe=20)
   ```

3. **逐个分析** (每只2分钟)
   ```python
   for stock in stocks['stocks'][:10]:
       symbol = stock['symbol']
       
       # 综合评分
       score = get_stock_score(symbol)
       
       # 资金流向
       flow = get_fund_flow(symbol)
       
       # 估值判断
       pe = get_pe_percentile(symbol)
       
       # 综合判断
       if (score['totalScore'] > 70 and
           flow['summary']['trend'] == 'inflow' and
           pe['percentile'] < 30):
           print(f"✅ {stock['name']}: 优质+资金+低估")
   ```

### 场景3: 定投策略

**智能定投金额计算**:

```python
def smart_invest(symbol, base_amount=1000):
    """
    根据估值和市场情绪动态调整定投金额
    """
    # 获取估值
    pe = get_pe_percentile(symbol)
    percentile = pe['percentile']
    
    # 获取市场情绪
    sentiment = get_market_sentiment()
    fear_greed = sentiment['fearGreedIndex']
    
    # 基础金额
    amount = base_amount
    
    # 估值调整
    if percentile < 20:
        amount *= 2.0  # 极度低估时加倍
    elif percentile < 40:
        amount *= 1.5  # 偏低时增加50%
    elif percentile > 75:
        amount *= 0.5  # 高估时减半
    
    # 市场情绪调整
    if fear_greed < 30:
        amount *= 1.5  # 恐慌时增加50%
    elif fear_greed > 70:
        amount *= 0.7  # 贪婪时减少30%
    
    return int(amount)

# 使用示例
amount = smart_invest("600036", base_amount=1000)
print(f"本期定投金额: {amount}元")
```

## 最佳实践

### 1. 组合使用功能

**不要**单独依赖一个指标  
**要**综合多个维度分析

✅ 好的例子:
```python
# 综合判断
score = get_stock_score(symbol)
flow = get_fund_flow(symbol)
pe = get_pe_percentile(symbol)

if (score['totalScore'] > 70 and
    flow['summary']['trend'] == 'inflow' and
    pe['percentile'] < 40):
    print("✅ 优质标的")
```

❌ 不好的例子:
```python
# 只看一个指标
score = get_stock_score(symbol)
if score['totalScore'] > 70:
    print("买入")  # 风险：可能高估
```

---

### 2. 定期review

**建议频率**:
- 市场情绪: 每天交易前
- 资金流向: 每天收盘后
- 综合评分: 每周一次
- 估值分析: 每周一次
- 股东分析: 每月一次

---

### 3. 设置阈值

根据自己的风险偏好设置:

**保守型**:
- 评分: ≥80
- PE分位数: <20%
- 连续流入: ≥5天

**平衡型**:
- 评分: ≥70
- PE分位数: <40%
- 连续流入: ≥3天

**激进型**:
- 评分: ≥60
- PE分位数: <60%
- 资金流入即可

## 常见问题

### Q1: 评分为什么是0或很低？

**A**: 可能原因:
1. 因子数据缺失（常见于新股）
2. 技术指标未达标
3. 基本面较差

**解决**: 查看各维度详细得分，找出具体原因

---

### Q2: 数据来源是什么？

**A**: 
- 主要: akshare (东方财富)
- 备用: 模拟数据
- 查看响应中的 `source` 字段

---

### Q3: 多久更新一次？

**A**:
- 实时查询，不缓存
- K线数据: 日线级别
- 财务数据: 季报更新

---

### Q4: 如何解释"模拟数据"？

**A**: 
当真实数据源不可用时，系统会使用模拟数据保证功能可用。
- 用于测试和演示
- 生产环境应使用真实数据
- 响应中 `source` 会标注

---

### Q5: 评分权重可以调整吗？

**A**: 
可以！修改 `config/scoring_config.py`:
```python
SCORING_WEIGHTS = {
    'technical': 0.50,    # 改为50%
    'fundamental': 0.25,  # 改为25%
    'momentum': 0.15,
    'quality': 0.10,
}
```

---

### Q6: 如何批量查询？

**A**:
使用 Python 脚本循环调用:
```python
symbols = ['600036', '600519', '000858']
results = []

for symbol in symbols:
    score = get_stock_score(symbol)
    results.append(score)
```

---

### Q7: API有调用限制吗？

**A**: 
当前版本没有限制，但建议:
- 合理控制频率
- 避免短时间大量请求
- 生产环境建议添加缓存
