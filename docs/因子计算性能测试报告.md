## 优化细节

### 1. 多进程并行

**原始代码**:
```python
for symbol in symbols:  # 串行
    factors = calculate_factors_for_stock(db, symbol)
    save_factors(db, symbol, date, factors)
```

**优化代码**:
```python
with Pool(processes=7) as pool:
    results = pool.map(calculate_factors_for_stock, symbols)  # 并行
    save_factors_batch(db, results)  # 批量保存
```

**效果**: CPU利用率从94%提升到293%（7核并行）

### 2. 批量INSERT

**原始代码**:
```python
for factor_name, factor_value in factors.items():
    conn.execute("INSERT INTO factor_values VALUES (?, ?, ?, ?)", ...)
    # 27个因子 = 27次INSERT
```

**优化代码**:
```python
insert_data = [(symbol, date, name, value) for ...]
conn.executemany("INSERT INTO factor_values VALUES (?, ?, ?, ?)", insert_data)
# 一次性插入所有数据
```

**效果**: 数据库I/O从 27×19=513次 减少到 1次

### 3. 事务批处理

**原始代码**:
```python
for symbol in symbols:
    save_factors(db, symbol, date, factors)  # 每次都commit
```

**优化代码**:
```python
conn.execute('BEGIN TRANSACTION')
for result in batch_results:
    # 批量处理
conn.commit()  # 一次性commit
```

**效果**: commit次数从19次减少到1次

### 4. 预先筛选

**原始代码**:
```python
symbols = db.get_all_symbols()  # 5518只
for symbol in symbols:
    data = get_stock_data(db, symbol)
    if len(data) < 60:
        continue  # 浪费了一次查询
```

**优化代码**:
```python
# 预先筛选有效股票
symbols = conn.execute("""
    SELECT symbol FROM (
        SELECT symbol, COUNT(*) as cnt 
        FROM daily_klines GROUP BY symbol
    ) WHERE cnt >= 60
""").fetchall()  # 只返回19只
```

**效果**: 避免5499次无效数据库查询
