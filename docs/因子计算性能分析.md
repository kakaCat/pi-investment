## 性能瓶颈分析

### 瓶颈1: 串行处理 ⭐⭐⭐⭐⭐

**问题**: 5518只股票串行处理，即使每只股票只需100ms，总时间也要：
```
5518 × 100ms = 551秒 ≈ 9分钟
```

**影响**: 最严重的瓶颈

**优化方案**: 
- 使用多进程并行处理（推荐4-8进程）
- 预期提升: 4-8倍速度

### 瓶颈2: 数据库I/O ⭐⭐⭐⭐

**问题**: 每只股票都要执行3次数据库操作：
1. SELECT 查询100天K线
2. DELETE 删除旧因子
3. INSERT 插入新因子（27个因子 = 27次INSERT）

总计: 5518 × (1 SELECT + 1 DELETE + 27 INSERT) = **159,522次数据库操作**

**影响**: 严重瓶颈

**优化方案**:
- 批量INSERT（一次插入多行）
- 使用事务批处理（每100只股票提交一次）
- 使用 INSERT OR REPLACE 替代 DELETE + INSERT
- 预期提升: 3-5倍速度

### 瓶颈3: 重复查询 ⭐⭐⭐

**问题**: 每次计算都查询100天历史数据，但实际只需要：
- 最新1天的数据（计算当日因子）
- 前60天的数据（作为计算窗口）

**影响**: 中等瓶颈

**优化方案**:
- 增量计算：只计算最新日期的因子
- 缓存历史数据：避免重复查询
- 预期提升: 1.5-2倍速度

### 瓶颈4: 数据不足导致无效计算 ⭐⭐

**问题**: 
```python
if data is None or len(data) < 60:
    return None  # 跳过
```

5518只股票中，大部分可能因数据不足（<60天）而被跳过，但仍然执行了数据库查询。

**影响**: 轻度瓶颈

**优化方案**:
- 预先筛选有足够数据的股票
- 使用SQL COUNT预检查
- 预期提升: 1.2-1.5倍速度

### 瓶颈5: 缺少进度缓存 ⭐

**问题**: 如果计算中断，需要从头开始，没有断点续传。

**影响**: 轻度瓶颈（影响用户体验）

**优化方案**:
- 记录已完成的股票
- 支持断点续传
- 预期提升: 提升容错性

## 性能优化方案

### 方案A: 快速优化（1小时实施）⭐⭐⭐⭐⭐

**优化点**:
1. 多进程并行（4进程）
2. 批量INSERT（100行/批次）
3. 事务批处理（100只股票/事务）

**预期效果**: 
- 当前: ~10分钟
- 优化后: ~1-2分钟
- 提升: **5-10倍**

**实施代码**:
```python
from multiprocessing import Pool
import sqlite3

def calculate_batch(symbols_batch):
    """批量计算一组股票的因子"""
    db = Database(db_path)
    conn = db._get_connection()
    
    results = []
    for symbol in symbols_batch:
        factors = calculate_factors_for_stock(db, symbol)
        if factors:
            results.append((symbol, latest_date, factors))
    
    # 批量插入
    if results:
        conn.execute('BEGIN TRANSACTION')
        for symbol, date, factors in results:
            for factor_name, factor_value in factors.items():
                conn.execute(
                    'INSERT OR REPLACE INTO factor_values VALUES (?, ?, ?, ?)',
                    (symbol, date, factor_name, factor_value)
                )
        conn.commit()
    
    return len(results)

# 主函数
symbols = db.get_all_symbols(market='A')
batch_size = 100
batches = [symbols[i:i+batch_size] for i in range(0, len(symbols), batch_size)]

with Pool(processes=4) as pool:
    results = pool.map(calculate_batch, batches)
```
