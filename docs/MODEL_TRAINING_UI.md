# 模型训练UI使用指南

## 概述

模型训练页面提供了一个可视化界面，用于配置和启动机器学习模型训练任务，并查看训练历史和结果。

## 访问方式

1. 启动后端API服务器：
```bash
node dist/api/web/server.js
```

2. 启动前端开发服务器：
```bash
cd quant-web
npm run dev
```

3. 在浏览器中访问：http://localhost:3001/

4. 点击左侧菜单的"模型训练"

## 功能说明

### 1. 训练配置

在训练配置卡片中，可以设置以下参数：

- **训练天数** (30-365天)
  - 用于训练的历史数据天数
  - 推荐值：90天（平衡数据量和训练时间）

- **模型类型**
  - XGBoost（推荐）：梯度提升树，性能优秀
  - LightGBM：更快的训练速度
  - Random Forest：随机森林

- **交叉验证折数** (2-10折)
  - 用于评估模型性能的交叉验证折数
  - 推荐值：5折（标准配置）

- **使用高级特征工程**
  - 开启：使用49个高级特征（包含衍生特征、统计特征、交叉特征等）
  - 关闭：使用38个原始技术指标特征
  - 推荐：开启（性能更好）

### 2. 训练任务监控

点击"开始训练"后，页面会显示当前训练任务的状态：

- **状态指示**
  - 进行中：蓝色旋转图标
  - 已完成：绿色对勾
  - 失败：红色叉号

- **任务信息**
  - 训练天数
  - 模型类型
  - 特征类型（高级/原始）

- **训练结果**（完成后显示）
  - 准确率
  - AUC值
  - 特征数量

### 3. 历史训练报告

在页面底部的表格中，可以查看所有历史训练记录：

- **训练时间**：任务完成的时间戳
- **特征数**：使用的特征数量（49个高级特征或38个原始特征）
- **操作**：点击"查看详情"可以查看完整的训练报告

### 4. 报告详情

点击"查看详情"后，会弹出模态框显示：

- 训练时间
- 特征数量
- 完整的特征列表

## 性能对比

根据90天数据、5折交叉验证的测试结果：

| 特征类型 | 特征数 | 准确率 | AUC |
|---------|--------|--------|-----|
| 原始特征 | 38 | 79.93% | 0.5998 |
| 高级特征 | 49 | 82.14% | 0.6314 |

**结论**：高级特征在所有指标上都优于原始特征，推荐使用。

## API端点

前端调用的后端API端点：

- `POST /api/training/start` - 启动训练任务
- `GET /api/training/status/:taskId` - 查询任务状态
- `GET /api/training/reports` - 获取所有训练报告
- `GET /api/training/report/:filename` - 获取报告详情

详细API文档见：[TRAINING_API.md](./TRAINING_API.md)

## 训练流程

1. 在训练配置表单中设置参数
2. 点击"开始训练"按钮
3. 系统在后台启动Python训练脚本
4. 页面每3秒轮询一次任务状态
5. 训练完成后显示结果
6. 可以在历史报告中查看详细信息

## 注意事项

1. **训练时间**：根据数据量和模型复杂度，训练可能需要几秒到几分钟
2. **并发限制**：同一时间只能运行一个训练任务
3. **数据要求**：确保数据库中有足够的历史数据
4. **特征工程**：首次使用高级特征时，系统会自动进行特征映射和提取

## 故障排查

### 训练失败

如果训练任务失败，检查：

1. 数据库连接是否正常
2. Python环境是否配置正确
3. 是否有足够的历史数据
4. 查看任务日志：`GET /api/training/logs/:taskId`

### 页面无法加载

1. 确认后端API服务器正在运行（端口3001）
2. 确认前端开发服务器正在运行
3. 检查浏览器控制台是否有错误

### API调用失败

1. 检查API服务器日志
2. 确认API端点URL正确
3. 检查CORS配置
