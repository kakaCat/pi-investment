# 量化投资系统工作流程指南

## 概述

本文档介绍量化投资系统的完整工作流程，从数据采集到交易信号生成的全过程。

## 核心工作流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     量化投资系统工作流程                          │
└─────────────────────────────────────────────────────────────────┘

1️⃣ 数据采集          2️⃣ 因子计算          3️⃣ 特征工程
   ↓                    ↓                    ↓
[股票列表]          [技术指标]           [特征组合]
[K线数据]    →      [基本面因子]   →     [特征选择]
[财务数据]          [市场因子]           [特征标准化]
   ↓                    ↓                    ↓
4️⃣ 模型训练          5️⃣ 信号生成          6️⃣ 风险控制
   ↓                    ↓                    ↓
[XGBoost]           [买入信号]           [仓位管理]
[随机森林]    →      [卖出信号]    →      [止损止盈]
[神经网络]          [持仓建议]           [风险评估]
   ↓                    ↓                    ↓
7️⃣ 回测验证          8️⃣ 实盘交易          9️⃣ 绩效分析
   ↓                    ↓                    ↓
[历史回测]          [订单执行]           [收益报告]
[性能评估]    →      [持仓监控]    →      [风险报告]
[参数优化]          [实时调整]           [归因分析]
```

## 详细流程说明

### 阶段1: 数据采集 📊

**目标**: 获取市场数据，建立数据基础

**核心脚本**: 
- `scripts/fetch_hs300_data.py` - 获取沪深300成分股数据
- `quantsys/data/fetchers/klines.py` - K线数据采集器

**数据类型**:
- **股票列表**: 沪深300、中证500等指数成分股
- **K线数据**: 日线、周线、月线（开高低收量）
- **财务数据**: 市盈率、市净率、ROE等基本面指标
- **市场数据**: 北向资金、融资融券、大单流入等

**执行时间**: 每日16:00（收盘后）

**示例命令**:
```bash
# 获取沪深300数据（最近5天）
python3 scripts/fetch_hs300_data.py

# 更新所有A股数据
python3 -c "
from quantsys.data.db import Database
from quantsys.data.fetchers.klines import KlineFetcher
db = Database('~/.pi-invest/stock-db/stocks.db')
fetcher = KlineFetcher(db)
symbols = db.get_all_symbols(market='A')
fetcher.run(symbols=symbols, days=5, market='A')
"
```

**数据存储**:
- 数据库路径: `~/.pi-invest/stock-db/stocks.db`
- 数据规模: 5847只股票、519万条K线、22万条因子记录

### 阶段2: 因子计算 🧮

**目标**: 从原始数据中提取量化因子

**核心脚本**:
- `scripts/calculate_factors.py` - 计算最新因子
- `scripts/calculate_historical_factors.py` - 批量计算历史因子

**因子类型**:

#### 技术指标类 (30+)
- **趋势类**: MA5/10/20/60, EMA, MACD, ADX
- **动量类**: RSI, KDJ, CCI, Williams %R
- **波动类**: ATR, Bollinger Bands, 标准差
- **成交量类**: OBV, Volume Ratio, 量价背离

#### 基本面因子类
- **估值因子**: PE, PB, PS, PCF
- **盈利因子**: ROE, ROA, 净利润增长率
- **成长因子**: 营收增长率、EPS增长率
- **质量因子**: 资产负债率、流动比率

#### 市场因子类
- **资金流向**: 北向资金净买入、大单净流入
- **情绪因子**: 换手率、振幅、涨跌停统计
- **相对强度**: 相对大盘强度、行业相对强度

**执行时间**: 每日16:30（数据更新后）

**示例命令**:
```bash
# 计算最新因子（最近5天）
python3 scripts/calculate_factors.py

# 批量计算历史因子（指定日期范围）
python3 scripts/calculate_historical_factors.py \
  --start-date 2024-01-01 \
  --end-date 2024-12-31

# 分析单只股票的因子
python3 scripts/analyze_stock_factors.py --symbol 000001
```

**输出示例**:

### 阶段3: 特征工程 🔧

**目标**: 将因子转换为机器学习特征

**核心模块**: `quantsys/ml/features/feature_engineering.py`

**特征处理流程**:

1. **特征组合**
   - 单因子特征: 直接使用计算的因子值
   - 交叉特征: MA5/MA20比值、RSI与成交量组合
   - 时序特征: 5日涨幅、20日波动率

2. **特征选择**
   - 相关性分析: 剔除高度相关的冗余特征
   - 重要性排序: 基于模型的特征重要性
   - 稳定性检验: 剔除不稳定的特征

3. **特征标准化**
   - Z-score标准化: (x - μ) / σ
   - Min-Max归一化: (x - min) / (max - min)
   - Robust Scaler: 对异常值鲁棒

**示例代码**:
```python
from quantsys.ml.features.feature_engineering import FeatureEngineer

engineer = FeatureEngineer()

# 生成特征
features = engineer.generate_features(
    symbol='000001',
    date='2024-05-19',
    lookback_days=60
)

# 特征选择
selected_features = engineer.select_features(
    features,
    method='importance',
    top_k=50
)

# 特征标准化
normalized_features = engineer.normalize_features(
    selected_features,
    method='zscore'
)
```

### 阶段4: 模型训练 🤖

**目标**: 训练预测模型，预测股票未来表现

**核心脚本**: `scripts/ml_retrain.py`

**模型类型**:
- **XGBoost**: 主力模型，梯度提升树
- **随机森林**: 集成学习，降低过拟合
- **神经网络**: 深度学习，捕捉非线性关系

**训练流程**:

1. **数据准备**
   - 训练集: 2020-2023年数据（70%）
   - 验证集: 2024年1-6月数据（15%）
   - 测试集: 2024年7-12月数据（15%）

2. **标签定义**
   - 涨跌标签: 未来5日涨幅 > 5% → 1, 否则 → 0
   - 收益标签: 未来5日收益率（回归任务）
   - 风险标签: 未来5日最大回撤

3. **模型训练**
   - 超参数优化: Grid Search / Random Search
   - 交叉验证: 5-Fold时间序列交叉验证
   - 早停策略: 验证集AUC连续10轮不提升则停止

4. **模型评估**
   - 分类指标: AUC, Precision, Recall, F1-Score
   - 回归指标: RMSE, MAE, R²
   - 业务指标: 年化收益率、夏普比率、最大回撤

**执行时间**: 每周日凌晨（或手动触发）

**示例命令**:
```bash
# 训练新模型
python3 scripts/ml_retrain.py \
  --model xgboost \
  --start-date 2020-01-01 \
  --end-date 2024-12-31

# 分析特征重要性

# 模型预测

```

### 阶段5: 信号生成 📡

**目标**: 根据模型预测生成交易信号

**核心脚本**: `scripts/generate_signals.py`

**信号类型**:

1. **买入信号**
   - 模型预测概率 > 0.7
   - RSI < 70（未超买）
   - 成交量放大 > 1.5倍
   - 北向资金净流入

2. **卖出信号**
   - 模型预测概率 < 0.3
   - RSI > 80（超买）
   - 跌破止损线（-8%）
   - 达到止盈目标（+15%）

3. **持仓信号**
   - 0.3 ≤ 预测概率 ≤ 0.7
   - 无明显买卖信号
   - 继续观察

**执行时间**: 每日17:00（因子计算后）

**示例命令**:
```bash
# 生成今日信号
python3 scripts/generate_signals.py

# 生成指定日期信号
python3 scripts/generate_signals.py --date 2024-05-19

# 查看信号详情
python3 -c "
from quantsys.signals.generator import SignalGenerator
gen = SignalGenerator()
signals = gen.get_latest_signals()
for s in signals[:10]:
    print(f'{s.symbol} {s.signal_type} {s.confidence:.2f}')
"
```

### 阶段6: 风险控制 🛡️

**目标**: 控制投资组合风险，保护资金安全

**核心脚本**: `scripts/risk_check.py`

**风险控制维度**:

1. **仓位管理**
   - 单只股票: ≤ 10%
   - 单个行业: ≤ 30%
   - 总仓位: 60-80%（根据市场环境调整）

2. **止损止盈**
   - 个股止损: -8%
   - 个股止盈: +15%
   - 组合止损: -5%（单日）

3. **风险指标**
   - VaR (Value at Risk): 95%置信度下的最大损失
   - 最大回撤: 历史最大跌幅
   - 夏普比率: 风险调整后收益
   - Beta系数: 相对市场的波动性

4. **风险预警**
   - 🔴 高风险: VaR > 5%, 立即减仓
   - 🟡 中风险: 3% < VaR ≤ 5%, 谨慎操作
   - 🟢 低风险: VaR ≤ 3%, 正常操作

**示例命令**:
```bash
# 风险检查
python3 scripts/risk_check.py

# 查看风险报告
python3 -c "
from quantsys.risk.manager import RiskManager
rm = RiskManager()
report = rm.generate_risk_report()
print(report)
"
```

### 阶段8: 实盘交易 💼

**目标**: 执行交易信号，管理持仓

**核心功能**:
- 订单执行: 市价单、限价单
- 持仓监控: 实时盈亏、风险预警
- 自动调仓: 根据信号自动买卖

**交易流程**:

1. **开盘前（9:00-9:25）**
   - 查看昨日信号
   - 制定交易计划
   - 设置委托单

2. **盘中监控（9:30-15:00）**
   - 监控持仓盈亏
   - 触发止损止盈
   - 调整仓位

3. **收盘后（15:00-17:00）**
   - 更新数据
   - 计算因子
   - 生成明日信号

**风险提示**:
- ⚠️ 实盘交易有风险，建议先模拟盘验证
- ⚠️ 严格执行止损，控制单笔损失
- ⚠️ 不要频繁交易，避免过度交易成本

## 自动化调度 ⏰

系统使用 `scheduler.py` 实现全自动运行：

```python
# 每日任务时间表
16:00 - 数据更新（收盘后）
16:30 - 因子计算
17:00 - 信号生成
17:30 - 风险检查
18:00 - 绩效报告

# 每周任务
周日 00:00 - 模型重训练
周日 02:00 - 策略回测
周日 03:00 - 周报生成
```

**启动调度器**:
```bash
# 前台运行（测试）
python3 scripts/scheduler.py

# 后台运行（生产）
nohup python3 scripts/scheduler.py > logs/scheduler.log 2>&1 &

# 查看日志
tail -f logs/scheduler.log
```

## 常见问题

### Q1: 数据更新失败怎么办？
```bash
# 检查网络连接
curl -I https://xueqiu.com

# 检查数据库
sqlite3 ~/.pi-invest/stock-db/stocks.db "SELECT COUNT(*) FROM stocks;"

# 手动重试
python3 scripts/fetch_hs300_data.py
```

### Q2: 模型预测不准确？
- 检查特征重要性，剔除无效特征
- 增加训练数据量
- 调整模型超参数
- 考虑市场环境变化，定期重训练

### Q3: 回测收益很高，实盘亏损？

- 考虑交易成本和滑点
- 验证信号执行时机
- 检查市场环境是否变化

### Q4: 如何优化策略？
1. 分析失败案例，找出共性
2. 增加新的有效因子
3. 优化止损止盈参数
4. 改进仓位管理策略
5. 结合市场环境动态调整
