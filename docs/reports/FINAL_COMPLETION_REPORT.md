**功能**:

- IR (Information Ratio) 计算
- ICIR综合评价
- IC衰减分析
- 分组IC分析

**业务价值**:
```python
# IC > 0.03 为有效因子
# IR > 1.0 为优秀因子
# ICIR > 0.5 为可用因子

analyzer = ICAnalyzer()
ic = analyzer.calculate_ic(factor_values, forward_returns)
# IC: 0.0523 ✓ 有效因子

ir = analyzer.calculate_ir(ic_series)
# IR: 1.85 ✓ 优秀因子
```

#### 因子正交化 (`orthogonalizer.py` - 195行)

**方法**:
1. **Schmidt正交化**: 保留原始方向
2. **PCA降维**: 提取主成分

**效果**:
- 输入: 50个因子，相关性0.3-0.8
- 输出: 50个正交因子，相关性<0.1
- 或: 10个主成分，解释方差>85%

#### 因子分层回测 (`layering_backtest.py` - 240行)

**功能**:
- 5层/10层分组

**示例结果**:

### 3.2 期权策略框架 (650行)

#### Greeks计算器 (`greeks_calculator.py` - 320行)

**支持指标**:
- **Delta**: 标的价格敏感度
- **Gamma**: Delta敏感度
- **Theta**: 时间衰减
- **Vega**: 波动率敏感度
- **Rho**: 利率敏感度

**额外功能**:
- Black-Scholes定价
- 隐含波动率计算（牛顿法）

**示例**:
```python
greeks = calculator.calculate_all_greeks(
    S=100, K=100, T=0.25, r=0.05, sigma=0.2
)
# Delta: 0.5987 (标的涨1元，期权涨0.60元)
# Gamma: 0.0199 (Delta加速度)
# Theta: -0.0123 (每天损失0.0123)
# Vega: 0.1987 (波动率+1%，价格+0.20)
```

#### Delta中性策略 (`option_strategies.py` - 180行)

**策略逻辑**:
1. 持有期权头寸
2. 用标的资产对冲Delta
3. 保持组合Delta≈0
4. 赚取Gamma和Theta收益

**适用场景**:
- 波动率交易
- 市场中性策略
- 对冲基金核心策略

#### 波动率套利策略 (`option_strategies.py` - 150行)

**策略逻辑**:
1. 比较IV和HV
2. IV > HV: 卖出期权
3. IV < HV: 买入期权
4. Delta对冲保持中性

**示例**:
```
IV: 25.3%, HV: 18.7%
差异: 6.6% (显著高估)
操作: 卖出期权，做空波动率
```
