**状态**: ✅ 完成并验证

---

## 改动内容

### 简化前
- 支持多字段查询：info、price、news、announcements
- 默认查询 info + price
- 复杂的字段组合逻辑
- 代码 211 行

### 简化后
- **仅支持实时行情查询（price）**
- 移除 info、news、announcements 字段
- 代码简化至 162 行（减少 23%）
- 专注于核心功能

---

## 核心特性

### 1. 专注实时行情
```typescript
// 仅一个参数
data_fetch_stock({ symbol: "600519" })
```

### 2. 智能 fallback（保留）
```typescript
source: 'auto'  // 默认：实时失败时自动切换到数据库
```

### 3. 友好错误提示（保留）
非交易时段自动提示：
```
💡 提示：当前非交易时段（A股交易时间：周一至周五 9:30-11:30, 13:00-15:00）。
   实时行情不可用是正常现象。系统已自动尝试返回最近收盘价。
   若需明确指定数据源，可使用 source="db" 参数直接获取数据库数据。
```
