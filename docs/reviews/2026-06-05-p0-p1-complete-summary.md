## 🎯 P0: 高级因子库

### 新增因子（6个）

#### 反转类（3个）
1. **reversal_1d** - 1日反转
   - 公式: -(close[t] - close[t-1]) / close[t-1]
   - 验证结果: ❌ 较差 (3.4/10)
   - 状态: 已实现，但效果不佳

2. **reversal_5d** - 5日反转
   - 公式: -(close[t] - close[t-5]) / close[t-5]
   - 验证结果: ⚠️ 一般 (5.8/10)
   - 状态: 已实现，谨慎使用

3. **overnight_return** - 隔夜收益
   - 公式: (open[t] - close[t-1]) / close[t-1]
   - 验证结果: ⚠️ 一般 (5.8/10)
   - 状态: 已实现，谨慎使用

#### 动量类（3个）
4. **momentum_6m** - 6个月动量
   - 公式: (close[t] - close[t-120]) / close[t-120]
   - 验证结果: ✅ **优秀 (10.0/10)**
   - 多空收益: **0.22%**
   - 状态: **强烈推荐使用**

5. **momentum_52w_high** - 52周最高价距离
   - 公式: (close[t] - high_52w) / high_52w
   - 验证结果: ✅ **优秀 (10.0/10)**
   - 多空收益: **0.27%** (最高)
   - 状态: **强烈推荐使用**

6. **acceleration** - 动量加速度
   - 公式: momentum_20d - momentum_60d
   - 验证结果: ✅ **优秀 (10.0/10)**
   - 多空收益: **0.16%**
   - 状态: **强烈推荐使用**

- **实现率**: 100% (6/6)
- **优秀率**: 50% (3/6)
- **可用率**: 100% (全部可用，但效果不同)

## 🔧 P1: 因子分层回测工具

### 实现内容

#### 后端（Python）
1. **服务层**: `factor_layering_service.py` (450行)
   - `run_layering_backtest()` - 单因子回测
   - `run_batch_layering_backtest()` - 批量回测
   - `_prepare_factor_data()` - 因子数据准备（滑动窗口）
   - `_prepare_return_data()` - 收益率数据准备

2. **API端点**: `api/routes/backtest.py` (+110行)
   - `POST /api/backtest/factor-layering` - 单因子回测
   - `POST /api/backtest/factor-layering/batch` - 批量回测

#### 前端（TypeScript）
3. **工具层**: 2个工具 (+380行)
   - `factor_layering_backtest` - 单因子回测工具
   - `batch_factor_layering_backtest` - 批量回测工具

4. **工具注册**: `tools/index.ts` (+4行)

#### 测试
5. **单元测试**: `test_factor_layering_service.py` (30行)
   - 基础结构验证
   - 方法存在性测试

### 核心功能

1. **分层回测**
   - 按因子值分N层（默认10层）
   - 计算每层平均收益、夏普比率、胜率
   - 计算多空组合收益（最高层 - 最低层）

2. **单调性检查**
   - 验证因子值与收益的单调关系
   - 单调性得分（0-100%）

3. **IC统计**
   - IC均值、标准差、IR
   - IC正比率

4. **有效性评分**
   - 综合评分（0-10分）
   - 评分权重: 单调性30% + 收益30% + 夏普40%

1. **复用现有组件**
   - 复用 `FactorLayeringBacktest` 和 `ICAnalyzer`
   - 节省了大量开发时间

2. **清晰的架构**
