## 核心功能

### CompositeScorer 类

整合技术面和基本面评分器，提供统一的综合评分接口。

**主要方法**:
```python
def score(technical_factors, fundamental_data, strategy='balanced')
```

**返回结果**:
- 综合评分 (0-100)
- 评级 (A+/A/B+/B/C/D)
- 投资建议（基于协同性分析）
- 详细分项明细

---

## 5种评分策略

| 策略 | 技术面 | 基本面 | 适用场景 |
|------|-------|-------|---------|
| **balanced** | 50% | 50% | 平衡策略，通用 |
| **technical_focus** | 70% | 30% | 短线交易 |
| **fundamental_focus** | 30% | 70% | 长线投资 |
| **aggressive** | 80% | 20% | 波段操作 |
| **conservative** | 20% | 80% | 价值投资 |

### 策略选择建议

**根据投资风格**:
- 短线交易者 → technical_focus / aggressive
- 中线交易者 → balanced
- 长线投资者 → fundamental_focus / conservative
- 价值投资者 → conservative

**根据市场环境**:
- 牛市 → technical_focus
- 熊市 → fundamental_focus
- 震荡市 → balanced

## 协同性分析

CompositeScorer 不仅计算综合评分，还分析技术面和基本面的协同性：

**高度协同**（分差 ≤ 10分）:
- 双重确认，信号可靠
- 示例：技术90 + 基本85

**较为协同**（分差 10-20分）:
- 基本一致，可接受

**不协同**（分差 > 20分）:
- 需警惕，一强一弱
- 技术强 → 注意基本面风险
- 基本强 → 等待技术确认

## 技术实现

### CompositeScorer 架构

```
CompositeScorer
├── TechnicalScorer      # 技术面评分
├── FundamentalScorer    # 基本面评分
├── _get_weights()       # 策略权重映射
├── _calculate_rating()  # 评级计算
└── _generate_recommendation()  # 建议生成
```

### 评分流程

1. 调用 TechnicalScorer 计算技术面评分
2. 调用 FundamentalScorer 计算基本面评分
3. 根据策略计算加权综合评分
4. 分析协同性
5. 生成评级和建议

```python

scorer = CompositeScorer()

    technical_factors={...},
```
