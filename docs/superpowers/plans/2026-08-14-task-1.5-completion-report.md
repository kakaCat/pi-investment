## 🔧 已修复的问题

### 1. ES 模块 `__dirname` 不可用
**问题**: `__dirname` 在 ES 模块中未定义  
**修复**: 使用 `fileURLToPath(import.meta.url)` 计算

### 2. 环境变量加载时机
**问题**: 模块加载时 `process.env` 为空（dotenv 尚未执行）  
**修复**: 延迟路径计算，在函数内部读取环境变量

### 3. Agent OS CLI 参数不匹配
**问题**: 假设的参数与实际 CLI 不符  
**修复**: 
- `--min-score` → `--min-importance`
- `--content` 不需要 JSON.stringify
- 添加 `--json` 标志
- 添加 `--category` 参数

### 4. 工作目录问题
**问题**: CLI 找不到 `config.yaml`  
**修复**: 在 Agent OS 根目录下执行命令（`cwd: agentOSDir`）

### 5. 编译路径计算错误
**问题**: `dist/` 目录导致相对路径偏移  
**修复**: 优先使用环境变量，降级才使用相对路径

### Namespace 不存在

**症状**:
```
Error: namespace not found: system
```

**原因**: Agent OS 数据库中 namespace 表为空（尽管 `resource namespace list` 显示有 4 个）

**解决方案** (二选一):

#### 方案 A: 重新初始化 Agent OS 数据库
```bash
cd /Users/yunpeng/pi-investment/agent-os
dropdb agent_os
createdb agent_os
psql agent_os < schema.sql
```

#### 方案 B: 创建缺失的 namespace
```bash
cd /Users/yunpeng/pi-investment/agent-os
./agent-os resource namespace create --name system --description "System namespace"
```

#### 方案 C: 修改代码使用已存在的 namespace
检查实际数据库中的 namespace:
```sql
SELECT * FROM namespaces;
```

如果 `fin-agent` 存在，修改默认映射使用它。
