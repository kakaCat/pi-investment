# 多数据源实时行情端到端测试报告

**测试日期**: 2026-05-29
**测试环境**: 本地开发环境
**测试股票**: 600900.SH (长江电力)

## 测试场景

### 1. 实时数据获取（默认）
- **命令**: `curl "http://127.0.0.1:5001/api/stock/600900/quote"`
- **结果**: ⚠️ 实时数据源不可用（预期行为，非交易时段）
- **验证**: 返回错误信息 "无法获取 600900 的实时行情"
- **说明**: 非交易时段或网络限制导致实时数据源不可用，符合预期

### 2. 实时数据获取（显式指定）
- **命令**: `curl "http://127.0.0.1:5001/api/stock/600900/quote?source=realtime"`
- **结果**: ⚠️ 实时数据源不可用（预期行为）
- **验证**: 与默认行为一致，返回相同错误信息
- **说明**: 显式指定 realtime 时不会 fallback 到数据库

### 3. 数据库查询
- **命令**: `curl "http://127.0.0.1:5001/api/stock/600900/quote?source=db"`
- **结果**: ✅ 成功
- **返回数据**:
  ```json
  {
    "symbol": "600900",
    "name": "长江电力",
    "price": 27.24,
    "changePct": 0.0,
    "open": 27.06,
    "high": 27.33,
    "low": 27.01,
    "volume": 1112715.0,
    "tradeDate": "2026-05-27",
    "source": "db_fallback"
  }
  ```
- **验证**: 
  - ✅ source 字段为 "db_fallback"
  - ✅ 包含 tradeDate 字段（数据库数据特征）
  - ✅ 数据完整，包含价格、涨跌幅、成交量等字段

### 4. Auto Fallback
- **命令**: `curl "http://127.0.0.1:5001/api/stock/600900/quote?source=auto"`
- **结果**: ✅ 成功
- **返回数据**: 与 Test 3 相同（fallback 到数据库）
- **验证**: 
  - ✅ 实时数据不可用时自动 fallback 到数据库
  - ✅ source 字段为 "db_fallback"
  - ✅ 数据与 db 模式一致
- **说明**: auto 模式优先尝试实时数据，失败时自动降级到数据库

### 5. 参数验证
- **命令**: `curl "http://127.0.0.1:5001/api/stock/600900/quote?source=invalid"`
- **结果**: ✅ 成功
- **返回错误**: "Invalid source parameter: invalid. Must be one of: realtime, db, auto"
- **验证**: 
  - ✅ 返回 400 错误
  - ✅ 错误信息清晰，列出所有有效选项
  - ✅ 参数验证正常工作

## 测试总结

### 功能验证
- ✅ 数据库查询功能正常
- ✅ Auto fallback 机制正常
- ✅ 参数验证正常
- ⚠️ 实时数据源在非交易时段不可用（预期行为）

### 数据源行为
| 模式 | 行为 | 结果 |
|------|------|------|
| realtime (默认) | 仅尝试实时数据源 | 失败时返回错误 |
| realtime (显式) | 仅尝试实时数据源 | 失败时返回错误 |
| db | 仅查询数据库 | 成功返回历史数据 |
