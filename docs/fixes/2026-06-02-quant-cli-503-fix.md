# Fix: quant_cli 503 错误修复

**日期**: 2026-06-02  
**问题**: 多个 `quant_cli` 命令返回 HTTP 503 错误："No module named 'quantsys'"

## 问题根源

quantsys-v2 后端的某些 API 端点尝试导入不存在的 v1 `quantsys` 模块：

```python
# quantsys-v2/api/routes/analysis.py
sys.path.insert(0, str(_V2_ROOT.parent / 'quant'))
from quantsys.cli.analysis_query import analyze_price_action  # 失败：模块不存在
```

v1 `quantsys` 模块已被废弃并移除，但 v2 的这些端点尚未完成原生实现，仍依赖 v1 代码。

## 受影响的命令

以下 `quant_cli` 命令会触发 503 错误：

1. `financial.pe_percentile` - PE历史分位数
2. `sentiment.stock_fund_flow` - 个股资金流向
3. `sentiment.margin_data` - 融资融券数据
4. `sentiment.fund_holdings` - 基金持仓
5. `sentiment.top_fund_stocks` - 基金重仓股
6. `sentiment.top_holders` - 前十大股东
7. `sentiment.holder_changes` - 股东人数变化
8. `sentiment.insider_trades` - 高管增减持
9. `market.sentiment` - 市场情绪
10. `stock.score` - 股票综合评分
11. `stock.screen` - 股票筛选

## 解决方案

### 1. 移除 V2_ROUTES 映射

**文件**: `src/infrastructure/quant/quant-v2-client.ts`

从 `V2_ROUTES` 映射表中注释掉所有未实现的端点，添加说明：

```typescript
// ── sentiment ──
// "sentiment.stock_fund_flow": { path: "/api/stock/{symbol}/fund-flow", method: "GET" },  // 未实现 - 依赖 v1 quantsys 模块
// "sentiment.margin_data": { path: "/api/stock/{symbol}/margin", method: "GET" },  // 未实现 - 依赖 v1 quantsys 模块
```

### 2. 标记命令为已弃用

**文件**: `src/infrastructure/tools/core/quant-cli-tool.ts`

更新命令定义，添加 `deprecated: true` 和清晰的错误消息：

```typescript
"market.sentiment": {
  domain: "market",
  action: "sentiment",
  description: "⚠️ 暂不可用：v2 端点依赖 v1 quantsys 模块（已废弃），等待 v2 原生实现。",
  params: {},
  example: {},
  deprecated: true,
  replacement: "市场情绪分析功能暂不可用，等待 v2 实现",
},
```

## 修复后的行为

**修复前**:
```
quant_cli({ command: "market.sentiment" })
→ HTTP 503: {"error":"Module not available: No module named 'quantsys'","success":false}
```

**修复后**:
```
quant_cli({ command: "market.sentiment" })
→ QuantV2Error: 命令 market.sentiment 没有 v2 端点映射
```

## 影响

- ✅ **用户体验改善**: 错误消息更清晰，明确说明功能未实现
- ✅ **避免混淆**: 不再返回误导性的 503 服务不可用错误
- ✅ **文档化**: 通过 `deprecated` 标记明确哪些功能不可用
- ⚠️ **功能缺失**: 这些命令暂时无法使用，需要等待 v2 原生实现
