## 根因与代码修复

1. **信号回填**：原工具/客户端有 30 秒 Axios 超时，旧实现逐信号、逐窗口查交易日历和 K 线，目标日缺 K 时静默 `updated=0`。现改为整次共享交易日历、一次批量 K 线查询、精确目标日收盘；默认扫全部历史 NULL 欠账，显式 `lookback_days` 才限下界。返回 `not_due/missing_kline/invalid_signal/blocked/complete`。`refresh=True` 仅允许带 `signal_date` 或 `symbol` 的受控重算，目标日缺 K 不清空旧值。工具与客户端超时均为 60 秒。
2. **重复调度**：内置 `SIGNAL_JOBS` 不再重复注册回填任务；生产调度只走 Agent OS webhook。到期欠账未完整时任务显式失败，不再假报成功。
3. **watch 留痕**：终态 PATCH 与 `agent_response` 同事务写入，JSONB 合并保留通知审计字段；D-31 待办关闭与触发终态同步具备事务性，触发写失败时待办回滚。非终态不写裁决。
4. **K 线修复**：正常回填路径及优先级不变；新增显式 `force` 修复，必须指定 symbols（单次至多 20），DB 旁路读取两个独立网络源，精确日期、OHLC/量一致才写并读回核验。分歧、缺源、日期不符、读失败均零写入。日级数据写入口过滤盘中日 bar；修复转换保留 `source`，严格读采用 fail-fast。
