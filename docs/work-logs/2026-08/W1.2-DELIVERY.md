## 二、核心设计

### 证据链门禁 ("No Execution, No Memory")
```python
def validate_evidence_gate(self) -> bool:
    """evidence 非空才能 status >= testing"""
    if self.status in [MemoryStatus.TESTING, MemoryStatus.ACTIVE]:
        if not self.evidence or not any(self.evidence.values()):
            return False
    return True
```

**规则**:
- `status=active` 或 `status=testing` 时，`evidence` 必须非空
- `status=deprecated` 或 `status=archived` 不受限制
- 违反规则抛出 `ValueError: "No Execution, No Memory"`

### 置信度爬坡
```python
if validation_count < 10:
    confidence = 0.3
elif validation_count < 30:
    confidence = 0.5
else:
    confidence = 0.7
```

### 记忆类型 (kind)
- `rule`: 规则/原则（蒸馏产出，需人工确认）
- `episode`: 情节记忆（完整叙事，如 v13 复盘）
- `experience`: 经验（结构化，条件→动作）
- `stock_note`: 个股笔记

### 记忆状态 (status)
- `testing`: 测试中（候选规则，需验证）
- `active`: 激活（生产使用）
- `deprecated`: 废弃（被更好规则替代）
- `archived`: 归档（历史参考）

### 范围 (scope)
- `global`: 全局记忆
- `stock:600519`: 个股记忆
- `strategy:v13`: 策略记忆
- `sector:消费`: 行业记忆
