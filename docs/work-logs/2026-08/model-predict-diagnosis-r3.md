## 1. 问题描述

**现象**：`model_predict` 工具对不同股票返回近乎恒等的预测值，无区分度。

**实测证据**（2026-08-20）：
```
model_predict(002241)  # 歌尔股份
→ prediction: 0.4659, confidence: low

model_predict(600737)  # 中粮糖业
→ prediction: 0.4659, confidence: low
```

两只完全不同的股票（消费电子 vs 白糖）返回相同预测值 0.4659，说明模型已退化为常数函数。

---

## 2. 根因定位

### 2.1 模型陈旧（2.5 个月未更新）

**发现**：
- 当前使用的模型文件最后训练时间：**2026-06-03**
- 诊断时间：2026-08-20
- 时间差：**78 天（约 2.5 个月）**

**影响**：
- 市场环境已显著变化（6 月震荡 → 8 月恐慌底 → 反弹）
- 模型训练时的特征分布与当前数据脱节
- 模型默认回退到"无信息"的 0.5 附近常数预测

### 2.2 特征污染

**发现**：模型特征管道中存在数据泄露或失效特征。

**可能原因**（待进一步排查）：
1. **未来数据泄露**：训练时使用了包含未来信息的特征（如 T 日预测用了 T+1 的数据）
2. **S3 因子管线问题**：训练时使用的大写因子（RSI12/MACD 等）在 2026-05-20 后冻结，导致训练样本与推理样本特征不一致
3. **特征缺失处理不当**：推理时遇到缺失值填充策略与训练时不同

**AUC 验证**：
```
模型在最近数据上的 AUC = 0.468
```
- AUC < 0.5 说明模型还不如随机猜测（0.5）
- 这通常是特征泄露或标签错误的标志

### 2.3 默认模型兜底机制

**代码层发现**：`model_predict` 在检测到模型性能过低（如 confidence < threshold）时，会启用"安全模式"返回无信息预测（0.5 附近 + low confidence）。

当前正是该机制生效，避免了误导性预测，但也说明底层模型已失效。

## 4. 解决方案

### 短期（M8-1 完成即可用）

1. **训练新模型**：使用 M0-2 回填的新管线因子（ma5/ma10/rsi14 等小写因子，230 交易日历史）
2. **剔除冻结因子**：确保训练特征集中无大写因子（RSI12/MACD/MA60 等）
3. **特征-标签时间对齐**：严格检查特征日期 < 标签日期，防止未来数据泄露
4. **上线门禁**（M8-2）：AUC > 0.55 且 IR > 0 才允许上线

### 长期（Phase 3 完整方案）

1. **模型训练自动化**：每周/每月自动重训，避免陈旧
2. **特征工程重构**：基于新因子管线构建稳健特征集
3. **在线监控**：持续跟踪 AUC/IC 指标，低于阈值自动告警
4. **A/B 测试**：新模型先在影子模式运行，验证后再替换
