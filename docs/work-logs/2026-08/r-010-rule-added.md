### 2. R-010 规则内容

```markdown
## R-010 任务完成通知
重要任务完成后调用 feishu_notify 主动通知用户，让用户及时知晓工作成果。
触发条件：
①完成 M*/P*/Sprint/Phase 编号任务
②系统组件首次上线
③关键验收通过/失败
④发现重大问题需立即通知

通知内容：核心成果、关键数据、相关文档链接、下一步计划
urgency 选择：normal（一般完成）/ high（关键里程碑、紧急问题）
channel 选择：reports（日常汇报）/ alerts（告警）

不需要通知的情况：日常小修小补、中间调试过程（非最终交付）、纯代码重构
```

## 背景：为什么需要 R-010？

### 问题

- M1 市场感知自动化验证 (17:08)
- M3-2 回测矩阵引擎完成 (13:36)
- M6 周报自动化完成 (13:46)

但用户没有收到任何飞书通知。

### 根本原因

**不是技术问题**，是**流程缺失**：
1. ✅ 飞书 webhook 配置正常
2. ✅ `feishu_notify` 工具可用
3. ❌ **Agent 没有主动通知的习惯** - 完成任务后只写文档，不发通知

### 解决方案

将"任务完成→发通知"写入基因组规则，让 Agent 养成主动汇报的习惯。
