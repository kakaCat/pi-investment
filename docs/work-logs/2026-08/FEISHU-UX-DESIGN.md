## 💻 Agent OS CLI 体验

### 当前设计（WP-6）

```bash
# 发送到交易群
agent-os notify send --user yunpeng --title "测试" --message "内容"

# 发送到告警群
agent-os notify send --channel alerts --title "告警" --message "风险"
```

### 优化后设计（推荐）

```bash
# 统一接口
agent-os notify send --target trading --title "交易信号" --message "..."
agent-os notify send --target alerts --title "风险告警" --message "..."

# 或者更语义化
agent-os notify trading "交易信号" "买入 600519.SH"
agent-os notify alerts "风险告警" "止损触发"

# 支持不同消息类型
agent-os notify send --target trading --type report --file daily-report.json
agent-os notify send --target alerts --type alert --urgency high --message "..."

# 列出所有目标
agent-os notify list-targets
# 输出:
# trading  - 交易群 (https://...xxx)
# alerts   - 告警群 (https://...yyy)
# reports  - 报告群 (https://...zzz)
```

## 🔧 Agent-ts 集成体验

### 场景 1: 在代码中发送通知

```typescript
import { getFeishuService } from './services/feishu-notification.service.js';

const feishu = getFeishuService();

// 发送每日报告
await feishu.sendDailyReport({
  date: '2026-08-14',
  total_assets: 1050000,
  cash: 79500,
  holdings_count: 11,
  total_pnl: 50000,
  total_pnl_pct: 5.0,

  sell_count: 1,
  key_findings: '白酒板块表现强劲，科技板块调整'
});

// 发送交易信号
await feishu.sendAlert({
  title: '🚨 交易信号触发',
  content: `**股票**: 600519.SH 贵州茅台
**信号**: 买入信号
**价格**: ¥1,205.00
**置信度**: 82%`,
  urgency: 'high'
});

// 发送自定义卡片
await feishu.sendCard({

  content: `**股票**: 600519.SH

**价格**: ¥1,205.00`
});
```

## ✅ 最终答案

### 应该做成什么样子？

**用户视角**:
1. **想聊天** → 私聊或 @ Pi Investment Bot → 问答交互
2. **想接收通知** → 拉机器人入群 → 自动收到报告/告警

**开发者视角**:
1. **双向对话** → App Token + WebSocket → `agent-ts/src/api/feishu.ts`
2. **单向通知** → Webhook + HTTP → `agent-os notify` + `feishu-notification.service.ts`

**核心原则**:
- ✅ 两种机制，各司其职
- ✅ 用户体验简单直观
- ✅ 开发接口清晰易用
- ✅ 配置灵活可扩展
