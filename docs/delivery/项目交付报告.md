### 快速开始

```bash
# 1. 启动服务
cd quantsys-v2
python api/server.py

# 2. 测试API
curl http://localhost:5001/api/health

# 3. 获取市场情绪
curl http://localhost:5001/api/market/sentiment

# 4. 筛选股票
curl "http://localhost:5001/api/stocks/screen?max_pe=20&limit=10"
```
