```
┌─────────────────────────────────────────┐
│      量化投资决策支持系统 v2.0           │
└─────────────────────────────────────────┘
           │
           ├─ 市场环境分析
           │   └─ market.sentiment (市场情绪)
           │
           ├─ 股票筛选
           │   └─ stock.screen (多条件筛选)
           │
           ├─ 个股分析
           │   ├─ stock.score (综合评分)
           │   ├─ stock_fund_flow (资金流向)
           │   ├─ pe_percentile (估值判断)
           │   └─ margin_data (杠杆水平)
           │
           └─ 投资决策
               └─ 综合研判 → 买入/持有/卖出
```

### 完整投资流程

```
第一步: 市场环境判断
└─ market.sentiment → 判断市场阶段和情绪

第二步: 股票初筛
└─ stock.screen → 批量筛选符合条件的股票

第三步: 综合评分
└─ stock.score → 对筛选结果进行详细评分

第四步: 资金确认
└─ stock_fund_flow → 确认主力资金流入

第五步: 估值判断
└─ pe_percentile → 判断是否处于估值低位

第六步: 杠杆分析
└─ margin_data → 查看融资融券情况

第七步: 投资决策
└─ 综合分析 → 制定投资策略
```

## 🎓 应用示例

### 场景1: 寻找优质价值股

```python
# 第一步: 批量筛选
screen_result = stock_screen(
    max_pe=15,           # PE<15
    min_roe=0.15,        # ROE>15%
    max_debt_ratio=0.3,  # 负债率<30%
    limit=20
)

# 第二步: 逐个分析
for stock in screen_result['stocks']:
    # 综合评分
    score = stock_score(stock['symbol'])
    
    # 资金流向
    flow = stock_fund_flow(stock['symbol'])
    
    # 估值判断
    pe_pct = pe_percentile(stock['symbol'])
    
    # 综合判断
    if (score['total_score'] > 70 and
        flow['summary']['trend'] == 'inflow' and
        pe_pct['percentile'] < 30):
        print(f"✓ 优质价值股: {stock['name']}")
```

### 场景2: 市场择时

```python
# 判断市场环境
sentiment = market_sentiment()

if sentiment['sentiment_level'] == 'extreme_fear':
    # 市场恐慌，寻找超跌机会
    candidates = stock_screen(
        max_pe=10,
        min_roe=0.20,
        sort_by='pe'
    )
    print("市场恐慌，关注低估优质股")

elif sentiment['sentiment_level'] == 'extreme_greed':
    # 市场贪婪，注意风险
    print("市场过热，谨慎操作，逢高减仓")
```

### 场景3: 资金流向策略

```python
# 寻找资金持续流入的股票
screen_result = stock_screen(min_score=60, limit=50)

strong_inflow_stocks = []

for stock in screen_result['stocks']:
    flow = stock_fund_flow(stock['symbol'], days=10)
    
    if (flow['summary']['consecutive_inflow_days'] >= 5 and
        flow['summary']['total_main_net_inflow'] > 10000):
        # 连续5天流入 且 累计>1亿
        strong_inflow_stocks.append({

            'name': stock['name'],
            'flow': flow['summary']
        })
```
