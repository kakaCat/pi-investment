## 🚀 功能详解

### 1. stock.score - 股票综合评分 ⭐⭐⭐⭐⭐

**评分维度**:
- 技术面 40%: RSI, MACD, 均线, 布林带
- 基本面 30%: PE, ROE, 负债率, PB
- 动量 20%: 涨跌幅, 成交量, 连续上涨
- 质量 10%: 毛利率, 净利率, 现金流

**创新点**:
- ✅ 配置驱动 (权重可调)
- ✅ 7个等级 (A+ → D)
- ✅ 5种信号
- ✅ <100ms响应

**配置文件**: `config/scoring_config.py` (126行)

### 2. sentiment.stock_fund_flow - 资金流向 ⭐⭐⭐⭐

**分析维度**:
- 主力行为: 流向强度和持续性
- 资金结构: 机构 vs 散户
- 流向强度: 极高/高/中/低
- 趋势稳定性: 稳定/初现/不稳

**数据内容**:
- 主力/超大单/大单/中单/小单净流入
- 金额(万元) + 占比(%)

**优化**:
- ✅ 代理自动管理
- ✅ 3次重试 (指数退避)
- ✅ 备用数据源

### 4. market.sentiment - 市场情绪 ⭐⭐⭐⭐

**分析指标** (5个维度):
1. 涨跌家数比
2. 成交量变化
3. 指数表现
4. 市场波动率
5. 新高新低比

**情绪评级** (7级):
- extreme_greed → extreme_fear

**市场阶段**:
- 牛市/复苏/整固/调整/熊市

**输出示例**:
```json
{
  "sentimentScore": 60.0,
  "sentimentLevel": "neutral_positive",
  "fearGreedIndex": 60.0,
  "marketPhase": "recovery",
  "recommendation": "市场偏乐观，可适量参与"
}
```

### 5. sentiment.margin_data - 融资融券 ⭐⭐⭐ 🆕

## 💡 完整分析体系

### 四位一体分析框架

```
┌─────────────────────────────────────┐
│         量化投资决策支持系统          │
└─────────────────────────────────────┘
           │
           ├─ 个股分析
           │   ├─ stock.score (综合评分)
           │   ├─ stock_fund_flow (资金流向)
           │   ├─ pe_percentile (估值判断)
           │   └─ margin_data (杠杆水平)
           │
           └─ 市场分析
               └─ market.sentiment (市场情绪)
```

### 实际应用流程

```
第一步: 市场环境判断
└─ market.sentiment → 确定当前市场阶段

第二步: 个股筛选
└─ stock.score → 筛选高分股票

第三步: 资金确认
└─ stock_fund_flow → 确认主力资金流入

第四步: 估值判断
└─ pe_percentile → 判断是否低估

第五步: 杠杆分析
└─ margin_data → 查看融资情况

第六步: 投资决策
└─ 综合判断 → 买入/观望/回避
```

## 📈 技术架构

### 分层设计

```
┌─────────────────────────────────────┐
│         API Layer (Routes)          │
│  analysis.py, sentiment.py, etc.   │
└─────────────────────────────────────┘
               ↓
┌─────────────────────────────────────┐
│      Business Logic (Services)      │
│  ScoringService, SentimentService   │
└─────────────────────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Data Access (Repositories + DS)   │
│  FactorRepo, FundFlowSource, etc.  │
└─────────────────────────────────────┘
```

### 设计模式

**策略模式**: 多数据源策略
```python
sources = [
    EastMoneySource(),    # 主数据源
    SimulatedSource(),    # 备用数据源
]
```

**配置驱动**: 评分系统
```python
config = SCORING_CONFIG
service = ConfigurableScoringService(config)
```

**工厂模式**: 数据源创建
```python
class DataSourceFactory:
    @staticmethod
    def create(type):
        if type == 'fund_flow':
            return FundFlowDataSource()
        elif type == 'margin':
            return MarginDataSource()
```
