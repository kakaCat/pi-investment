## 🔧 Part 1: 问题诊断与修复

### 问题发现

多个 `quant_cli` 命令返回 503 错误：
```json
{
  "error": "Module not available: No module named 'quantsys'",
  "success": false
}
```

### 根本原因

quantsys-v2 后端的某些端点尝试导入已废弃的 v1 `quantsys` 模块：
```python
# quantsys-v2/api/routes/analysis.py (旧代码)
sys.path.insert(0, str(_V2_ROOT.parent / 'quant'))
from quantsys.cli.analysis_query import analyze_price_action  # ❌ 模块不存在
```

### 解决方案

1. **临时修复**: 从 V2_ROUTES 中移除未实现的端点
2. **永久方案**: 实现 v2 原生版本

**影响的命令** (11个):
- financial.pe_percentile
- sentiment.stock_fund_flow
- sentiment.margin_data
- sentiment.fund_holdings
- sentiment.top_fund_stocks
- sentiment.top_holders
- sentiment.holder_changes
- sentiment.insider_trades
- market.sentiment
- stock.score
- stock.screen

## 💡 技术亮点

### 1. 分层架构

```
Routes (API层)
    ↓
Services (业务逻辑层)
    ↓
DataSources (数据获取层) + Repositories (数据访问层)
```

- **解耦**: 各层职责清晰
- **可测试**: 每层可独立测试
- **可扩展**: 新增功能无需修改现有代码

### 2. 策略模式

**数据源策略**:
```python
sources = [
    EastMoneyFundFlowSource(),  # 主数据源
    AkShareFundFlowSource(),    # 备用数据源
]
```

**配置驱动策略**:
```python
# 从配置文件加载规则
config = TECHNICAL_SCORING['rsi']
for rule in config['rules']:
    # 应用规则
```

### 3. 容错机制

- 重试机制 (3次，指数退避)
- 优雅降级 (备用数据源)
- 详细日志 (每次尝试都记录)
- 错误恢复 (代理设置自动恢复)

### 4. 配置化设计

- 权重可配置
- 规则可配置
- 等级可配置
- 无需修改代码

**stock.score** 提供多维度评分：
- 快速筛选优质股票
- 识别买入/卖出信号
- 综合技术面和基本面

### 2. 资金追踪

**sentiment.stock_fund_flow** 提供资金分析：
- 追踪主力资金动向
- 识别机构吸筹/出货
- 判断资金流向趋势

### 3. 估值判断

**financial.pe_percentile** 提供估值参考：
- 判断是否低估/高估
- 识别买入时机
- 制定定投策略

### 组合使用

```
1. 用 stock.score 筛选高分股票
2. 用 sentiment.stock_fund_flow 确认资金流入
3. 用 financial.pe_percentile 判断估值合理
→ 找到优质且低估的股票
```
