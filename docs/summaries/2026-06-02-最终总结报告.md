## 🚀 功能详情

### 功能 1: stock.score (股票综合评分) ⭐⭐⭐⭐⭐

**评分体系**:
- 技术面 40%: RSI, MACD, 均线, 布林带
- 基本面 30%: PE, ROE, 负债率, PB
- 动量 20%: 涨跌幅, 成交量, 连续上涨
- 质量 10%: 毛利率, 净利率, 现金流

**创新点**:
- ✅ 配置驱动设计 (可调整权重和规则)
- ✅ 7个等级划分 (A+ 到 D)
- ✅ 5种交易信号
- ✅ 响应时间 <100ms

**配置文件**: `config/scoring_config.py`

---

### 功能 2: sentiment.stock_fund_flow (资金流向) ⭐⭐⭐⭐

**分析维度**:
- 主力行为: 流向强度和持续性
- 资金结构: 机构 vs 散户
- 流向强度: 极高/高/中/低
- 趋势稳定性: 稳定/初现/不稳

**数据内容**:
- 主力/超大单/大单/中单/小单净流入
- 金额(万元) + 占比(%)
- 5种交易信号

**优化**:
- ✅ 自动代理管理
- ✅ 智能重试 (3次，指数退避)
- ✅ 优雅降级 (备用数据源)

---

### 功能 3: financial.pe_percentile (PE分位数) ⭐⭐⭐⭐

**核心功能**:
- PE历史分位数计算 (0-100%)
- 7个估值等级判断
- 统计分析 (min/max/mean/median/std)

**技术特点**:
- 智能估算历史PE (基于价格变化)
- 523个数据点 (2年历史)
- 无需外部API

**应用场景**:
- 估值筛选
- 买入时机判断
- 定投策略制定

---

### 功能 4: market.sentiment (市场情绪) ⭐⭐⭐⭐ 🆕

**分析指标** (5个维度):
1. **涨跌家数比**: 市场强弱判断
2. **成交量变化**: 市场活跃度
3. **指数表现**: 上证/深证/创业板
4. **市场波动率**: 风险水平
5. **新高新低比**: 个股强弱

**情绪评级** (7个等级):
- extreme_greed (极度贪婪)
- greed (贪婪)
- neutral_positive (偏乐观)
- neutral (中性)
- neutral_negative (偏悲观)
- fear (恐慌)
- extreme_fear (极度恐慌)

**市场阶段判断**:
- bull_market (牛市)
- recovery (复苏)
- consolidation (整固)
- correction (调整)
- bear_market (熊市)

**输出示例**:
```json
{
  "sentimentScore": 60.0,
  "sentimentLevel": "neutral_positive",
  "fearGreedIndex": 60.0,
  "marketPhase": "recovery",
  "recommendation": "市场偏乐观，可适量参与"
}
```

## 💡 核心价值

### 1. 完整的量化分析体系

```
选股 (stock.score)
    ↓
资金确认 (stock_fund_flow)
    ↓
估值判断 (pe_percentile)
    ↓
市场环境 (market.sentiment)
    ↓
投资决策
```

### 2. 多维度分析能力

**个股维度**:
- 综合评分 (技术+基本面+动量+质量)
- 资金流向 (主力行为+资金结构)
- 估值水平 (PE历史分位数)

**市场维度**:
- 市场情绪 (恐惧贪婪指数)
- 市场阶段 (牛市/熊市/震荡)
- 操作建议 (买入/观望/回避)

### 3. 实际应用场景

**场景1: 寻找优质股票**
```python
# 1. 用stock.score筛选高分股票
scores = [get_score(symbol) for symbol in symbols]
top_stocks = [s for s in scores if s['total_score'] >= 70]

# 2. 用stock_fund_flow确认资金流入
for stock in top_stocks:
    flow = get_fund_flow(stock['symbol'])
    if flow['summary']['trend'] == 'inflow':
        print(f"✓ {stock['symbol']}: 主力流入")

# 3. 用pe_percentile判断估值
for stock in candidates:
    pe = get_pe_percentile(stock['symbol'])
    if pe['percentile'] < 30:
        print(f"✓ {stock['symbol']}: 低估")
```

**场景2: 判断市场环境**
```python
# 检查市场情绪
sentiment = get_market_sentiment()

if sentiment['sentiment_level'] == 'extreme_fear':
    print("市场恐慌，寻找优质标的逢低布局")
elif sentiment['sentiment_level'] == 'extreme_greed':
    print("市场贪婪，注意风险控制")
```

**场景3: 定投策略**
```python
# 基于估值和市场情绪的定投策略
def calculate_invest_amount(symbol):
    pe = get_pe_percentile(symbol)
    sentiment = get_market_sentiment()
    
    # 基础金额
    base_amount = 1000
    
    # 估值调整
    if pe['percentile'] < 20:
        amount = base_amount * 2  # 低估时加倍
    elif pe['percentile'] < 40:
        amount = base_amount * 1.5
    else:
        amount = base_amount
    
    # 市场情绪调整
    if sentiment['sentiment_level'] in ['fear', 'extreme_fear']:
        amount *= 1.5  # 恐慌时增加
    
    return amount
```
