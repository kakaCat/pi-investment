## 🚀 核心功能详解

### 1. stock.score - 股票综合评分 ⭐⭐⭐⭐⭐

**4个评分维度** (权重可配置):
- 技术面 40%: RSI, MACD, 均线, 布林带
- 基本面 30%: PE, ROE, 负债率, PB
- 动量 20%: 涨跌幅, 成交量, 连续上涨
- 质量 10%: 毛利率, 净利率, 现金流

**7个等级**: A+ / A / B+ / B / C / D

**5种信号**: 强烈买入 / 买入 / 回避 / 超买 / 超卖

**配置文件**: `config/scoring_config.py` (126行)

---

### 2. sentiment.stock_fund_flow - 资金流向 ⭐⭐⭐⭐

**4个分析维度**:
- 主力行为: 流向强度和持续性
- 资金结构: 机构 vs 散户
- 流向强度: 极高/高/中/低
- 趋势稳定性: 稳定/初现/不稳

**5种交易信号**:
- 强烈流入 → 买入
- 机构吸筹 → 买入
- 机构出货 → 卖出
- 流出预警 → 减仓
- 中性观望 → 持有

---

### 3. financial.pe_percentile - PE分位数 ⭐⭐⭐⭐

**核心功能**:
- PE历史分位数 (0-100%)
- 7个估值等级判断
- 523个历史数据点

**应用场景**:
- 估值筛选
- 买入时机判断
- 定投策略制定

---

### 4. market.sentiment - 市场情绪 ⭐⭐⭐⭐

**5个分析指标**:
1. 涨跌家数比
2. 成交量变化
3. 指数表现
4. 市场波动率
5. 新高新低比

**7个情绪等级**: extreme_greed → extreme_fear

**5个市场阶段**: 牛市/复苏/整固/调整/熊市

---

### 5. sentiment.margin_data - 融资融券 ⭐⭐⭐

**数据内容**:
- 融资余额/买入/偿还
- 融券余额/卖出/偿还
- 融资融券总余额

**分析维度**:
- 融资趋势
- 融券趋势
- 活跃程度
- 变化率

---

### 6. stock.screen - 股票筛选 ⭐⭐⭐⭐

**筛选条件**:
- PE范围
- ROE范围
- 负债率
- 市值范围
- 行业
- 评分
- 排除ST

**5个预设策略**:
- 价值股
- 成长股
- 大盘股
- 低估值
- 高质量
