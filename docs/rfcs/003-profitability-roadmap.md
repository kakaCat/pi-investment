## 1. 目标与诚实的边界

**目标**：让 PI Investment 系统具备**可持续的、可证明的**股市盈利能力。

**盈利公式（乘法关系，任一为零则结果为零）**：

```
盈利 = 数据地基 × 策略优势 × 风控纪律 × 反馈学习
```

**诚实声明**：不承诺稳赚。股市是零和博弈，对手是散户、游资、机构和其他量化。本路线图承诺的是：提高胜率、纪律与迭代速度；任何阶段达不到验收标准就不进入下一阶段，绝不拿真金白银赌未验证的策略。

## 3. 分阶段路线图

### Phase 1 — 数据地基 🧱 〔当前阶段〕

**目标**：消除误导性数据，为 ML 积累足够历史。

- [x] 1.1 API 层过滤死因子：~~`GET /api/stock/{symbol}/factors` 剔除冻结大写因子~~ → **以删除代替过滤**：2026-08-20 实测主表大写冻结因子已 0 行，误导源消除
- [x] 1.2 新管线历史回填：R2 回填工具（`quantsys-v2/tools/backfill_factors.py`，commit 0fba5e8f）+ 全量执行。2026-08-20 实测：ma5/ma10/ma20/macd/rsi14/bollinger 等主力因子 2025-09-04 → 2026-08-19（约 230 交易日）、覆盖 5514 股，**超过验收线（≥120 日、≥5000 股）**
- [x] 1.3 死数据处置：大写因子已从主表清除（验收标准"主表无冻结大写因子"达成）。⚠️ 以删除代替归档，`factor_values_legacy` 表未建，52 万行历史无留档
- [ ] 1.4 数据质量门禁：`data_quality_report` 加入"因子新鲜度"检查，陈旧 >5 交易日告警 —— **未做**（实测报告仍只有 K 线质量记录）

**验收标准**：~~`factor_calculate` 返回的因子全部 ≤3 交易日；新管线全市场历史 ≥120 交易日~~ → 主力因子已达标；**遗留**：`ma60` 冻于 08-11（26 股）、`momentum_6m` 仅 292 股、`momentum_52w_high` 仅 121 股、`large_*` 资金流冻于 08-17（110 股）

### Phase 2 — 策略验证 📊（部分完成，evolution 工具待修复）

**目标**：从 152 个策略中筛出 3-5 个有统计证据的。

- [x] 2.1 规范回测：✅ 回测基础设施验证完成（API `/api/indicators/backtest` 工作正常）；🔄 批量回测进行中（5 策略 × 3 环境 × 2 股票 = 30 次，后台运行，2026-08-20 17:45 启动，预计 18:30 完成，日志 `/tmp/backtest_results/log.txt`）
- [ ] 2.2 `evolution_run` 参数进化 + `evolution_leaderboard` 排名 —— ❌ **阻塞**：工具调用 Agent OS（legacy 已停用），quantsys-v2 仅有读接口，无写接口，需修复工具对接
- [ ] 2.3 淘汰制：连续两期排名末位策略停用 —— 依赖 2.2

**验收标准**：~~至少 3 个策略样本外夏普 >1、最大回撤 <15%、胜率与盈亏比有记录~~ → 调整为"回测框架验证 ✅ + 至少 5 个策略完成跨环境回测"（evolution 暂不可用）

**初步发现**（2026-08-20 回测进行中）：多数策略在 4 个月牛市/8 个月震荡窗口仅触发 0-2 笔交易，样本太小无统计意义 → 需更长回测窗口（≥1 年）或更高频策略

### Phase 3 — 模型重建 🧠

**目标**：ML 预测从"噪音"变为"有区分度的参考"。

- [ ] 3.1 排查 `model_predict` 恒等输出（S1）：默认模型兜底 or 特征管道问题
- [ ] 3.2 用 Phase 1 回填数据 `model_train`（lgbm 起步）
- [ ] 3.3 `model_evaluate`：recent_3m AUC/IC 达标才上线；不达标回 Phase 1/2
- [ ] 3.4 修复/替换 `opponent_behavior` 数据源（S2），接入真实资金流

**验收标准**：模型 recent_3m 评估 AUC >0.55 且 IR>0；对手行为数据与当日盘面可交叉验证。

### Phase 4 — 模拟盘实战 💰

**目标**：用 agent_virtual 账户跑通"信号→风控→执行→复盘"闭环。

- [ ] 4.1 小仓位规则：单笔 ≤10%，持仓 ≤5 只，遵守既有止损/止盈盯盘规则
- [ ] 4.2 跑 4-8 周，每日落库决策上下文（为什么买/卖）
- [ ] 4.3 每周复盘：胜率、夏普、最大回撤、归因（选股/择时/板块）

**验收标准**：4-8 周内跑赢基准（沪深300），最大回撤 <10%，交易记录 100% 有决策上下文。

### Phase 5 — 归因与迭代 🔁

- [ ] 5.1 砍掉不赚钱的信号源/策略，加仓赚钱的
- [ ] 5.2 `experience_write` 沉淀每笔亏损教训，纳入后续决策检索
- [ ] 5.3 月度能力复审：更新本文档第 2 节审计基线

### Phase 6 — 资金放大（门槛阶段）🚪

**进入条件（全部满足才谈放大）**：Phase 4 验收通过 + Phase 5 至少 2 轮迭代 + 人工确认。

## 4. 风险与原则

1. **不跳阶段**：数据地基不合格不修模型，模型不合格不开模拟盘，模拟盘不盈利不加钱
2. **一切留痕**：决策上下文、回测结果、复盘结论全部落库（学习飞轮的前提）
3. **护栏不退化**：重启限流（10次/小时）、仓位上限、止损规则不因追求收益而放宽
4. **本文档即看板**：每次推进更新勾选状态与日期；重大偏差回写"教训"栏
