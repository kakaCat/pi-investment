Dashboard 页面 API 需求分析

分析 HTML 原型和现有 React Dashboard 需要哪些后端接口

当前状态概览

HTML 原型 (quant-web-v2-prototype.html)

  • 静态 mock 数据
  • 展示：投资组合价值、持仓数量、今日信号、系统状态
  • 组合净值走势图表
  • 最近信号列表
  • 快捷操作按钮
  • 数据更新任务状态
  • 最近回测结果

React Dashboard (DashboardOverview.tsx)

  • 已连接真实后端 API
  • 调用 6 个接口获取数据
  • 展示：系统健康、信号、回测、任务队列
  • 支持任务操作（运行、重试、取消）
  • 自动刷新活跃任务

现有后端 API (quantsys-v2/api/server.py)

✅ 已实现的接口

/api/health 系统健康检查
/api/platform/status 平台状态
/api/signals 信号列表
/api/backtest/results 回测结果
/api/stocks/list 股票列表
/api/data/update 数据更新

需要补充的接口

为了让 HTML 原型连接真实后端，需要以下新接口：

1

📊 /api/portfolio/summary

用途：获取投资组合概览数据

返回数据：
  • 总资产价值 (total_value)
  • 今日涨跌幅 (daily_change_percent)
  • 持仓数量 (holdings_count)
  • 盈利/亏损持仓数 (profit_count, loss_count)
2

📈 /api/portfolio/history

用途：获取组合净值历史数据（用于绘制走势图）

参数：days (7/30/90)
返回：时间序列数据 [{date, value, change_percent}]
3

⚡ /api/signals/today

用途：获取今日信号统计

返回数据：
  • 总信号数 (total_count)
  • 买入/卖出/持有数量 (buy_count, sell_count, hold_count)
  • 最近 5 条信号详情
4

⚙️ /api/jobs 或 /api/jobs/status

用途：获取后台任务状态（数据更新、因子计算等）

返回：任务列表 [{name, status: 'completed'|'running'|'queued', progress}]
注：React Dashboard 已在用，可能需要调整返回格式
5

🔬 /api/backtest/recent

用途：获取最近回测结果（简化版）

返回：最近 3-5 条回测 [{strategy_name, symbol, return_percent}]
注：/api/backtest/results 已存在，可能只需调整查询参数
6

🤖 /api/training/history

用途：获取 ML 模型训练历史

状态：React Dashboard 已在调用
需确认：后端是否已实现

💡 关键问题

  1. 是改造 HTML 原型还是改造 React Dashboard？
    • HTML 原型：需要添加 JavaScript 调用 API
    • React Dashboard：已有 API 集成，可能只需调整 UI
  2. 是否需要保持两个版本？
    • 统一到一个版本更易维护
    • HTML 原型可作为设计参考
  3. 后端接口是否需要新增？
    • 大部分接口已存在
    • 可能只需要添加 1-2 个聚合接口
