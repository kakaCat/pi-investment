HTML 原型 vs React Dashboard 的关键差异

两个版本在功能、数据源和用途上的不同

HTML 原型 (quant-web-v2-prototype.html)
📍 位置： /quant-web-v2-prototype.html
⚠️ 数据来源：

完全是硬编码的 mock 数据

展示内容：
  • 投资组合价值：¥1,258,400
  • 持仓数量：8 只（6 盈利 / 2 亏损）
  • 今日信号：12 条（5 BUY / 3 SELL / 4 HOLD）
  • 系统状态：运行正常
  • 组合净值走势图（SVG 硬编码）
  • 最近信号列表（5 条固定数据）
  • 快捷操作按钮（9 个）
  • 数据更新任务（3 条固定状态）
  • 最近回测（3 条固定结果）
🎨 特点：
  • 设计完整、视觉精美
  • 包含完整的侧边栏导航
  • 多个页面（仪表盘、指标IDE、股票研究等）
  • 响应式设计（移动端适配）
  • 但没有任何 API 调用
React Dashboard (DashboardOverview.tsx)
📍 位置： /quant-web/src/components/dashboard/DashboardOverview.tsx
✅ 数据来源：

真实后端 API（quantsys-v2）

调用的 API：
  • /api/health
  • /api/platform/status
  • /api/jobs
  • /api/signals?days=30
  • /api/backtest/results
  • /api/training/history
展示内容：
  • 系统健康状态（数据库、模型）
  • 高置信信号数量
  • 买入/卖出比例
  • 任务队列（运行中/失败）
  • 平台状态
  • 平均夏普比率
  • 模型 AUC
  • 今日高概率信号
  • 信号摘要面板
  • 回测摘要面板
  • 任务操作面板（可运行任务）
⚙️ 特点：
  • 功能完整、已连接后端
  • 使用 Ant Design 组件
  • 支持实时刷新
  • 可执行任务操作
  • 但缺少投资组合价值、持仓等核心指标

🤔 核心差异总结

❌ HTML 原型缺失

  • 没有 API 集成
  • 数据全是假的
  • 按钮点击无实际功能
  • 无法真实运行

⚠️ React Dashboard 缺失

  • 没有投资组合价值
  • 没有持仓数量统计
  • 没有净值走势图
  • UI 不如原型精美
  • 没有完整导航结构

✅ 理想状态

  • HTML 原型的精美 UI
  • React Dashboard 的 API 集成
  • 补充投资组合相关接口
  • 统一到一个版本

💡 我的疑惑点

1. 您说的 "http://localhost:3000/dashboard" 是指哪个？

• HTML 原型是单文件，需要直接打开 HTML 文件
• React Dashboard 运行在开发服务器上（可能是 localhost:3000）
• 我不确定您当前看到的是哪个版本

2. 您想要的最终效果是什么？

• 让 HTML 原型连接后端（需要大量 JavaScript 改造）
• 让 React Dashboard 变得像 HTML 原型一样精美（需要 UI 改造）
• 还是创建一个全新的版本？

3. 后端接口是否需要新增？

• React Dashboard 已经在用 6 个接口
• HTML 原型展示的数据（投资组合价值、持仓）后端可能还没有对应接口
• 需要确认 quantsys-v2 是否已实现这些数据的查询功能

👉 请告诉我：您当前运行的是哪个版本？想要达到什么效果？
