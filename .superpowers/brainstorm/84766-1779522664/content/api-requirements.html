React Dashboard 生产化改造方案

补充缺失的接口，让 Dashboard 达到生产可用标准

🎯 目标明确

为 React Dashboard (quant-web/src/components/dashboard/DashboardOverview.tsx) 补充缺失的后端接口， 使其展示完整的投资组合数据，达到生产可用标准。

📋 需要补充的接口清单

基于 HTML 原型的功能，React Dashboard 缺少以下核心数据

1

📊 GET /api/portfolio/summary

用途：获取投资组合核心指标

返回数据结构： 
{
  "success": true,
  "data": {
    "totalValue": 1258400.00,        // 总资产价值
    "dailyChange": 29447.68,          // 今日变动金额
    "dailyChangePercent": 2.34,       // 今日涨跌幅 %
    "holdingsCount": 8,                // 持仓数量
    "profitCount": 6,                  // 盈利持仓数
    "lossCount": 2,                    // 亏损持仓数
    "availableCash": 50000.00,         // 可用资金
    "totalCost": 1200000.00,           // 总成本
    "totalProfit": 58400.00,           // 总盈亏
    "totalProfitPercent": 4.87         // 总收益率 %
  }
}
🔧 后端实现： 查询 positions 表聚合计算
2

📈 GET /api/portfolio/history

用途：获取组合净值历史数据（绘制走势图）

请求参数：
  • days: 7 | 30 | 90 (默认 30)
返回数据结构： 
{
  "success": true,
  "data": {
    "period": "30d",
    "history": [
      {
        "date": "2026-04-21",
        "value": 1200000.00,
        "changePercent": 0.0
      },
      {
        "date": "2026-04-22",
        "value": 1205000.00,
        "changePercent": 0.42
      },
      // ... 更多数据点
      {
        "date": "2026-05-23",
        "value": 1258400.00,
        "changePercent": 2.34
      }
    ]
  }
}
🔧 后端实现： 查询 portfolio_snapshots 表或实时计算
3

💼 GET /api/portfolio/holdings

用途：获取当前持仓列表

返回数据结构： 
{
  "success": true,
  "data": {
    "holdings": [
      {
        "symbol": "600519.SH",
        "name": "贵州茅台",
        "quantity": 100,
        "avgCost": 1650.00,
        "currentPrice": 1680.00,
        "marketValue": 168000.00,
        "profit": 3000.00,
        "profitPercent": 1.82,
        "weight": 13.35              // 占组合比例 %
      },
      // ... 更多持仓
    ],
    "totalCount": 8
  }
}
🔧 后端实现： 查询 positions 表 + 关联最新价格
4

    "buyCount": 5,
    "sellCount": 3,
    "holdCount": 4,
    "highConfidenceCount": 8,        // 置信度 >= 0.8

      {
        "id": 1234,
        "symbol": "600519.SH",
        "name": "贵州茅台",
        "action": "BUY",
        "confidence": 0.87,
        "timestamp": "2026-05-23T10:32:00"
      },
      // ... 最近 5 条

6

🔬 GET /api/backtest/recent

用途：获取最近回测结果（简化版，用于 Dashboard 展示）

请求参数：
  • limit: 默认 5
返回数据结构： 
{
  "success": true,
  "data": {
    "backtests": [
      {
        "id": 123,
        "strategyName": "MA 双均线",
        "symbol": "600519.SH",
        "returnPercent": 23.5,
        "sharpeRatio": 1.85,
        "timestamp": "2026-05-22T15:30:00"
      },
      // ... 更多回测
    ]
  }
}
✅ 已存在： /api/backtest/results 加 limit 参数即可

📝 总结

需要补充的核心接口：
  • 3 个必须新增：投资组合摘要、历史净值、持仓列表
  • 3 个可能调整：今日信号、最近任务、最近回测
后端数据源确认：
  • 需要确认 quantsys-v2 数据库是否有 positions 表（持仓数据）
  • 需要确认是否有 portfolio_snapshots 表（历史净值）
  • 如果没有，需要先设计数据表结构
