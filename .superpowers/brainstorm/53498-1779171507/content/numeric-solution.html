💡 更好的方案：使用数字枚举

彻底避免字符串大小写问题

🎯 你的建议

使用数字字段代替字符串，这样就完全不用关心大小写问题了

🔄 实现方案对比

A

添加 action_type 数字字段

// API 返回
{
  action: "buy",
  action_type: 1,  // 1=买入, 2=卖出
  ...
}

// 前端过滤
buySignals = signals.filter(s => s.action_type === 1)
sellSignals = signals.filter(s => s.action_type === 2)

优点

  • 完全避免字符串问题
  • 性能更好（数字比较）
  • 保留原字段兼容性

缺点

  • 需要修改后端API
  • 需要维护枚举映射
B

前端映射转换（推荐）

// 定义枚举
enum SignalAction {
  BUY = 1,
  SELL = 2
}

// 数据转换
const normalized = data.map(s => ({
  ...s,
  actionType: s.action.toLowerCase() === 'buy'
    ? SignalAction.BUY
    : SignalAction.SELL
}))

// 过滤使用
buySignals = signals.filter(s => s.actionType === SignalAction.BUY)

优点

  • 不需要改后端
  • 类型安全（TypeScript）
  • 立即可用

缺点

  • 前端需要转换逻辑
C

后端直接返回数字

// API 返回
{
  action: 1,  // 1=买入, 2=卖出
  ...
}

// 前端直接使用
buySignals = signals.filter(s => s.action === 1)

// 显示时映射
const actionText = {
  1: '买入',
  2: '卖出'
}

优点

  • 最简洁
  • 性能最优
  • 统一数据格式

缺点

  • 需要改后端和前端
  • 破坏现有API格式
