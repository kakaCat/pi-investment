🐛 Bug 详情

代码 vs 实际数据

❌ 代码中的判断

const buySignals = signals.filter(
  s => s.action === 'BUY'
)
const sellSignals = signals.filter(
  s => s.action === 'SELL'
)

✅ API 返回的数据

{
  "action": "buy",  // 小写
  "symbol": "600000",
  ...
}
{
  "action": "sell", // 小写
  "symbol": "600001",
  ...
}
⚠️ 结果： 'buy' !== 'BUY' 和 'sell' !== 'SELL'，所以过滤结果都是空数组

💡 解决方案选择

选择你认为最合适的修复方式

A

转换为大写比较

s.action.toUpperCase() === 'BUY'

优点

  • 兼容大小写
  • 代码改动最小

缺点

  • 每次过滤都要转换
B

改为小写比较（推荐）

s.action === 'buy'

优点

  • 与API数据格式一致
  • 性能最好
  • 代码简洁

缺点

  • 需要同步修改显示逻辑
C

数据规范化

setSignals(data.map(s => ({
  ...s,
  action: s.action.toUpperCase()
})))

优点

  • 统一数据格式
  • 后续使用方便

缺点

  • 增加数据处理步骤
