## 🎯 页面功能说明

### 1. 顶部标题栏

**位置**: 页面最顶部

**显示内容**:
- 标题: "服务注册中心"
- 副标题: "当前 X 个服务在运行"（自动统计）
- 刷新按钮

**功能**:
- 📊 **实时统计**: 自动计算在线服务数量
- 🔄 **手动刷新**: 点击刷新按钮，重新加载服务列表

---

### 2. 服务卡片（在线服务）

**位置**: 主内容区，每个在线服务一张卡片

#### 卡片内容

**第一行**（最显眼）:
- 左侧: 状态徽章 + 服务名称
  - ✅ 绿色 = 在线正常（< 60秒心跳）
  - ⚠️ 黄色 = 异常警告（60-120秒）
  - ❌ 红色 = 离线失联（> 120秒）
- 右侧: 💓 心跳时间（如：30秒前）

**第二行**（服务信息）:
- 服务类型（中文）: 交易系统、AI 决策大脑、基础设施服务
- 运行时长: 计算从注册时间到现在

**第三行**（API 地址）:
- API 完整地址
- 复制按钮（点击复制到剪贴板）

**第四行**（操作按钮）:
- "查看详情" 按钮 → 打开详情弹窗
- "API 文档" 按钮 → 新窗口打开 API 文档

#### 卡片功能

1. **状态实时显示**
   - 根据心跳时间自动计算状态
   - 颜色编码：绿（正常）、黄（警告）、红（离线）
   - 左侧彩色边框加强视觉提示

2. **悬停效果**
   - 鼠标悬停时卡片阴影加深
   - 提示这是可点击的

3. **API 地址复制**
   - 点击 API 地址或复制按钮
   - 自动复制到剪贴板
   - 显示 "已复制" 提示

4. **查看详情**
   - 点击按钮打开弹窗
   - 显示完整的服务信息

5. **打开 API 文档**
   - 新标签页打开服务的 API 文档
   - 默认地址: `{api_base}/docs`
   - 如果 metadata 中有自定义，使用自定义地址

---

### 3. 服务卡片（待接入服务）

**位置**: 在线服务卡片之后

**样式**: 虚线边框 + 灰色背景（区别于在线服务）

**显示内容**:
- ⏳ 未注册标识
- 服务名称（如：agent-dh）
- 服务说明（如：AI 决策大脑 · 待接入）
- 接入指南按钮

**功能**:
- **接入指南**: 点击显示如何注册到 Registry 的文档

**用途**:
- 提示用户还有哪些服务需要接入
- 提供接入帮助

---

### 4. 详情弹窗

**触发**: 点击卡片的 "查看详情" 按钮

**位置**: 屏幕中央弹出层

**内容分组**（3个部分）:

#### 基本信息
- Agent ID: 完整的唯一标识
- 类型: 服务类型（中文）
- 状态: 当前状态（带颜色标签）
- 版本: 服务版本号

#### 网络信息
- 地址: host:port
- API: 完整 URL（可复制）
- 进程 ID: 系统进程 ID

#### 运行状态
- 注册时间: 首次注册的时间
- 运行时长: 自注册以来的时长
- 最后心跳: 最后一次心跳时间

**功能**:
1. **信息展示**: 表格形式，清晰对齐
2. **API 复制**: 点击 API 地址复制
3. **关闭弹窗**: 点击关闭按钮或遮罩层
4. **打开文档**: 底部按钮快捷跳转

---

### 5. 空状态

**场景**: 没有任何注册的服务时

**显示**:
```
┌─────────────────────────────────┐
│                                 │
│           📭                    │
│       暂无注册的服务             │
│                                 │
│  quantsys-v2 启动后会自动注册   │
│                                 │
│      [刷新] [查看接入指南]       │
└─────────────────────────────────┘
```

**功能**:
- 友好提示：说明如何让服务注册
- 刷新按钮：重新检查
- 接入指南：查看文档

## 🔧 交互细节

### 状态颜色规则

| 心跳间隔 | 状态 | 颜色 | 图标 | 说明 |
|---------|------|------|------|------|
| < 60秒 | 在线 | 绿色 #67c23a | ✅ | 正常运行 |
| 60-120秒 | 异常 | 黄色 #e6a23c | ⚠️ | 心跳延迟，可能有问题 |
| > 120秒 | 离线 | 红色 #f56c6c | ❌ | 已失联 |
| - | 未注册 | 灰色 #909399 | ⏳ | 预期服务未接入 |

### 心跳时间显示

| 时间差 | 显示 |
|--------|------|
| < 60秒 | "30秒前" |
| 60秒-1小时 | "5分钟前" |
| 1小时+ | "2小时前" |

### 运行时长显示

| 时长 | 显示 |
|------|------|
| < 1小时 | "运行 30分钟" |
| 1小时-24小时 | "运行 5小时30分钟" |
| 1天+ | "运行 2天5小时" |

### 服务类型映射

| agent_type | 显示名称 |
|-----------|---------|
| trading-system | 交易系统 |
| ai-agent | AI 决策大脑 |
| infrastructure | 基础设施服务 |
| data-service | 数据服务 |
| 其他 | 原始值 |

## 📊 数据流程

### 1. 页面加载

```
用户打开页面
    ↓
调用 API: GET /api/v1/registry/agents/available
    ↓
返回服务列表 JSON
    ↓
前端计算状态（根据心跳时间）
    ↓
渲染服务卡片
    ↓
显示统计信息（X 个服务在运行）
```

### 2. 手动刷新

```
用户点击刷新按钮
    ↓
显示 loading 状态
    ↓
重新调用 API
    ↓
更新页面数据
    ↓
隐藏 loading
```

### 3. 查看详情

```
用户点击 "查看详情"
    ↓
打开弹窗
    ↓
显示该服务的完整信息
    ↓
用户可以关闭或打开文档
```

### 4. 自动刷新（可选）

```
每 30 秒
    ↓
后台静默调用 API
    ↓
更新数据（不显示 loading）
    ↓
如果状态变化（在线→离线），显示通知
```
