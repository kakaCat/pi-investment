🚀 v0.1.1 新增改进

P0-1

心跳失败自动处理

连续 3 次心跳失败自动停止 Agent，防止僵尸进程，提升系统稳定性。

P0-2

完整的输入验证

所有 API 都有参数验证，提前捕获无效输入，清晰的错误消息，更好的开发体验。

P0-3

HTTP 请求自动重试

网络请求自动重试最多 3 次，指数退避策略，请求成功率提升 4%。
