# 持仓复盘 SOP（Portfolio Review）

> 定位：把"持仓复盘"做成逐只归因决策流程，不满足于报一遍盈亏数字。**所有健康阈值对齐交易宪法**（单股≤20%/行业≤40%/现金≥10%、止损 -8/-10/-12%），TS 版迁移时曾用 15% 线——本版已替换为宪法口径，禁止回退用旧阈值。
> 铁律：复盘结论必须基于真实数据（position_list 实时盈亏 + data_fetch_financial/quote/kline 核验），禁止凭记忆说"这只逻辑没问题"；每只给明确动作（持有/减/止损/加），不许"再看看"式骑墙。

## 第 1 步：全景速查（portfolio_analyze）

1. `portfolio_analyze` — 一键出每只持仓的盈亏状态/止损止盈线距离/T+1 可卖性，按 stop_loss > take_profit > review > hold 优先级排序——先拿系统判定的问题清单。
2. `position_list` + `account_info` — 核实持仓明细（可卖数量 T+1）、总资产、现金比例、各股占比。
3. `regime_position_limit` — regime 档位与熔断状态（R-007：熔断触发=强制减仓一半、禁止新开仓，直接决定调仓方向）。

## 第 2 步：逐只深度核验（对 portfolio_analyze 标出的问题股 + 全部浮亏股）

对每只需要裁决的持仓：

| 核验项 | 工具 | 看什么 |
|--------|------|--------|
| 浮盈亏与止损距离 | position_list（实时盈亏） | 距止损线（宪法 -8/-10/-12% 按规模）几个点 |
| 当初为什么买 | memory_search(decision/experience) + decision_history(related stock) | 买入逻辑原文，判断是否已变 |
| 逻辑还成立吗 | data_fetch_financial + stock_intel | 基本面是否恶化（业绩/暴雷/减持） |
| 技术位置 | data_fetch_kline(60日) + factor_calculate(rsi/macd) | 趋势、支撑压力、是否破位 |
| 资金态度 | fund_flow | 主力在进还是在出 |
| 当前价格合理吗 | pe_percentile | 估值分位（跌到低估≠要砍，但要区分"错杀"与"价值陷阱"） |

## 第 3 步：五问复盘清单（每只必答，回答不了就说明证据不足）

1. **当初为什么买？**（买入逻辑——记忆/决策审计里应有记录，没有说明当时没留痕，本身是教训）
2. **逻辑还成立吗？**（基本面有无变化——用第 2 步财务/情报核验说话）
3. **现在处于什么位置？**（技术面——趋势/支撑/破位）
4. **如果今天是空仓，还会买吗？**（重新审视——把沉没成本清零，问自己按当前价位和逻辑是否愿意新建仓；答案"不会"=该考虑退出）
5. **下一步怎么操作？**（持有/减仓/止损/加仓——给出明确动作和触发条件）

## 第 4 步：组合层面检查

1. **行业分散度**：单行业 ≤40% 宪法上限（position_list 归并行业算）；同涨同跌的高相关持仓视同集中
2. **单股集中度**：任一持仓市值 > 总资产 20% 违规（宪法第 3 条），超限必须减
3. **现金比例**：≥10% 宪法底线；低现金时任何加仓都不允许
4. **仓位匹配 regime**：总权益仓位 vs regime_position_limit 档位上限（R-006）
5. **熔断状态**：R-007 60日回撤 >8% → 强制减仓一半禁新开仓（m4_circuit_breaker_check 每日核）

## 与 deep-analysis 的分工

- 持仓中某只被标记"需重新评估/逻辑存疑"时，若要做是否保留的深度裁决 → 对那只单独跑 deep-analysis 六维尽调（基本面/估值/技术/资金/筹码/情报全景），本技能的五问是"组合视角快筛"，deep-analysis 是"单只全景裁决"。
- 卖出决策前：position_list 确认可卖数量（T+1）、risk_controller 算止损价、memory_search 检索该股教训（R-008）——完整链条走完再 portfolio_trade，reason 注明规则 ID。

> 数据标注（R-013）：盈亏/仓位 = position_list/account_info 时点值；止损价 = risk_controller 计算；regime = regime_position_limit 返回。调仓决策落 decision_audit(trade_sell/risk_control)。
