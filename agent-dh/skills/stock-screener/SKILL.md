# 选股 SOP（Stock Screener）

> 定位：按用户条件在全市场筛候选。与 opportunity-funnel（主动扫全市场机会）分工——本技能是"用户给了方向/条件，我按条件找票"；与 deep-analysis 分工——本技能只负责"找出来+初筛验证"，**单只买卖裁决必须交给 deep-analysis 六维尽调**。
> 铁律：screening 结果只是"满足财务条件的名单"，**不代表可以买**——每只候选至少要过一遍财务真实核验与一票否决排雷（screening 不返回质量分，别把它当质量背书）。

## 第 1 步：澄清需求

用户未指定时问清三件事：①行业/板块偏好 ②风险偏好（稳健价值/成长进攻）③投资期限。用户明确给了条件就直接筛，别啰嗦。

## 第 2 步：初筛（screening 条件筛选）

`screening(criteria, limit)` — criteria 用区间数组 JSON（实测形态：`{pe: [0, 20], roe: [15, null], market_cap: [50, null]}` 表示 PE 0-20 / ROE≥15 / 市值≥50亿，null=不限上界；limit 1-200，默认 50）。

常用条件组合模板：

| 目标 | criteria |
|------|----------|
| 低估值价值 | `{pe: [0, 15], roe: [12, null], market_cap: [100, null]}` |
| 高 ROE 质量 | `{roe: [15, null], market_cap: [100, null]}` |
| 成长候选 | `{pe: [0, 30], roe: [8, null]}`（成长股 ROE 门槛低） |
| 小盘观察 | `{market_cap: [50, 200]}`（低于 50 亿默认排除） |

> 实测注意：screening 返回的是"符合条件名单"（含得分但普遍为参考值），**不做一票否决过滤**——排除条件必须在第 3 步逐只人工核验。

## 第 3 步：逐一验证候选（Top 3-5 只，禁止只看名单就推荐）

对每只候选调用：
1. `data_fetch_financial` — 核对 ROE/毛利率/净利增速/负债率/市值是否真达标（回测确认，不信筛选器二次计算）
2. `pe_percentile` — 估值贵贱：分位 <40% 好价格、40-80% 中性、>80% 只做波段
3. `factor_calculate`(rsi/macd) — 技术位置：是否高位过热、趋势方向
4. `stock_intel`(announcements/insider) — 排雷：暴雷公告/高管减持/立案

### A 股优质标准（门槛对照）

| 指标 | 达标线 | 优秀线 |
|------|--------|--------|
| ROE | > 12% | > 15% |
| 毛利率 | > 25% | > 30% |
| 净利增速 | > 0% | > 15% |
| 资产负债率 | < 65% | < 50% |
| 市值 | > 50亿 | > 200亿 |

### 估值参考（分位为主，绝对值为辅）

| 类型 | PE 参考 | PB 参考 |
|------|---------|---------|
| 价值股 | < 15 | < 2 |
| 成长股 | < 30 | < 5 |
| 周期股 | 看 PB | < 3 |

### 一票否决（命中即剔除，写在输出里）

- 连续 2 年亏损 / 净利增速持续为负且无反转证据
- 商誉占净资产 > 30%
- 大股东质押比例 > 50%（stock_intel 查不到时标注"质押数据未核验"）
- 近期被 ST / 监管函 / 立案调查
- 审计意见非标准无保留

## 输出骨架

```
## 选股结果 - {条件/板块}（{date}）

### 候选名单（screening {limit} 只 → 验证后 {n} 只）
| 排名 | 股票 | 代码 | ROE% | PE分位% | RSI | 财务/估值/技术要点 | 一票否决检查 |
|------|------|------|------|---------|-----|------------------|-------------|
| 1 | {name} | {code} | {x} | {x} | {x} | ... | 无雷/命中{排除项}剔除 |

### 风险提示
- 板块风险：...
- 个股风险：...
- 市场环境：...（regime_position_limit 档位——狂热/熔断期即使筛出好票也不建议立即建仓）

### 下一步
- Top 候选若要做买入裁决 → 走 deep-analysis 单只六维尽调（本技能不做买卖建议）
- 可落观察池：pool_manage(add_members) 跟踪，等买点
```

> 数据标注（R-013）：每只候选的 ROE/PE/RSI 等字段带 data_fetch_financial/pe_percentile/factor_calculate 来源与数据期；screening 只标"条件筛选名单"。候选池调整落 decision_audit。
