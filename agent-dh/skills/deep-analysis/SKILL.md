# 个股深度分析 SOP（Deep Analysis）

> 定位：把"分析一只股票"从"看几个数字就表态"升级为"六维取证 + 信号分级 + 固定骨架结论"。与 opportunity-funnel 分工——漏斗负责"全市场找候选"，本技能负责"对单只候选做尽调裁决"。多只候选时逐只完整执行本流程，禁止交叉混淆数据。
> 铁律：每一步必须真实调用工具取证（R-013：数据带来源工具+时点），禁止凭记忆/感觉编数字；买/卖建议必须走 R-009 分级；结论必须落固定骨架，禁止自由发挥式点评。

## 第 0 步：定级与排雷准备（先看有没有雷，再看值不值得买）

1. `trading_calendar` 确认交易日；非交易时段分析结论标注"仅供研究，不构成交易时点依据"。
2. `data_fetch_quote`（realtime）拿现价/涨跌幅/成交额——一切分析锚定实时价。
3. `stock_intel`（all）排雷：公告暴雷/高管减持/负面新闻 → 有雷直接降级并如实标注，不硬推。
4. `memory_search`（namespace=experience，query="{symbol} {name}")检索历史教训——R-008：重复犯过的错最低级。
5. `data_fetch_market_sentiment` + `regime_position_limit` 定市场环境档位：恐慌/狂热时建议降一级处理。

## 第 1 步：六维取证（每一维都真实调用，禁止跳维）

| 维度 | 工具 | 关键看什么 |
|------|------|-----------|
| ① 基本面 | `data_fetch_financial` | 营收/净利增速、ROE、毛利率、负债率；增速是否匹配估值 |
| ② 估值 | `pe_percentile` | PE-TTM 历史分位：<40%=好价格候选，40-80%=中性，>80%=贵（只做波段） |
| ③ 技术面 | `factor_calculate`(rsi/macd/turnover) + `data_fetch_kline`(近60日) | 趋势方向、超买超卖、量能配合、关键支撑压力 |
| ④ 资金面 | `fund_flow` | 主力/大单净流入趋势、两融杠杆变化；持续流入=机构共识 |
| ⑤ 筹码 | `chip_analysis` | 平均成本、获利盘比例（>90%浮盈兑现压力大，套牢盘重=反弹阻力大）、筹码集中度 |
| ⑥ 博弈情报 | `stock_intel` + `lhb_dragon_tiger`(symbol,若近期上榜) | 游资席位动向、机构买卖、内部人增减持 |

辅助维度（可选，标的多或关键裁决时加分）：`swing_points`（历史波段胜率/买区）、`model_predict`（ML 弱信号，仅辅助）、`competition_analysis`（竞争地位）、`manipulation_detect`（操纵风险）。

## 第 2 步：R-009 信号分级（裁决环节，必须有结论）

多维共振判定：

- **A 级**（≥3 维同向 + 无雷）：基本面好 + 估值分位<40% + 技术转强/资金流入 → 标准仓候选
- **B 级**（2 维同向或有轻微矛盾）：半仓候选；写明矛盾点与假设
- **C 级**（单维信号或高维矛盾/有雷）：只记录观察，禁止委托

定级后：`signal_track`(action=record, symbol, price=实时价, grade, source=opportunity_scan/manual, reason=分级依据) 落库——每个分析结论必须留痕，供 5/10/20 日回填验证胜率。

## 第 3 步：固定骨架输出（格式不可自由发挥）

### 单只模式（手动指定个股时）

```
## {code} {name} 深度分析（{日期}）

### 【核心数据】（数据来源：data_fetch_quote realtime {时点} / data_fetch_financial {期} / pe_percentile 截至{日}）
- 现价：{price}（{涨跌幅}%）| 成交额 {amt} 亿
- 财务：营收 {rev}（{rev_yoy}%）/ 净利 {np}（{np_yoy}%）| ROE {roe}% | PE-TTM {pe}（历史分位 {pct}%）
- 技术：RSI {rsi} | MACD {macd} | 量能 {vol_note}
- 资金：主力 {n日净流入} | 两融 {margin_note}
- 筹码：平均成本 {cost} | 获利盘 {profit_pct}%

### 【六维结论】
基本面：…（增速质量/毛利率/负债）
估值：…（分位判定）
技术：…（趋势/位置）
资金：…（主力态度）
筹码：…（成本结构/套牢浮盈）
情报：…（公告/增减持/席位，有雷必标红）

### 【信号分级】{A/B/C} — {一句话依据}
共振维度：…（列同向维度）
矛盾/风险点：…

### 【操作建议】
- 若 A：标准仓候选。买点参考 {价位逻辑}，止损 {stop_loss 计算价}（risk_controller stop_loss，按规模定 -8/-10/-12%）
- 若 B：半仓或等回调。触发条件：{写清什么信号出现再动手}
- 若 C：不交易。观察点：{什么变化升级为 B/A}

> 已检索经验：{memory_search 结论} | 已落库 signal_track ✓
```

### 多只模式（机会扫描出的候选清单）

1. 先给一张候选对比表（code/名称/评分/现价/PE分位/ROE/资金/初步分级），
2. 再逐只按上述骨架给"详情+操作建议"，每只独立留痕。

## 判断标准速查（对齐 genome 约束）

- 好公司底线：ROE ≥ 12%（成长股 ≥ 8%）、营收/净利正增长、负债率 < 70%
- 好价格：PE-TTM 历史分位 < 40%；分位 > 80% 只做波段不追高
- 止损铁律：大盘蓝筹 -8% / 成长股 -10% / 小盘题材 -12%（宪法第 4 条），买入前用 risk_controller 算好
- 仓位钳制：单股 ≤ 总资产 20%、单行业 ≤ 40%、现金 ≥ 10%；regime 档位余量以 regime_position_limit 返回为准（R-006）
- 弱市/恐慌（regime=panic 之外档位下降 / 情绪分低）自动降一级：A 按 B 执行、B 只观察
- 北向资金已永久停披露个股数据（2024-08 起），不要用北向字段当依据
- 数据源临时失效时如实标注"XX 源不可用"，用其他维度补位，禁止编数

## 公告利好利空速查（stock_intel 解析用）

| 类型 | 信号 |
|------|------|
| 业绩预增/超预期 | 利好，看是否已 price-in（涨幅与放量） |
| 大额减持/质押 | 利空，尤其高位+游资票 |
| 增持/回购 | 底部信号，配合筹码看 |
| 立案/问询/退市风险 | 重雷，直接降 C 级不碰 |
| 重组/收购 | 双刃，看注入资产质量与停牌前位置 |
