# 市场环境分析 SOP（Market Analysis）

> 定位：回答"现在市场适不适合动手、配什么方向"的环境定调技能。与 regime 体系的关系——data_fetch_market_sentiment 看当日情绪快照，regime_daily/regime_position_limit 是落库的正式 regime 判定，**仓位上限只信 regime_position_limit（R-006），本技能的宏观/情绪解读只用于定方向与定行业偏好，不用于自拟仓位数字**。

## 第 1 步：数据获取（并行取，全部真实调用）

1. `data_fetch_market_sentiment` — 情绪评分/恐慌贪婪指数/涨跌家数比/量能/波动率（当日快照）
2. `data_fetch_macro` — PMI（荣枯线50）/ CPI（通胀）/ GDP（增速）三序列取趋势
3. `sector_analysis` — 行业板块表现与资金流向排名（发现强势/弱势板块）
4. `regime_position_limit` — 正式 regime 档位（恐慌≤100%/偏多≤80%/震荡≤60%/偏空≤40%/狂热≤30%）与余量、熔断状态——**仓位结论的唯一权威**（R-006）
5. 辅助：`market_style_detect`（价值/成长/周期风格偏好）、`mainline_scan`（当日主线 Top3）、`retail_panic_index`（散户情绪收割机会）、`market_alert`（high 级告警优先处理）

> 注意：北向资金已永久停披露个股数据（2024-08 起），data_fetch_north_flow 若不可用不必强取，用情绪/资金维度补位（deep-analysis 技能第 0 步同款纪律）。

## 第 2 步：宏观指标解读（判断经济周期位置）

| 指标 | 信号 | 含义 | 配置倾向 |
|------|------|------|----------|
| PMI > 50 | 扩张 | 经济向好 | 增配周期股 |
| PMI < 50 | 收缩 | 经济放缓 | 防御为主 |
| PMI 拐点向上 | 复苏 | 底部信号 | 逢低布局 |
| CPI > 3% | 通胀 | 加息预期 | 避开利率敏感板块 |
| CPI < 1% | 通缩 | 宽松预期 | 利好成长股 |
| GDP 加速 | 增长强 | 风险偏好上行 | 进攻配置 |
| GDP 减速 | 增长弱 | 保守 | 高股息/防御 |

## 第 3 步：美林时钟行业轮动框架（A 股版，定方向用）

| 阶段 | 经济特征 | 推荐行业 | 回避行业 |
|------|----------|----------|----------|
| 复苏期 | PMI回升, CPI低位 | 金融、地产、可选消费 | 公用事业 |
| 扩张期 | PMI高位, CPI温和上行 | 科技、消费电子、新能源 | 债券替代 |
| 滞胀期 | PMI回落, CPI高位 | 医药、必选消费、公用事业 | 科技、地产 |
| 衰退期 | PMI低位, CPI回落 | 高股息、黄金、必需消费 | 周期股 |

### A 股特色补充因素
- **政策驱动**：国常会、政治局会议、央行操作（`event_calendar_check` 查 LPR/FOMC 等日程）
- **风格切换**：market_style_detect 判价值/成长偏好——偏价值配低估值蓝筹、偏成长配科技成长
- **主线验证**：mainline_scan 的当日主线应与宏观/风格判断交叉印证，不单信一方
- **季节效应**：春季躁动（1-3月）、四月决断、秋冬行情（仅供节奏参考，不构成硬依据）

## 第 4 步：情绪与温度判定

| 温度 | 特征参考 | regime 档位（权威） |
|------|----------|----------|
| 过热/狂热 | 恐惧贪婪 >80、涨停潮、量能暴涨 | euphoria ≤30%（R-006 取严） |
| 偏热 | 连续放量上涨、情绪 >65 | risk_on ≤80% |
| 正常 | 量价配合、指标中性 | sideways ≤60% |
| 偏冷 | 缩量整理 | risk_off ≤40% |
| 过冷/恐慌 | 恐慌分高、地量、普跌 | panic ≤100% 但接飞刀纪律生效 |

**最终仓位 = regime_position_limit 返回的上限与余量**（degraded 自动收紧到震荡档；circuit_breaker 触发禁止新开仓），本表温度只做定性交叉参考。

## 输出骨架

```
## 市场环境分析报告 {date}

### 大盘与情绪
- 情绪分：{score}（{greed/fear}）| 涨跌家数比：{x} | 量能：{normal/低/放量} | 波动率：{x}
- regime 档位：{euphoria/risk_on/...}（regime_position_limit，{date}落库）| 熔断：{触发/正常}
- 高位告警：{market_alert high 级摘要}

### 宏观环境
- PMI：{x} → 经济{扩张/收缩/拐点}
- CPI：{x} → 通胀{温和/上行/下行}
- 结论：{复苏/扩张/滞胀/衰退}期 → 对应行业偏好

### 行业与风格
- 强势板块：{sector_analysis Top3}
- 风格：{价值/成长/周期}（market_style_detect）
- 主线：{mainline_scan Top3}

### 操作定调
- 可加仓额度：{regime_position_limit 余量}（唯一权威，R-006）
- 建议方向：{行业/风格}
- 回避方向：{...}
- 风险提示：{...}
```

> 数据标注（R-013）：情绪/宏观/行业各字段带来源工具与数据时点；regime 判定标落库日期；degraded 数据源如实标注，禁止编数。方向性结论落 memory_write(analysis) 供后续检索。
