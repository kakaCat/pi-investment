# 会话启动简报 SOP（Session Briefing）

> 为什么需要：会话启动时我拿到的只有**静态层**（身份 + 基因组宪法/原则/规则/教训 + 工作区指令 + 工具清单），
> **没有事实层**——不知道账户能不能买、市场什么状态、我自己最近的决策是赚是亏、有哪些事悬着没闭环。
> 而这三类"事实"恰恰决定超额利润。本 SOP 把事实层固化成固定动作。
>
> 铁律：①每一项必须来自工具实测并标注来源与时点（R-013），取不到就写"降级/未取到"，禁止凭记忆填。
> ②简报不是决策；下单仍走 R-001/R-002（确认价格、可卖数量、regime 额度、止损线）。
> ③**业绩反馈必须放在决策之前**：我已知的历史事实是"买入决策 20 日平均超额为负"，
> 简报要主动把它摆出来（R-008 扩展的会话级形态），而不是靠临时想起。

## 第 0 步：时间与可交易性（决定"今天能不能动手"）

| 工具 | 读什么 |
|---|---|
| `trading_calendar` | 今天是否 A 股交易日（非交易日 → 只做分析与池治理，禁止下单，宪法第 1 条） |
| 当前时间 | 是否落在 9:30-11:30 / 13:00-15:00（盘中/盘后决定可做与不可做） |

## 第 1 步：账户与风险额度（决定"能买多少"）

| 工具 | 读什么 |
|---|---|
| `account_info` | 总资产 / 现金 / 现金占比（宪法：现金 ≥10%） |
| `position_list` | 逐只成本、现价、盈亏、**shares_available（T+1）** |
| `regime_position_limit` | regime 档位与权益上限、当前仓位、余量、**熔断状态**（R-006/R-007；degraded 要说明） |

输出红线：本日可加仓额度 = min(regime 上限余量, 单股 20%、单行业 40%、现金 10% 三重钳制后的空间)。

## 第 2 步：我自己的业绩与纪律（**先验，影响每一次下注**）

| 工具 | 读什么 |
|---|---|
| `decision_scores` | band 分布 / 平均与最差超额 / learnedLesson 覆盖率 —— 我过去的同类决策跑赢还是跑输基准 |
| `memory_search("业绩归因", namespace=analysis)` | 昨日/最近一次归因结论（组合超额来自选股还是来自不参与？） |
| `experience_stats` | 经验库胜率与平均盈亏（按标的/结果分布） |

判读口径：**若平均超额为负，本次所有"想买"的冲动都要先被这条事实审一遍**；
若超额为正但主要来自低仓位/不参与，要明确"这是不参与的红利，不是选股能力"。

## 第 3 步：市场与催化剂（决定"往哪看"）

| 工具 | 读什么 |
|---|---|
| `data_fetch_market_sentiment` | 情绪分 / 恐慌贪婪 / 涨跌家数 / 量能（极端值决定进攻或防守） |
| `mainline_scan` 或 `sector_analysis` | 当日主线与轮动方向（线索，不直接下单） |
| `event_calendar_check` | 未来 2 日宏观事件（CPI/PMI/FOMC/LPR/交割） |
| `stock_events`（对每只持仓 + 候选） | 解禁/减持/财报/股东会（买入前排雷） |

## 第 4 步：未闭环清单（防止"悬着的事没人管"）

| 来源 | 看什么 |
|---|---|
| `board_read(status=active)` | 别人给我的请求/我发起的悬赏（有人等回复 = 隐性承诺） |
| `decision_history(action=pending, days=7)` | 逾期未评估的决策（学习回路断点） |
| `watch_list` + `market_alert(level=high)` | 盯盘规则与高风险告警 |
| 看门狗未闭环 | `quant.scheduler_watchdog_log WHERE resolved=false`（漏跑/僵尸/未打标） |
| `genome_benchmark` | 观察期 candidate（到期需裁决） |

## 输出模板（≤12 行，每行一个结论，不要复述原始数字）

```
【简报 · {日期} {时段}】交易日=是/否 · 可下单=是/否
账户：总资产 ¥X｜现金 X%（≥10% 合规/违规）｜仓位 X%（regime 上限 X%，余量 X%）
风险：熔断=无/触发｜止损风险持仓=…
我的业绩先验：买入决策 20 日平均超额 X%（band: big_loss X / big_win X）→ 本次下注纪律：…
市场：情绪 X（贪婪/恐慌）｜主线=…｜2 日内事件=…
未闭环：公告板 X 条待复｜逾期未评估决策 X｜看门狗未闭环 X（…）｜candidate 到期 X
今日红线：…
```

## 失败安全

- 任一源降级/超时 → 该行写 `降级：<源>`（R-013），不得省略或编造；
- 交易时段外的简报只做 1/2/4 步（第 1 步仍需，因为要判断"能否下单"）；
- 简报发现"熔断触发/现金违规/止损已破"→ 优先按宪法处置，简报其余内容后置。
