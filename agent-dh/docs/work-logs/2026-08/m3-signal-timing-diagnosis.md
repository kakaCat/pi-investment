# 信号分级制（Signal Grading System）

## 1. 分级定义

### A 级信号（标准仓）

**条件**: ≥3 个独立维度共振，无明显矛盾

**维度清单**:
1. **主线共振**: 标的属于当日 Top 3 主线板块
2. **技术面**: 突破关键位（MA/MACD 金叉/布林带上轨）
3. **资金面**: 主力资金净流入 >0 且连续 3 日流入
4. **基本面**: ROE >15%、PE <30、无 ST 标记、无操纵嫌疑

**仓位**: 标准仓（risk_controller position_size 建议仓位）

**示例**: 见 §3.1

### B 级信号（半仓）

**条件**: 2 个维度同向 或 有轻微矛盾（如技术+主线，但资金流-1 日流出）

**仓位**: 半仓（建议仓位 × 0.5）

**示例**: 见 §3.2

### C 级信号（仅观察）

**条件**: 单维度信号 或 高维矛盾（如技术突破但主力资金流出）

**仓位**: 0（不交易，仅 signal_track 记录）

**示例**: 见 §3.3
