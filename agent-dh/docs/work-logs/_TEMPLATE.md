# 工作日志模板

> 复制本文件到 `YYYY-MM/<kebab-title>.md` 后填写。**文件名以 `_` 开头 = 模板/草稿，不进索引与台账。**
> 结论块是硬要求：读的人（下个窗口的 agent）只看前 20 行就要能判断「要不要细读这页」。

## 结论（必填，≤5 行）

- **结论**：一句话说清做成了什么 / 查到了什么（可验证，不含"应该""大概"）。
- **影响面**：谁受影响（哪个实例/账户/插件/页面）、影响多久。
- **是否改变认知**：是 → 指向合并去向（`L2` 页面路径，写进 front-matter 的 `distilled_into`）；否 → 写"无认知变化"并说明理由。
- **证据**：跑过的命令 / 接口 / 文件路径（可复现），必要时贴关键输出。

## 过程（写到"够复现"为止，不写流水账）

1. 现象与初始判断
2. 排查路径（试过什么、排除了什么）
3. 根因
4. 修复与验证

## 遗留

- 未闭环项 / 已知坑 / 下次别再踩的地方
