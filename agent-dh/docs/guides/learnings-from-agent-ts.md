## 一、可立即吸收的方法论

### 1. 买卖点分析框架（其最成熟的高频输出）
用户最高频的问题是"XX 买卖点"。对方的回答模板值得采用：
- **价位地图**：把年内高点/压力区/短期压力/现价/历史买入区/止损线/恐慌低点画成一张纵向价格图，标星号区分验证强度
- **历史验证买区**：此前 N 次触发过的买入区权重最高（如中石油 10.4~10.7 触发过 4 次）
- **股息率锚**：央企巨无霸（低波动、织布机行情）用股息率定买区（买区对应股息率 4.4~4.5%）
- **PE 分位定策略性质**：PE 分位 ~88% → "只做波段、不做长持"
- **单次波段空间测算**：买价→卖价 ≈ +9%，叠加股息，明确"一年做 1~2 轮"
- **联动开关**：中石油=布伦特油价是开关，油价趋势性走弱则整个波段逻辑放弃
- **子弹纪律**：历史教训"买区触发 4 次都没买成（满仓）"→ 机会来了要有子弹，为标的预留仓位
- **分析结论直接转化为盯盘规则**（含买区上沿提醒，不只止损）

### 2. 崩盘日买抗跌股（有实证，win 5/5，avg +9%）
指数单日 ≤-5% 的崩盘日调仓，优选当日抗跌股（跌幅 < 指数一半或逆势收红）。
原理：崩盘日抗跌 = 资金护盘 = 相对强度，V 型反弹中率先修复领涨。
边界：若持续阴跌而非反弹，抗跌股会补跌，必须配止损。

### 3. 机械止盈对无人值守账户有效（win 3/3，avg +10.5%）
浮盈 +10% 且盘中回落 → 机械止盈。净效果为正：接受少赚 5~9% 的机会成本，规避 -20% 回吐尾部风险。反例：无规则的 v14 账户同期 -53%。

### 4. 换仓后规则补位（血泪教训）
v13 账户 8/19 买入 5 只持仓后**没有任何盯盘止损规则**，301520 盘中 -10.5% 完全无告警。
**纪律：每次新开仓/换仓后，必须立即为每只持仓挂止损盯盘规则**（开仓动作的收尾步骤，不是可选项）。

### 5. 告警链路健康检查
盯盘触发 ≠ 告警送达。对方曾因 wake-adapter 语法错误 + 端口被抢占，歌尔 18 次触发全部静默错过，少赚 2~3%。
**行动**：定期抽查触发记录的 notified 字段；关键进程要有健康检查。

### 6. 盯盘阈值的噪音调优
量能异动阈值从 2.5x（一天触发 4 次，噪音）→ 4x → 8x，逐步上调到信号/噪音比可接受。
**原则：告警阈值不是一次设对，是按触发频率反馈迭代。**

### 7. 深度分析输出标准（其 deep-analysis skill）
- 好公司：价值型 ROE≥12% 三年稳定 / 负债率<60% / 毛利率>20% / 经营CF>净利润×0.7；成长型营收连续两年 ≥15%
- 好价格：PE 历史分位 < 40% + ≥2 个买入信号共振
- **大盘降级**：弱势市场所有结论降一级
- 输出必含：买入区间 / 止损位 / 止盈目标 / 1-2 条核心风险

### 8. 持仓复盘五问
每只持仓回答：①当初为什么买 ②逻辑还成立吗 ③目前什么位置 ④今天空仓还会买吗 ⑤下一步操作。
组合层面：行业分散度 / 相关持仓同涨同跌 / 仓位匹配市场环境 / 现金储备。

## 三、对方架构上值得借鉴的机制

1. **Skills 强制路由**：用户输入先匹配 skill（deep-analysis/portfolio-review/risk-manager…），命中后必须先 read skill 文件才能行动——把方法论固化成可迭代的文件，而非塞在系统提示词里。
2. **task 分解 + 异步并行**：plan_task → task_create（带依赖 blockedBy/blocks）→ task_execute_async 批量并行拉数（10 只股 × 10 个维度一次发出），结果通过 background-results 投递。≈ 我的 todo_write + workflow，但它更轻量（不起 subagent）。
3. **系统级防循环注入**：第 13/26/39…轮无进展时系统自动注入"停止无新信息重试，存 memory，换方案"——与我的原则 5（3 次未推进停止）同类，但由系统强制执行。
4. **压缩前记忆冲刷**：context 压缩前自动跑一个 "Pre-compaction memory flush" subagent，把关键上下文写 memory_write 防丢。
5. **盯盘触发即唤醒 agent 决策**：后端 watcher 触发后把"触发条件+你当时的监视理由"作为 prompt 唤醒 agent 子会话处理，不是只发通知。
