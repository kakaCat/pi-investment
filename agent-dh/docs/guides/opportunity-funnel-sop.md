# 机会发现漏斗（Opportunity Funnel）

> 目的：把"找机会"从"在熟人（池内 20 只）里挑"升级为"在全市场 5400 只里筛"。
> 每一步都必须真实调用工具，禁止凭记忆/感觉跳过。产出必须落库，否则不算完成。

## 第 1 步：全市场初筛（二选一或并用）

**A. 基本面初筛** — `screening`（全 A 股，非池内）：
- criteria 必须用**区间数组格式**：`{"pe":[0,25],"roe":[12,null],"market_cap":[80,null]}`（用 min_roe/max_pe 键名会静默返回未过滤的假结果——已踩过坑）
- 条件随市场风格切换（先 `market_style_detect`）：
  - 价值/防御期：`pe[0,25] + roe[12,] + market_cap[80,]`
  - 成长期：`roe[15,] + market_cap[100,]`，放宽 pe
  - 恐慌期：加 `pb[0,1.5]`，找错杀
- limit 取 30，sort_by 按风格选 roe 或 pe

**B. 情绪/资金初筛** — 与 A 并行：
- `mainline_scan`：当日主线 Top3
- `limit_up_pool`：涨停家数+连板高度判断情绪温度（<20 家=冰点，>50 家=亢奋）
- `fund_flow`（不传 symbol）：板块资金流入/流出 Top5

## 第 2 步：交叉验证（砍到 ≤10 只）

初筛结果与第 1B 步交叉：
- **只保留**落在当日资金净流入主线/板块内的标的（筛选榜与资金主线互相印证才有效，如"低 PE 高 ROE 榜单全是铝股 + 工业金属净流入 24 亿"）
- 剔除：主线外标的、ST、上市 <60 天、当日一字板买不到的
- 若初筛结果与主线零交集，如实报告"主线内无符合质量标准的标的"，不硬凑

## 第 3 步：个股三维深度验证（每只候选）

对交叉后的每只（≤10 只）：
1. **技术面**：`factor_calculate`（rsi/macd/turnover/volatility）或 `swing_points`（波段位置，处于上升段还是回调段）
2. **估值面**：`pe_percentile`（分位 <40%=好价格候选，>80%=只波段不长持）
3. **排雷**：`stock_intel`（公告暴雷/高管减持=直接淘汰）；`chip_analysis`（获利盘 >90% 警惕兑现压力）
- 任一维度发现硬伤 → 淘汰并记录原因
- `degraded_sources` 非空时：按工具提示用 web_search 补排雷，禁止因源失效跳过

## 第 4 步：R-009 信号分级

对存活标的逐只定级，标准（详见 docs/architecture/signal-grading.md）：
- **A 级**：≥3 个独立维度共振（主线/技术面/资金面/基本面无雷）→ 标准仓候选
- **B 级**：2 维同向或轻微矛盾 → 半仓候选
- **C 级**：单维或高维矛盾 → 只观察

已知维度残缺（评分时明示）：
- 北向资金：交易所永久停披露，**该维度不存在**，权重由板块资金流+两融替代
- 个股资金流实时：东财源被封，用 DB 缓存/同花顺降级，注明数据时效
- ML 预测（model_predict）：弱信号（auc≈0.58），只能当第 4 辅助维度，不能当决策驱动

## 第 5 步：落库（必须，无例外）

- **每只存活标的**调 `signal_track(record)`：symbol/price/grade/source=opportunity_scan/reason（一句话分级理由）
- C 级也要落——落库成本低，样本积累是验证扫描能力的唯一途径
- 最后 `memory_write` 一条当日扫描摘要（主线/候选数/分级分布/关键结论）

## 输出格式

给用户/调用方的报告必须包含：
1. 市场环境一句话（风格 + 情绪温度 + regime）
2. 初筛口径与交叉结果（多少只进、多少只出、为什么）
3. 分级清单：A/B/C 各标的 + 一句话理由 + 关键价位
4. 明确的风险提示与"不做什么"

## 反模式（禁止）

- ❌ 只用 `opportunity_scan`（它只扫池内约 20-400 只，覆盖窄）就回答"市场机会"
- ❌ screening 用 min_roe/max_pe 键名（静默假结果）
- ❌ 跳过第 5 步落库（没有样本积累，能力永远无法被验证）
- ❌ 追高：标的单日已涨 >5% 时降级处理，策略写"等回踩确认"而非"立即买入"
- ❌ 在止损线/仓位上限（regime_position_limit）未确认时给出买入建议
