# REQ-261019144524-ec50 进化闭环有效性改造：让自我进化以盈利为北极星

- **类型**：spike（先调研定方案）
- **创建**：2026-10-19 · w-503df447（investor）
- **触发**：用户原话「自我进化，感觉没有用，没有提高投资的准确性和发现盈利机会」

## 1. 背景与问题陈述

系统已建成完整的自我进化机制（基因组四段、验证门、蒸馏、周报、调度任务群），但用户感受不到它在投资结果上的任何作用。本需求要回答：**进化机制为什么在空转，以及怎样把它接到盈利的北极星上。**

## 2. 证据链（2026-10-19 实测，全部标注来源）

### 2.1 投资结果层：进化没有可衡量的产出

| 证据 | 数据 | 来源与时点 |
|---|---|---|
| 账户几乎不交易 | 总资产 49.9 万，现金占比 **96.9%**，总盈亏 **-0.99%**，仅 2 只持仓 | account_info(agent_brain)，2026-10-19 13:41 |
| 自有决策评分 = 0 | decision_scores 共 27 条，**100% 为策略线账户 v13/v14 回填**，agent_brain 覆盖 **0 条**；且这 27 条 20 日平均超额 **-10.24%**、18/27 big_loss | decision_scores，2026-10-19 |

### 2.2 进化内容层：进化方向与盈利脱钩

- genome_history 最近 20 版（g22~g40）：R-015 公告板、R-016 样本门槛、R-018 启动简报、R-019 账户边界、R-020 数据卫生，lessons 全部是部署/观测/schema 类工程纪律——**没有一条交易层进化**（genome_history，2026-10-19）。
- 这不是执行偏差而是**结构性死锁**：R-016 要求样本 ≥7 才能改交易规则 → 账户零交易样本=0 → 只能改工程规则 → 工程规则不产生交易 → 样本继续=0。

### 2.3 信号源层：无米之炊

- strategy_list 共 **125 条策略**，首页 20 条几乎全是 `TEST-*` 测试策略，**全部 performanceStatus=unmeasured**（strategy_list，2026-10-19）。策略库被测试残留污染，且无任何一条有业绩证据。
- ML 模型为弱信号（历史实测 test_roc_auc≈0.58），evolution_run 多次诚实降级。

### 2.4 机制运行层：进化机器近期在大量失败

- 调度器 57 个任务中，进化与例程类 Agent 任务最近运行**大面积 ❌ failed**：evolution-distill-daily、evolution-gate-adjudicate、evolution-weekly-variant、agent-brain-weekly-evolution / weekly-distill / weekly-roi / daily-review / daily-audit / morning-analysis / candidate-hunt / core-plan、meta-learning-weekly、strategy-loop-weekly、weekly-report-m6、post-market-routine、pre-market-routine 等（scheduler_manage list，2026-10-19）。
- 即：进化机制不仅"空转"，最近还在"故障空转"——失败原因尚未排查，可能与其产出无价值互为因果。

## 3. 根因假设（待 spike 验证）

1. **北极星错位**：进化 KPI 实质是"系统不出错"（工程纪律），从未以"信号胜率/决策超额/账户收益改善"为目标函数。
2. **反馈环断裂于源头**：零交易 → 零自有样本 → R-016 封锁交易层进化 → 永远无样本。
3. **输入质量不治理**：策略库 TEST 残留 + 100% unmeasured、经验库 77.5% unknown-symbol 噪声，蒸馏出来的结论必然是垃圾（GIGO）。
4. **失败无告警闭环**：进化任务连续失败没有触发修复动作，机制"假装在跑"。

## 4. 候选破局方向（需求分析阶段需对比取舍）

## 5. 范围

**In scope**：进化目标函数重定义、样本来源机制、策略库与经验库治理方案、进化任务失败闭环；产出调研报告 + 推荐方案 + 分阶段验收指标。
**Out of scope**：直接修改任何 R-xxx 交易规则/仓位档位/止损线（受 R-016 约束）；真金账户；大规模策略重写。

## 9. 边界（不做什么）

- 只动进化链路的"度量、触发、样本、输入"四环，不动交易决策规则本身；
- 小仓位试单仅出方案与授权边界建议，执行与否由用户拍板；未获授权前不在 agent_brain 开任何新仓；
- 策略库/经验库的删除类操作必须留 decision_audit + memory 痕迹，可回溯；
- agent-os 执行器修复限于"webhook 任务通道选择"问题，不做执行器重构。

## 8. 结论

用户的负反馈经实证成立：进化闭环在**投资结果层零产出**（agent_brain 现金 96.9%、自有决策评分 0 条）、**内容层零交易进化**（基因组近 20 版全为工程纪律）、**运行层假运转**（进化类定时任务大面积 failed，根因为 webhook 任务被执行器按占位 command 执行）。改造路径确定为四阶段：P1 修触发 → P2 立度量（信号胜率/决策超额为北极星 KPI）→ P3 通样本（观察计分先行、授权试单后置）→ P4 清输入（策略库/经验库治理）。spike 交付调研报告 + 推荐方案 + 可证伪验收指标，详见 [design/design.md](design/design.md)。

## 11. 需求条款（G2 定义行）

- **SP-1: 修复进化任务触发链**——定位并修复调度器对 webhook 任务执行占位 command 的根因，使进化类 Agent 任务真实触发。
- **SP-2: 建立北极星 KPI 与周报度量**——定义信号胜率/决策超额/机制健康度三项指标，周报强制回答进化带来的 KPI 变化，连续无改善自动降频。
- **SP-3: 打通样本来源**——观察计分 SOP 全级别落地（零风险先行），小仓位试单仅出授权边界建议书交用户决策。
- **SP-4: 输入治理清单**——策略库 TEST 残留与经验库 unknown-symbol 噪声盘点成清单与处置建议，处置动作经用户确认后执行。
