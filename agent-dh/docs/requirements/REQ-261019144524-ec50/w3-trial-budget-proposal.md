## 1. 四项授权边界（建议值）

| 边界项 | 建议值 |
|---|---|
| 单笔试单金额 | ≤ 5,000 元（≈ 总资产 1%） |
| 试单总敞口 | ≤ 10,000 元（≈ 总资产 2%），同时持仓 ≤2 只 |
| 信号门槛 | 仅 A 级信号（R-009，≥3 维共振）；B/C 级一律不交易 |
| 止损纪律 | 宪法第 4 条铁律不豁免（蓝筹 -8% / 成长 -10% / 小盘 -12%），月度试单亏损 2,500 元熔断 |

确认链（R-001/R-008/R-005）与三重仓位钳制（R-006/R-007/服务端 80% 硬顶）均不豁免。详见 RFC 017 §2/§4。

## 2. 最坏情形测算

月度亏损熔断 2,500 元 ≈ 总资产（49.90 万，account_info 2026-10-20 快照）的 **0.50%**，仅占 R-007 熔断阈值（8%≈3.99 万）的 **6.3%**；试单敞口 1 万元全部同时触发 -10% 止损需约 2.5 轮「全灭」才触及月度熔断。测算与占比表见 RFC 017 §3。
