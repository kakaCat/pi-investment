队列 DAG 卡片类型可视化原型

基于 真实队列数据 的 DAG 可视化设计，展示卡片类型系统（phase/side/role 三轴）与交互功能。
数据来源：全仓 queue.json 文件 · 关联需求 REQ-260928001915-f978

① 卡片类型系统（7 类任务类型）

每张卡通过 phase 字段决定类型徽标文案，通过 status 决定底色， 通过 role 决定卡形（父卡/子卡/独立卡）。

② 角色三态（父卡 / 子卡 / 独立卡）

父卡带左侧蓝条 + 子卡链进度（4 段：dev/integrate/review/test）， 子卡缩进显示，独立卡为普通节点。

③ 真实 DAG（用队列 edges 画连线）

节点位置 = 队列 layers[]，连线 = 队列 edges[]。 悬停任一卡：橙色 = 上游、蓝色 = 下游；点击钉住。

📊 示例 DAG 简化示例（12 张卡）
已完成链路 进行中 / 待办 🟠 上游（它依赖谁） 🔵 下游（谁依赖它） 🟢 绿点 = 可开工
交互提示：鼠标移到任意卡片上即可看到它的上下游链路高亮，点击可以钉住。 完整交互功能（关键路径、主线折叠）见 dag-card-types-demo.html。
