# 用例设计（REQ-260923134706-e72f）

## 1. 场景总览 <!-- serves: FR-1 -->

主角：盯流程的人（用户）。场景：会话标题栏流程图 → 点节点 → 就地看这一步"交付了什么 + 是否按规定执行"。
面板是**索引**不是阅读器：所有长文档都从面板点开去右侧栏读。

## 2. 主流程 <!-- serves: FR-1, FR-2, FR-4, FR-5, FR-6, FR-7, FR-9 -->

**UC-1 点开面板（FR-1/FR-9）**：绑定需求的会话 → 点流程图「拆分」→ 面板出现在流程条正下方右对齐（间隙 8px），
无遮罩、无底部按钮、右上角有 ×；点面板外或 × → 收起。

**UC-2 读面板头（FR-2）**：任一点开的节点 → 第一行 `REQ-xxx` 胶囊 + 需求标题；第二行状态胶囊
（已立项/已分析/已设计/已拆分/实施中/待验收/已归档）+ 一句话进展 + 相对时间。

**UC-3 看交付物（FR-3/FR-4）**：「需求分析」→ 基础信息（默认展开）列产物文档 → 点条目右侧栏打开全文；
「设计」→ 设计文档逐份 ✅已交/⬜未交；「拆分」→ 拆分计划 + DAG 分层；「归档」→ ✅ 已归档徽标 + 归档文档 + 合并去向 + 一句话结论。

**UC-4 看任务怎么走（FR-5/FR-7）**：「实施」→ 默认「流程图」= DAG 分层（点节点开任务卡）→ 切「泳道」=
6 条状态道横向卡片（窄窗口可横滑、无裁切）。

**UC-5 核对是否按规定执行（FR-6）**：任一节点 → 展开「🔄 执行流程」→ 三段：提示词注入（规定原文，可点开）/
执行动作对照（规定动作 ✅/⬜ + 出处）/ 上下文管理（真实隔离留痕）。

## 3. 异常与空态 <!-- serves: FR-4, FR-6 -->

| 场景 | 面板表现 |
|---|---|
| 分类跳过的节点（如 bug 跳过需求分析） | 显示「本分类跳过」，三段不渲染 |
| 该窗口无注入/隔离留痕 | 对应段显示「尚无注入留痕 / 尚无隔离留痕」空态 |
| 节点无产物/无任务 | 基础信息「尚无内容」；执行动作对照全 ⬜「未见记录」 |
| 无进行中需求（最近完成锚点） | 面板照常可看（既有行为保留），不新增干扰 |
