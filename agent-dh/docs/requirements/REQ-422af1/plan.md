## 做什么（目标 + 做法）

把「每个流水线节点注入哪段提示词」从一份常量改成**路由解析**：路由键 = (节点, 难度, 立项类型)，5 级回退链解析；提示词写成 md 分片、构建期内联成常量；注入受预算约束并留痕。每个节点都可按难度切档（不是只做 brainstorming）。随后（P3）在节点边界**在同一个窗口里遗弃模型可见的上下文**，用「下一节点输入包」（提示词 + 文档 + 台账投影）整段替换——省 token，跨节点状态只靠文档承载。

    P0  路由骨架 + 现有 6 份提示词原样落位 + 6 条新门禁 + 快照逐字等价（零行为变更）
