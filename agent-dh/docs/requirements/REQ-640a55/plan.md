# REQ-640a55 拆分计划（design → decomposing 的交棒件）

## 目标

让三处「承诺了却没生效」的门禁真正执行：三要素门禁接上执行链（`task_card_incomplete` 可被产出）、
拆分骨架直出三要素节、编号跳号与重复两处死门禁复活。**只让实现追上已有承诺，不改提示词、不改状态机。**

## 做法

按依赖顺序分三个批次落 5 张卡：

1. 先修两处编号判据（纯函数、零接线风险，可独立单测证伪）；
2. 再让拆分骨架与兜底骨架头直出三要素节（**接线的前置**：否则接线会把所有新卡拦死）；
3. 最后接线两个调用点（拆分出口 + 单卡结单）并冻结兼容（T-9 改卡通道新旧标题双命中）。
