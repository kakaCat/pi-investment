## 反向验证（serves: FR-1, FR-3, FR-4）

只测成功路径等于没测。三处判据各改坏一次，对应用例必须变红：

| 破坏 | 期望 |
|---|---|
| 骨架把 `## 在做什么` 改回 `## 目标` | 出口拦截用例从「放行」变「拒绝」（证明门禁真在跑） |
| 重复判定的输入改回「去重后的清单」 | 重复用例变红 |
| 跳号正则改回 `(d+)` | 跳号用例变红 |
