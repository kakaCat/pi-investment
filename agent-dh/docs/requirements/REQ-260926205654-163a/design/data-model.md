# 数据模型设计文档

**需求ID**: REQ-260926205654-163a

## 数据模型变更 «serves: FR-3»

**无数据模型变更**。需求编号作为字符串字段存储，格式变化不影响数据模型。

## 数据存储 «serves: FR-2, FR-3»

**需求编号字段**：
- **字段名**：`id` 或 `requirement_id`
- **类型**：`string`
- **格式**（修改前）：`REQ-YYMMDDHHmmss-xxxx`
- **格式**（修改后）：`REQ-YYYYMMDDHHmm-xxxx`
- **存储方式**：按字符串原样存储，不解析
- **索引**：主键或唯一索引（按字符串）

## 数据兼容性 «serves: FR-3»

- **存储兼容**：新旧格式都是字符串，长度都是 `REQ-` + 14位 + `-` + 4位 = 22字符
- **查询兼容**：按字符串精确匹配，格式变化不影响查询
- **迁移不需要**：旧数据保持不变，新数据使用新格式
