## 主用例 `serves: FR-1, FR-2, FR-3, FR-4, FR-5`

UC-1：打开会话 → 点流程图节点展开面板 → 选中实施阶段并切到 [DAG] 页签 → 面板 HTML 注入 → `tryMountDagCanvas` 在 rAF 后
找到画布并挂载 → 画布按容器宽度绘制（2026-09-29 裁定 B：面板无标题行 / 无统计条）→ 悬停高亮上下游、单击钉住、
切纵向/横向、开关键路径与只看主线。

UC-2：选中拆分阶段 → 同一 `buildDagCanvas` 产出同结构面板 → 走同一条挂载路径（拆分阶段无页签，画布常显）。

UC-3：需求详情的 DOM 骨架与 UC-1/UC-2 逐项相同（同样无标题行 / 统计条）；它仍传队列 `ready[]`，只影响画布上的可开工绿点。

## 异常与边界 `serves: FR-4, FR-5`

- 画布不在 DOM（面板未展开 / 阶段未渲染）：`tryMountDagCanvas` 静默返回——不抛、不报错、不留空白块。
- 同 id 重复挂载（SSE 重绘、页签来回切）：先释放旧实例再挂新的，DOM 中该 id 始终只有一块画布。
- 同页两实例（会话面板 + 需求详情）：id 不同、实例表互不干扰，各自保留自己的工具条状态。
- 空任务 / 环形依赖：沿用既有降级（空态占位串 / 画布内一行说明），不新增异常分支。
- `ready` 两态：`undefined` = 推导（标「推导」）；`[]` = 队列确实无 ready（不标）——不得混同。
