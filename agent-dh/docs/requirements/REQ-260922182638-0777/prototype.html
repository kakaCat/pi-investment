§1 节点追溯链（stage-panel.ts）

位置：阶段详情面板底部「产物追溯链」一行。v2 规则：单份产物显示种类名；design 同类多份显示文件名层中文名；任务卡逐张展开。

改造前
追溯链：需求文档→architecture.md→interfaces.md→拆分计划→任务卡×2→new_proposal
  • design 多份裸显英文文件名（architecture.md / interfaces.md）；
  • 任务卡折叠成「任务卡×2」，看不到每张三卡；
  • 未知 kind（如 new_proposal）裸显英文枚举。
改造后
追溯链：需求文档→架构文档→接口文档→拆分计划→任务卡 · 新增映射模块→任务卡 · 收敛四处引用→产物（new_proposal）
  • design 每份文档显示中文文档名（架构文档 / 接口文档），tooltip 仍带完整路径；
  • 任务卡逐张列出且带任务名称（任务卡 · 新增映射模块），一眼知道每张卡干什么；
  • 未知 kind → 产物（原枚举值）。

  • DOC_KIND_META 与追溯链表各自维护已漂移；文件名位裸显英文；未知 kind 图标 📒 + 裸显英文。
改造后
  • 📄需求文档docs/requirements/REQ-xxx/requirement.md
  • 📐设计文档 · 架构文档…/design/architecture.md
  • 📒产物（extras_review） · review.html…/review.html
  • 中文名来自同一映射模块的两层函数；格式不变仅取值收敛；路径列仍显示真实文件名。图标归属不变。
