# 文档记录展示 - 设计文档

> REQ-7f6a8e · 测试文档 · 用于验证文档记录展示与健壮性校验

## 背景

需求详情页需要展示该需求关联的文档（需求文档、UI 文档、设计文档等）。
本文档作为「设计文档」落盘测试，验证：
1. 文档落盘后被记录到需求（docLinks.proposal）
2. 需求详情页「📁 文档记录」区块正确展示
3. 文件存在性校验正常工作（存在 → 可点击打开）

## 设计要点

- 文档类型：requirement（需求）/ ui（UI）/ proposal（设计）/ plan（计划）/ verification（验收）/ retro（复盘）
- 展示：图标 + 类型标签 + 路径（可点击弹窗打开）
- 健壮性：不存在的文档标注「文件缺失」，不当作有效文档
