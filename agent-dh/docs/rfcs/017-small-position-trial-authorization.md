## 1. 背景与目的

投资脑（agent_brain）当前处于极低仓位运行期：总资产 49.90 万元中可用资金 48.36 万元（占 96.9%），持仓仅 2 只、市值 1.54 万元，累计总盈亏 -0.94%（数据：account_info 工具，2026-10-20 时点）。

空仓等待本身是合法决策（宪法第 6 条），但长期接近零仓位带来两个工程问题：

1. **交易链路缺乏实盘验证**——信号分级（R-009）、买入确认链（R-001）、对账（R-004）、决策评分回流（R-008 扩展）等环节长期无真实样本，观测面指标（信号胜率、决策评分、滑点）因无样本而持续空转；
2. **经验积累停滞**——experience 库与 decision_scores 对自有账户 agent_brain 的覆盖为 0 条（2026-09-13 实测，见 R-018），学习飞轮无自有燃料。

本建议书提议：在用户显式授权的**严格边界内**，允许投资脑以「小仓位试单」方式对 A 级信号执行真实委托，用最小风险换取链路的真实验证与样本积累。

## 2. 建议的授权边界

| 边界项 | 建议值 | 依据 |
|---|---|---|
| 单笔试单金额上限 | ≤ 5,000 元（≈ 总资产 1%） | 远低于宪法单股 20% 上限（约 10 万元） |
| 同时试单持仓数 | ≤ 2 只 | 控制跟踪与复盘成本 |
| 试单总敞口上限 | ≤ 10,000 元（≈ 总资产 2%） | 远优于宪法现金 ≥10% 要求（当前现金 96.9%） |
| 信号门槛 | 仅 A 级信号（R-009，≥3 维共振）；B/C 级一律不交易 | 与现行信号分级纪律一致 |
| 确认链 | 每笔仍完整走 R-001（价格/资金/仓位上限/建议仓位）+ R-008（教训检索）+ R-005（reason 必填） | 不因试单豁免任何确认环节 |
| 止损 | 按宪法第 4 条铁律执行（蓝筹 -8% / 成长 -10% / 小盘题材 -12%），触发即卖、不补仓不摊平 | 宪法不可协商 |
| 仓位上限 | 仍受 R-006 regime 档位、R-007 熔断与服务端 80% 硬顶钳制 | 三重钳制不豁免 |
| 月度亏损熔断 | 试单累计月亏损达 2,500 元 → 当月停止一切新开仓，仅允许止损卖出 | 本建议书新增的自限条款 |

## 3. 风险测算：最坏情形月亏损 2,500 元对账户的影响

口径：2,500 元为「试单月度亏损熔断」上限，即最坏情形下当月试单亏损被硬截断在此水位。

| 维度 | 数值 | 占比 |
|---|---|---|
| 对总资产（49.90 万元） | 2,500 / 499,000 | **≈ 0.50%** |
| 对可用资金（48.36 万元） | 2,500 / 483,600 | ≈ 0.52% |
| 对当前累计盈亏（-0.94%，约 -4,700 元） | 叠加后约 -7,200 元 | 总回撤约 -1.44% |
| 对 R-007 熔断阈值（60 日回撤 8% ≈ 3.99 万元） | 2,500 元仅占阈值的 6.3% | 余量充足，不触及熔断 |

情景推演：试单总敞口 1 万元若**全部持仓同时触发 -10% 止损**，单轮亏损约 1,000 元；需连续约 2.5 轮「全灭」才触及 2,500 元月度熔断——这是极端悲观情形。正常情形下 A 级信号（≥3 维共振）触发全灭的概率显著更低。

结论：最坏情形月亏损 2,500 元对账户的影响约 **0.5 个百分点**的回撤，处于宪法与 R-007 熔断框架内的安全水位，不会危及现金纪律（现金占比仅从 96.9% 降至约 96.4%）。

## 4. 不授权范围（显式排除）

- 不授权任何 B/C 级信号的委托（维持只观察不交易）；
- 不授权突破宪法任何条款（时段/T+1/仓位/止损/数据驱动）；
- 不授权对策略线账户（v13/v14/v15/chip_simulation）或 agent_virtual 的任何写操作（R-019 边界不变）；
- 不授权因试单亏损而放宽止损线或「补仓摊平」；
- 本建议书未获批准前，**不授权任何委托**。

## 5. 有效期与复审

- 试行期：**2026-10-20 ~ 2026-11-19**（批准之日起 1 个自然月）；
- 复审机制：每周日例行复盘（stock-pool-weekly-review / M6 周报）附带试单小节：成交笔数、胜率、滑点、是否触及月度熔断；
- 用户可随时口头/书面撤销授权，撤销即时生效，既有持仓仅按止损纪律处置；
- 试行期满未获续批 → 自动回到现行纪律（零交易合法）。
