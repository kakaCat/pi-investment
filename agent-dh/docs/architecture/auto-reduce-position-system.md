# 自动减仓与止损系统

**版本**: v1.0  
**制定日期**: 2026-09-19  
**状态**: 已实施（华兰生物已设置止损）

## 目标

自动识别并执行减仓操作，防止亏损扩大，锁定盈利。

## 触发规则

### 止损触发（自动执行）
- **大盘蓝筹**: 浮亏达-8%自动全部卖出
- **成长股**: 浮亏达-10%自动全部卖出  
- **小盘题材**: 浮亏达-12%自动全部卖出

### 止盈触发
- **第一档**: 盈利+10% → 自动卖出50%（锁定部分利润）
- **第二档**: 盈利+20% → 人工确认后再卖30%
- **第三档**: 盈利+30% → 人工确认后全部卖出

### 持仓健康检查（每日15:30）
检查项：
1. 盈亏比例是否触发止损/止盈
2. 是否有未设置止损的持仓
3. 是否有风险事件（解禁/减持/业绩预警）
4. 主力资金是否持续流出（连续3日）

## 执行机制

### 自动执行（无需确认）
- ✅ 止损触发：立即卖出
- ✅ 止盈第一档：自动减半仓

### 人工确认（30分钟窗口）
- ⚠️ 止盈第二、三档
- ⚠️ 风险事件减仓
- ⚠️ 主力流出减仓
