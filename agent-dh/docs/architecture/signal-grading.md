# 信号分级制（Signal Grading System）

**版本**: 1.0  
**生效日期**: 2026-08-31  
**基于**: Genome Rules v7 R-009

---

## 1. 概述

信号分级制是 PI Investment 系统的核心决策框架，用于评估买入信号的可靠性并映射到相应仓位。通过多维度共振判断，将信号分为 A/B/C 三级，实现风险与收益的平衡。

**核心原则**：
- **维度共振**: 多个独立维度同时验证，提高信号可靠性
- **仓位分级**: 可靠性越高，仓位越大
- **风险控制**: 低质量信号不交易，避免冲动决策

---

## 2. 分级定义

### 2.1 A 级信号（标准仓）

#### 条件
**≥3 个独立维度共振，无明显矛盾**

#### 四大维度清单

| 维度 | 检查项 | 通过标准 |
|------|--------|---------|
| **1. 主线共振** | 标的是否属于当日 Top 3 主线板块 | 在主线涨停名单或相关产业链 |
| **2. 技术面** | 是否突破关键位 | MA 金叉 / MACD 金叉 / 布林带上轨突破 |
| **3. 资金面** | 主力资金流向 | 净流入 >0 且连续 3 日流入 |
| **4. 基本面** | 财务质量与风险标记 | ROE >15% / PE <30 / 无 ST / 无操纵嫌疑 |

#### 仓位规则
**标准仓位**（`risk_controller position_size` 建议仓位，通常为可用资金的 15-20%）

#### 操作规范
- ✅ 可交易
- 必须调用 `signal_track(grade='A', source=..., reason=...)`
- `portfolio_trade` 的 `reason` 参数必须注明 "A级信号"

---

### 2.2 B 级信号（半仓）

#### 条件
**2 个维度同向 或 有轻微矛盾**

**典型场景**:
- 技术面 + 主线共振，但资金面单日流出（整体趋势仍为流入）
- 技术面 + 资金面，但主线不在 Top 3（在 Top 10 或相关产业链）
- 主线 + 基本面，但技术面尚未明确突破

#### 仓位规则
**半仓**（建议仓位 × 0.5）

#### 操作规范
- ✅ 可交易（谨慎）
- 必须调用 `signal_track(grade='B', ...)`
- `reason` 注明 "B级信号"

---

### 2.3 C 级信号（仅观察）

#### 条件
**单维度信号 或 高维度矛盾**

**典型场景**:
- 仅技术面突破，但无主线共振、资金流出、基本面瑕疵
- 多维度矛盾（如技术突破但主力大幅流出、或主线热点但财务恶化）

#### 仓位规则
**零仓**（不交易）

#### 操作规范
- ❌ 禁止交易
- 仅调用 `signal_track(grade='C', ...)`（观察记录）
- 用于验证信号有效性，积累判断经验

---

## 3. 仓位映射表

| 信号级别 | 共振维度 | 仓位比例 | 操作 | 记录工具 |
|---------|---------|---------|------|---------|
| **A 级** | ≥3 维度 | 100% 建议仓位 | ✅ 可交易 | `signal_track(grade='A')` |
| **B 级** | 2 维度或轻微矛盾 | 50% 建议仓位 | ✅ 可交易（谨慎） | `signal_track(grade='B')` |
| **C 级** | 1 维度或高维矛盾 | 0% | ❌ 仅观察 | `signal_track(grade='C')` |

**示例计算**:
```
假设 risk_controller position_size 建议买入 1000 股
- A 级信号: 买入 1000 股（100%）
- B 级信号: 买入 500 股（50%）
- C 级信号: 不买入（0%）
```

## 4. 历史回溯示例

### 4.1 A 级信号示例

**标的**: 600519（贵州茅台）  
**信号日期**: 2026-08-25  
**信号来源**: `mainline_stocks`（主线「白酒」板块）

#### 四维度检查

| 维度 | 检查结果 | 说明 |
|------|---------|------|
| ✅ 主线共振 | 通过 | 属于 08-25 主线「白酒」板块（Top 2 主线，13 只涨停） |
| ✅ 技术面 | 通过 | MACD 金叉（DIF 上穿 DEA），突破 20 日均线（1850 → 1880） |
| ✅ 资金面 | 通过 | 主力净流入 +1.2 亿，连续 3 日流入（08-23/24/25） |
| ✅ 基本面 | 通过 | ROE 28%，PE 25x，无 ST 标记，无操纵嫌疑 |

**分级判定**: **A 级**（4/4 维度通过）

**操作记录**:
```javascript
// 1. 记录信号
await signal_track({
  action: 'record',
  symbol: '600519',
  price: 1880.00,
  source: 'mainline_stocks',
  grade: 'A',
  reason: '白酒主线+MACD金叉+主力流入+基本面优质'
});

// 2. 计算仓位
const positionSize = await risk_controller({
  command: 'position_size',
  symbol: '600519',
  price: 1880.00
});
// 返回: 建议买入 500 股

// 3. 执行交易（A 级 → 100% 仓位）
await portfolio_trade({
  action: 'BUY',
  symbol: '600519',
  quantity: 500,  // 100% 建议仓位
  reason: 'R-009 A级信号：白酒主线+MACD金叉+主力流入+基本面优质'
});
```

**实际结果**:
- 5 日收益: +8.2%（1880 → 2034）
- 10 日收益: +12.5%
- **验证**: ✅ A 级信号可靠性得到验证

### 4.2 B 级信号示例

**标的**: 000858（五粮液）  
**信号日期**: 2026-08-26  
**信号来源**: `sector_analysis`（白酒行业分析）

#### 四维度检查

| 维度 | 检查结果 | 说明 |
|------|---------|------|
| ✅ 主线共振 | 通过 | 属于「白酒」板块（08-25 主线，08-26 延续） |
| ✅ 技术面 | 通过 | RSI 从超卖区（28）反弹至 45，K线出现锤子线 |
| ⚠️ 资金面 | 轻微矛盾 | 主力净流出 -0.5 亿（仅单日，前 5 日累计净流入 +2.3 亿） |
| ✅ 基本面 | 通过 | ROE 22%，PE 18x，无风险标记 |

**分级判定**: **B 级**（3/4 维度通过，资金面轻微矛盾）

**操作记录**:
```javascript
await signal_track({
  action: 'record',
  symbol: '000858',
  price: 168.50,
  source: 'sector_analysis',
  grade: 'B',
  reason: '白酒主线+RSI超卖反弹+基本面优，但单日资金流出'
});

const positionSize = await risk_controller({
  command: 'position_size',
  symbol: '000858',
  price: 168.50
});
// 返回: 建议买入 600 股

// B 级 → 50% 仓位
await portfolio_trade({
  action: 'BUY',
  symbol: '000858',
  quantity: 300,  // 50% 建议仓位
  reason: 'R-009 B级信号：白酒主线+RSI反弹，资金面轻微矛盾'
});
```

**实际结果**:
- 5 日收益: +3.1%（168.50 → 173.72）
- 10 日收益: +1.8%（震荡）
- **验证**: ✅ B 级信号半仓策略合理（收益有限但风险可控）

### 4.3 C 级信号示例

**标的**: 600036（招商银行）  
**信号日期**: 2026-08-27  
**信号来源**: `opportunity_scan`（技术面扫描）

#### 四维度检查

| 维度 | 检查结果 | 说明 |
|------|---------|------|
| ❌ 主线共振 | 未通过 | 不属于当日主线板块（08-27 主线: 半导体/通信设备） |
| ✅ 技术面 | 通过 | 突破前期高点（43.20 → 43.85），MACD 即将金叉 |
| ❌ 资金面 | 未通过 | 主力净流出 -2.3 亿，连续 2 日流出 |
| ⚠️ 基本面 | 有瑕疵 | ROE 13.5%（偏低），PB 0.8x（银行业估值压制） |

**分级判定**: **C 级**（1/4 维度通过，高维度矛盾）

**操作记录**:
```javascript
// 仅记录观察，不交易
await signal_track({
  action: 'record',
  symbol: '600036',
  price: 43.85,
  source: 'opportunity_scan',
  grade: 'C',
  reason: '仅技术面突破，无主线共振，资金流出，银行业估值压制'
});

// C 级信号 → 不执行 portfolio_trade
```

**实际结果**:
- 5 日收益: -1.2%（43.85 → 43.32）
- 10 日收益: -2.8%
- **验证**: ✅ C 级信号不交易策略正确（避免亏损）

## 5. 实施规范

### 5.1 Agent 执行流程

```
1. 发现买入机会
   ├─ opportunity_scan（机会扫描）
   ├─ mainline_stocks（主线标的）
   └─ sector_analysis（行业分析）
         ↓
2. 四维度检查（逐一核对）
   ├─ 主线共振: market_theme 当日 Top 3
   ├─ 技术面: factor_calculate（RSI/MACD/MA）
   ├─ 资金面: factor_values（main_net_inflow/large_net）
   └─ 基本面: data_fetch_financial + manipulation_detect
         ↓
3. 分级判定
   ├─ ≥3 维度通过 → A 级
   ├─ 2 维度通过或轻微矛盾 → B 级
   └─ 1 维度或高维矛盾 → C 级
         ↓
4. 仓位计算
   ├─ A 级: risk_controller position_size × 1.0
   ├─ B 级: position_size × 0.5
   └─ C 级: 0（不交易）
         ↓
5. 记录信号（必须）
   signal_track(grade='A'/'B'/'C', source=..., reason=...)
         ↓
6. 执行交易（A/B 级）
   portfolio_trade(..., reason='R-009 X级信号：...')
         ↓
7. 后续追踪（自动）
   - M3-3 信号质量追踪系统自动回填 5/10/20 日表现
   - M6 周报统计分级别胜率
```

### 5.2 维度检查工具清单

| 维度 | 工具 | 核心字段 |
|------|------|---------|
| 主线共振 | `market_theme` 表 | trade_date, theme, stocks |
| 技术面 | `factor_calculate` | rsi, macd, ma20 |
| 资金面 | `factor_values` | main_net_inflow, large_net |
| 基本面 | `data_fetch_financial` + `manipulation_detect` | roe, pe, pb, 操纵评分 |

### 5.3 验证规则

#### 信号记录（强制）
- 所有信号必须调用 `signal_track`
- `grade` 参数必填（'A'/'B'/'C'）
- `reason` 参数必须说明各维度判断结果

#### 交易规则
- C 级信号禁止调用 `portfolio_trade`
- A/B 级信号 `reason` 必须包含 "R-009" 和级别标注
- 仓位必须符合映射表（A=100%, B=50%, C=0%）

#### 追踪规则
- M3-3 系统自动回填 5/10/20 日表现
- M6 周报按级别统计胜率
- 目标：A 级胜率 ≥60%，B 级胜率 ≥50%

## 6. 边界案例处理

### 6.1 维度数据缺失

| 场景 | 处理 |
|------|------|
| 主线数据缺失（市场无明显主线） | 该维度标记为"不适用"，降级为 B/C 级 |
| 资金流数据缺失（新股/停牌复牌） | 该维度跳过，至少需其他 2 维度通过才能交易 |
| 技术指标计算失败（K线不足） | 禁止交易（数据质量不足） |

### 6.2 矛盾处理

| 场景 | 判定 |
|------|------|
| 3 维度强通过，1 维度轻微矛盾 | A 级（轻微矛盾可容忍） |
| 2 维度强通过，2 维度明显矛盾 | C 级（高维矛盾） |
| 4 维度全部临界通过 | B 级（信号不够强） |

### 6.3 特殊市场环境

| 环境 | 调整 |
|------|------|
| 市场恐慌（regime=panic） | 提高标准：A 级需 4/4 维度 |
| 市场狂热（regime=euphoria） | 提高标准：降低仓位（A=80%, B=40%） |
| 市场震荡（regime=sideways） | 标准不变 |

## 7. 进化与优化

### 7.1 胜率目标

| 级别 | 5 日胜率目标 | 10 日胜率目标 | 20 日胜率目标 |
|------|-------------|--------------|--------------|
| A 级 | ≥60% | ≥55% | ≥50% |
| B 级 | ≥50% | ≥45% | ≥40% |
| C 级 | N/A（不交易） | N/A | N/A |

### 7.2 迭代机制

- **每周审查**: M6 周报显示分级别胜率，未达标时调整分级标准
- **每月进化**: 通过 `evolution_run` 优化维度权重
- **季度复盘**: 回测全部信号，验证分级制有效性

### 7.3 候选改进方向

1. **引入量化评分**: 每个维度 0-100 分，总分 ≥240 为 A 级
2. **行业差异化**: 不同行业采用不同权重（如科技股技术面权重更高）
3. **机器学习**: 用历史信号训练分类模型，自动分级
