    降级与边界状态（预览）——真实实现里这四种必须如实显示，不允许拿空 diff 冒充「无改动」
    binary

    git 判为二进制或含 NUL 字节：只列路径与「二进制」标签，不给行。

    oversized

    某一侧超过 maxFileBytes：只列路径、不给计数、不做对比。

    coarse

    行比对超过 diffTimeoutMs：退化为「整文件一删一增」，标注「粗粒度」，避免大文件卡死。

    baseline / session disposed

    Session 已释放或 Host 重启：卡片与对比都不再存在。任务卡只能显示「本轮无可对账快照」，并保留文件名清单——这正是要把「实施中的快速看」与「验收留档」分开的原因。
