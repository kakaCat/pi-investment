## 各部分详细说明

### 1. 统计卡片区
```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│  全部任务    │   │   进行中     │   │   测试中     │
│             │   │             │   │             │
│     45      │   │      8      │   │      3      │
│             │   │             │   │             │
└─────────────┘   └─────────────┘   └─────────────┘
   (灰色)            (蓝色)            (紫色)

✨ 特性:
- 鼠标悬停: 卡片上浮 + 阴影
- 点击: 高亮激活 + 联动筛选器
- 语义化颜色: 阻塞(红)、完成(绿)
```

### 2. 工具栏
```
┌────────────────────────────────────────────────────────────┐
│ 状态: [全部 ▾] 阶段: [全部 ▾] 端侧: [全部 ▾] 需求: [全部 ▾]  │
│ 排序: [最近更新 ▾]                    [分组] [列表] [时间线]│
└────────────────────────────────────────────────────────────┘

筛选选项:
• 状态: 待办/进行中/联调/测试/评审/完成
• 阶段: 文档/UI/分析/实施/测试/评审/合并
• 端侧: 前端/后端/全栈/文档
• 需求: 下拉显示所有需求ID

视图模式:
• 分组视图 (默认): 按需求分组
• 列表视图 (Phase 2): 扁平列表
• 时间线视图 (Phase 2): 甘特图为主
```

## 响应式布局

**桌面 (>768px)**:
```
统计卡片: 6列网格
工具栏: 横向排列，视图切换器右对齐
```

**平板 (≤768px)**:
```
统计卡片: 2列网格 (3行)
工具栏: 垂直堆叠
```

**手机 (≤480px)**:
```
统计卡片: 1列 (6行)
工具栏: 垂直堆叠，每项占满宽
```
