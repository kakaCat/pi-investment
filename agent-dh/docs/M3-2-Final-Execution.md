### 步骤1：查询可用策略

在 DSH 中执行：
```

```

从152个策略中筛选适合回测的策略（建议选择不同类型）。

### 步骤2：执行回测矩阵

选定策略后，对每个策略×环境组合执行：

```
strategy_execute(
  strategy_id=<策略ID>,
  mode='backtest',
  symbols=['000001'],  # 或其他标的
  start_date='2026-01-01',
  end_date='2026-02-28',
  initial_capital=100000
)
```

### 步骤3：收集结果并生成报告

使用 `memory_write` 保存结果，生成排名表。
