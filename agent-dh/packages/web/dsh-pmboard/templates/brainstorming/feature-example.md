# 需求说明（REQ-260101-001）

> 本文档面向：产品、开发、测试、用户——写给人看，不是写给代码看。
> 核心原则：**用户能看懂**——不写技术术语，用场景和结果说话。

## 产品定义 <!-- serves: FR-1 -->

**股票池智能推荐系统**：投资者在分析股票时，系统根据其历史关注的行业、持仓风格、近期市场热点，自动推荐相关的股票池（如"高ROE成长股"、"低估值蓝筹"、"新能源产业链"等），并显示每个池子的核心特征、最新表现和进入理由。

核心价值：从"不知道看哪些股票"到"系统主动推荐相关股票池"，降低选股门槛、提高决策效率。

**三要素检查清单**：
- [x] 说清楚"是什么"（智能推荐股票池的系统）
- [x] 说清楚"核心价值"（解决选股迷茫、提高决策效率）
- [x] 说清楚"与现状的区别"（主动推荐 vs 手动翻找池子列表）


## 目标用户与使用场景 <!-- serves: FR-1 -->

**目标用户**：
- **个人投资者**：有一定投资经验，关注特定行业或风格，但不知道如何系统化选股
- **投资顾问**：需要快速为客户推荐符合其风险偏好的股票组合

**使用场景**：
1. **早盘准备**：投资者打开系统，查看今日推荐的股票池（基于市场热点和个人偏好）
2. **持仓调整**：投资者持有某只股票后，系统推荐同行业或同产业链的其他标的
3. **行业研究**：投资者关注新能源行业，系统推荐"光伏产业链上游"、"锂电池中游"等细分池子
4. **风险分散**：投资者持仓集中在科技股，系统推荐低相关性的防御型股票池

**当前痛点**：
- 股票池列表有30+个，投资者不知道该看哪几个
- 手动筛选费时费力，容易错过优质标的
- 不了解每个池子的特点和适用场景

### FR-1：首页推荐卡片展示

**功能描述**：投资者打开系统首页时，在醒目位置看到"今日推荐股票池"卡片，展示3-5个系统智能推荐的股票池，每个池子显示名称、核心特征、最新涨跌幅、推荐理由。

**详细说明**：
- **使用场景**：投资者早盘9:15打开系统，准备当日交易决策
- **操作流程**：
  1. 投资者登录系统，进入首页
  2. 首页顶部展示"今日推荐股票池"模块（占据首屏1/3空间）
  3. 每个推荐池显示：池名称、标签（如"成长"、"防御"）、今日平均涨跌幅、推荐理由（1-2句话）
  4. 点击任一池子，进入该池子详情页
- **预期结果**：
  - 投资者无需翻找，直接看到与其相关的股票池
  - 通过涨跌幅快速判断当日市场风格
  - 通过推荐理由理解为什么推荐这个池子
- **边界条件**：
  - 新用户（无历史记录）显示通用热门池子（如"沪深300成分股"）
  - 非交易日显示上一交易日数据，并标注"非交易日数据"

**验收标准**：
1. 登录系统 → 首页顶部看到"今日推荐股票池"模块
2. 模块内显示3-5个池子，每个包含：名称、标签、涨跌幅、推荐理由
3. 点击任一池子 → 跳转到该池子详情页
4. 新用户登录 → 显示"沪深300成分股"、"创业板指成分股"等通用池子
5. 非交易日访问 → 数据标注"2026-01-03（上一交易日）"

### FR-2：基于持仓的关联推荐

**功能描述**：投资者查看某只持仓股票详情时，系统在侧边栏显示"相关股票池"推荐，包括同行业池子、上下游产业链池子、同风格池子（如同为高ROE成长股）。

**详细说明**：
- **使用场景**：投资者持有"宁德时代"，想了解同产业链或同风格的其他标的
- **操作流程**：
  1. 投资者点击持仓列表中的"宁德时代"
  2. 进入股票详情页，右侧栏显示"相关股票池"（3-4个）
  3. 推荐逻辑：
     - 同行业："锂电池中游制造"
     - 上下游产业链："锂资源上游"、"新能源汽车下游"
     - 同风格："高ROE成长股"
  4. 点击任一池子，进入池子详情页
- **预期结果**：
  - 投资者快速发现同类型或相关联的投资机会
  - 理解产业链上下游关系
  - 避免重复持仓（如发现已持有的其他股票也在推荐池中）
- **边界条件**：
  - 如果该股票不属于任何池子，显示"暂无相关推荐"
  - 如果投资者已持有推荐池中的其他股票，标注"已持仓：比亚迪"

**验收标准**：
1. 持仓列表点击"宁德时代" → 详情页右侧显示"相关股票池"模块
2. 推荐池包含："锂电池中游"、"锂资源上游"、"高ROE成长股"
3. 点击"锂电池中游" → 跳转到该池子详情页
4. 查看"平安银行"详情 → 推荐池包含"银行股"、"低估值蓝筹"
5. 查看不属于任何池子的股票 → 显示"暂无相关推荐"
6. 推荐池中如有已持仓股票 → 标注"已持仓：比亚迪（持仓市值：5万元）"

### FR-3：基于浏览历史的个性化推荐

**功能描述**：系统记录投资者最近7天浏览的股票池和个股，在首页推荐时优先推荐其关注的行业/风格相关的池子。

**详细说明**：
- **使用场景**：投资者最近一周频繁查看"光伏产业链上游"和"锂电池中游"两个池子，系统判断其关注新能源行业
- **操作流程**：
  1. 系统后台记录用户浏览行为：
     - 查看过的池子（池ID、时间、停留时长）
     - 查看过的个股（股票代码、所属行业、时间）
  2. 每日凌晨2:00计算推荐权重：
     - 最近7天内浏览次数 > 3次的池子，权重+10
     - 最近7天内浏览过的个股所属行业，相关池子权重+5
     - 市场热点行业（当日涨幅前3），相关池子权重+3
  3. 首页推荐展示权重Top 5的池子
- **预期结果**：
  - 投资者看到的推荐池更符合其投资偏好
  - 系统"越用越懂你"，推荐质量持续提升
- **边界条件**：
  - 新用户（无浏览记录）不启用个性化推荐，显示通用热门池
  - 用户清除浏览记录后，回退到通用推荐

**验收标准**：
1. 用户A最近7天浏览"光伏产业链"3次 → 首页推荐中包含"光伏产业链上游"
2. 用户B最近7天查看过"宁德时代"、"比亚迪" → 推荐中包含"新能源汽车产业链"
3. 新用户登录 → 推荐显示"沪深300"、"创业板指"等通用池
4. 用户在设置中点击"清除浏览记录" → 首页推荐变为通用池子
5. 当日市场热点为"银行股"（板块涨幅第1） → 即使用户未浏览过，推荐中也包含"银行股"

### FR-4：推荐理由透明化

**功能描述**：每个推荐的股票池都显示推荐理由（1-2句话），说明为什么推荐这个池子，例如"您近期关注新能源行业，该池子涨幅领先"、"该池子与您的持仓风格相似"。

**详细说明**：
- **使用场景**：投资者看到推荐结果，但不理解为什么推荐这些池子
- **操作流程**：
  1. 系统在生成推荐时，记录推荐依据（用户偏好/市场热点/持仓关联）
  2. 前端展示推荐理由（每个池子下方显示灰色小字）
  3. 推荐理由类型：
     - 用户偏好："您近期浏览过该行业相关内容"
     - 市场热点："该板块今日涨幅居前，市场关注度高"
     - 持仓关联："与您的持仓'宁德时代'同属产业链"
     - 风格匹配："该池子风格与您的历史选股偏好一致"
- **预期结果**：
  - 投资者理解推荐逻辑，提升对系统的信任
  - 投资者根据理由判断是否需要关注该池子
- **边界条件**：
  - 如果同时有多个推荐依据，优先显示最强依据（权重最高的）
  - 理由文案不超过20字，避免信息过载

**验收标准**：
1. 首页推荐"光伏产业链" → 理由显示"您近期浏览过该行业相关内容"
2. 推荐"银行股" → 理由显示"该板块今日涨幅居前，市场关注度高"
3. 持仓"宁德时代"，推荐"锂资源上游" → 理由显示"与您的持仓'宁德时代'同属产业链"
4. 推荐理由文案长度 < 20字
5. 如果池子因多个原因被推荐（如既是用户偏好又是市场热点） → 显示权重最高的一个理由

### FR-5：推荐结果可反馈

**功能描述**：投资者可以对推荐结果进行反馈（"有帮助"/"无帮助"），系统根据反馈调整后续推荐策略。

**详细说明**：
- **使用场景**：投资者看到推荐的"光伏产业链"，但实际上不感兴趣（可能是误触浏览）
- **操作流程**：
  1. 每个推荐池卡片右上角显示反馈按钮（👍 / 👎）
  2. 投资者点击👎后，弹出确认框："不再推荐该类型池子？"
  3. 确认后，系统记录负反馈：
     - 该池子权重-5
     - 该池子所属行业权重-3
  4. 下次推荐时，该池子及同类池子排序下降
- **预期结果**：
  - 投资者可以纠正系统的错误推荐
  - 推荐质量逐步优化
- **边界条件**：
  - 负反馈仅影响个性化推荐，不影响市场热点推荐
  - 用户可在设置中查看和撤销历史反馈

**验收标准**：
1. 首页推荐卡片右上角有👍 / 👎按钮
2. 点击👎 → 弹出确认框"不再推荐该类型池子？"
3. 确认后 → 该池子在后续推荐中排序下降或消失
4. 给"光伏产业链"点👎 → "光伏产业链上游"、"光伏产业链中游"等同类池子权重也下降
5. 设置页面显示"反馈历史" → 可查看和撤销历史反馈
6. 撤销负反馈后 → 该池子权重恢复

## 边界（不做什么） <!-- serves: FR-1 -->

- **不做实时推荐更新**：推荐结果每日凌晨2:00计算一次，盘中不会动态调整。理由：避免频繁计算消耗资源，且日内推荐变化会干扰用户决策。后续版本（P2）可考虑盘中重大事件触发的实时推荐。

- **不做个股推荐**：本期只推荐股票池，不推荐具体个股。理由：个股推荐涉及投资建议合规风险，需法务审核；股票池推荐属于信息聚合，风险较低。

- **不做推荐算法可视化**：不展示推荐算法的详细权重计算过程（如"用户偏好占40%，市场热点占30%"）。理由：对普通投资者而言，过于技术化的信息反而造成困扰；推荐理由已能满足基本理解需求。

- **不做跨账户推荐**：不推荐"其他用户也在关注的池子"。理由：避免羊群效应，保持推荐的独立性；且涉及用户隐私问题。

## 非功能需求 <!-- serves: FR-1 -->

- **性能**：
  - 首页推荐模块加载时间 < 500ms（前端 Performance API 测量）
  - 推荐计算任务（凌晨2:00）单用户耗时 < 100ms（后台日志监控）

- **准确性**：
  - 个性化推荐相关性 > 60%（用户满意度调研：推荐池中至少60%符合用户兴趣）
  - 推荐理由与实际依据一致性 100%（代码审查+单元测试保证）

- **容错性**：
  - 推荐算法失败时，回退到通用热门池推荐（不显示空白）
  - 用户浏览记录丢失时，不影响其他功能使用

- **兼容性**：
  - 支持已有用户（无浏览记录）平滑迁移到推荐系统（首次访问显示通用推荐）
  - 移动端和PC端推荐结果一致（同一账号跨设备同步）

## 验收标准（整体） <!-- serves: FR-1 -->

**端到端用户旅程**：

1. **新用户首次访问**
   - 打开系统首页 → 看到"今日推荐股票池"模块
   - 显示3个通用池子："沪深300成分股"、"创业板指成分股"、"高ROE成长股"
   - 每个池子显示涨跌幅、推荐理由（"热门池子，适合新手"）

2. **浏览行为积累**
   - 用户连续3天查看"光伏产业链"、"锂电池中游"
   - 查看个股"宁德时代"、"隆基绿能"

3. **个性化推荐生效**
   - 第4天早盘打开系统 → 首页推荐变为：
     - "光伏产业链上游"（理由：您近期浏览过该行业）
     - "锂电池中游"（理由：您近期浏览过该行业）
     - "新能源汽车产业链"（理由：与您的关注点相关）
     - "高ROE成长股"（理由：该风格与您的选股偏好一致）

4. **持仓关联推荐**
   - 用户买入"宁德时代" → 持仓列表显示该股票
   - 点击"宁德时代"详情 → 右侧显示"相关股票池"：
     - "锂电池中游"（同行业）
     - "锂资源上游"（上游产业链）
     - "新能源汽车下游"（下游产业链）
     - "高ROE成长股"（同风格）

5. **反馈调整**
   - 用户点击"新能源汽车产业链"的👎按钮
   - 确认后，后续推荐中该池子消失
   - 同类池子（如"新能源汽车整车"）权重也下降

6. **验收通过标准**
   - 全流程无报错、无空白页
   - 推荐结果符合用户行为（浏览新能源 → 推荐新能源池）
   - 推荐理由与实际依据一致（理由说"浏览过"，确实有浏览记录）
   - 反馈功能生效（点👎后，后续不再推荐）

## 依赖与约束 <!-- serves: FR-1 -->

**依赖**：
- **强依赖**：股票池管理系统已有池子数据接口（GET /api/pools）
- **强依赖**：用户浏览记录埋点已部署（前端 track.js 记录页面访问）
- **弱依赖**：市场行情数据接口（GET /api/quotes），如不可用则不显示涨跌幅

**约束**：
- 推荐算法必须基于已有数据（浏览记录、持仓数据），不引入外部数据源
