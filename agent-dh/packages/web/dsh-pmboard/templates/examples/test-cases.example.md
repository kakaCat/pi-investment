## 用例明细 <!-- serves: FR-3 -->

### TC-2 幂等不覆盖

- **测试数据**：目标文件 requirement.md 预写内容 "# 我手写的需求\n（共 42 行，含 FR-9 自定义节）"；构造 3 次连续节点转移事件
- **步骤**：1. 预写目标文件并记录 sha256 → 2. 触发转移钩子 ×3 → 3. 重算 sha256 → 4. 比对 artifacts 登记表
- **断言点**：
  1. 三次触发后文件 sha256 与预写时**逐字节一致**（不是"内容差不多"，是哈希相等）
  2. artifacts 表中 (req_id, path) 登记行数 = 1（唯一约束兜底，重复登记被拦）
  3. 日志含 3 条 "skip: exists"（每次跳过都留痕）
- **清理**：删除测试需求目录；artifacts 测试行走仓储 delete（测试库专用）

### TC-3 校验前移拦截

- **测试数据**：合规骨架逐节删法 ×3——①删「边界（不做什么）」整节；②把节名改成「边界与范围」；③节名后加全角括号注「（不做什么，含补充）」
- **步骤**：各变体分别 submit kind=requirement
- **断言点**：
  1. 变体①被拒，缺节清单含且仅含「边界（不做什么）」
  2. 变体②被拒（改名即不合规，hasRootSection 精确匹配）
  3. 变体③**通过**（括号注是合法形态——防止校验器比门禁更严）
- **清理**：无（纯校验路径，无落盘副作用）
