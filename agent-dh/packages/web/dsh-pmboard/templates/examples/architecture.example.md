# 架构设计（REQ-example）

## 整体架构 <!-- serves: FR-2 -->

```
┌─────────────────────────────────────────────────┐
│                  浏览器端                        │
│  ┌──────────┐    ┌──────────┐   ┌──────────┐  │
│  │ 需求列表 │───→│ 需求详情 │──→│ 文档预览 │  │
│  └──────────┘    └──────────┘   └──────────┘  │
└─────────────────────────────────────────────────┘
           │ HTTPS                │ WebSocket
           ↓                      ↓
┌─────────────────────────────────────────────────┐
│               Agent OS（端口 13080）             │
│  ┌──────────┐    ┌──────────┐   ┌──────────┐  │
│  │ API 网关 │───→│ Reqboard │──→│ Template │  │
│  │  (路由)  │    │  (需求)  │   │  (模板)  │  │
│  └──────────┘    └──────────┘   └──────────┘  │
│         │              │              │         │
│         └──────────────┼──────────────┘         │
│                        ↓                        │
│                  ┌──────────┐                   │
│                  │ Artifacts│ ← 产物登记表      │
│                  └──────────┘                   │
└─────────────────────────────────────────────────┘
           │ 文件系统                │ SQLite
           ↓                        ↓
    ┌──────────┐              ┌──────────┐
    │ 工作区   │              │ 数据库   │
    │ docs/    │              │ reqboard │
    └──────────┘              └──────────┘

数据流：
1. 用户新建需求 → Reqboard 创建 → 触发钩子
2. Template 模块选模板 → 写入 docs/ → 登记 artifacts
3. WebSocket 推送 "文档已生成"
```

## 技术选型 <!-- serves: FR-2 -->

### 模板存储方案：模板清单自动生成为 TypeScript 常量

**理由**：
- 模板总大小 < 100KB，内联后 bundle 增加可接受
- 浏览器端可直接读取（支持预览），不依赖文件系统
- 构建期生成，零运行时开销

**替代方案对比**：

| 方案 | 优点 | 缺点 | 为什么不选 |
|---|---|---|---|
| 文件系统读取 | 模板可热更新 | 浏览器无法访问 fs | 需求要求浏览器预览 |
| 数据库存储 | 动态增删模板 | 增加 DB 负担 | 模板是静态内容 |
| CDN 托管 | 分发快 | 依赖外部服务 | 本地部署不需要 CDN |

## 模块职责 <!-- serves: FR-3 -->

### Template 模块

**职责**：
- 根据阶段+类型选择模板 → 检查文件是否存在（幂等）→ 写入文件 → 登记产物
- 不关心需求何时创建（由钩子触发）
- 不负责内容校验（委托给 Validation 模块）

**对外接口**：
- `landTemplate(reqId, stage, category, targetPath)`：落盘模板
- `getTemplate(key)`：读取模板内容

**依赖关系**：
- 强依赖 fs 模块（写入失败时降级）
- 强依赖 Artifacts 表（登记失败时告警但不阻塞）
- 弱依赖 Reqboard（只接收钩子）

**状态管理**：无状态（每次调用独立）
