# 需求说明（REQ-260923000001-abcd）

## 产品定义 <!-- serves: FR-1 -->

需求文档模板系统：PM 和开发在创建需求时，系统根据需求类型（feature/bug/refactor/spike/doc/chore）自动生成对应的文档骨架，包含必填章节、填写提示和示例，让团队成员只需"填空"而非"从零写起"。

**核心价值**：从"记不住要写什么"到"照着模板填"，从"每个人格式不一样"到"质量一致性"，从"反复被门禁拦截"到"写完就能过"。

**与现状的区别**：现状是手动创建空白文件凭记忆填写，经常漏章节导致门禁拦截；新方案是自动生成带章节骨架和填写指引的文档。

## 目标用户与使用场景 <!-- serves: FR-1 -->

### 场景 1：PM 新建 Feature 需求
- 角色：产品经理
- 场景：周一早会后，PM 需要为新功能立项，打开系统新建 Feature 需求
- 系统自动生成包含必填章节的文档
- PM 按章节填写内容，不用担心遗漏

### 场景 2：开发创建 Bug 需求
- 角色：后端开发
- 场景：用户反馈登录接口 500 错误，开发新建 Bug 需求
- 系统生成包含"复现步骤/根因/回归"的模板
- 开发照着提示填写

## 功能点（需求条款） <!-- serves: FR-1 -->

| 编号 | 功能 | 验收标准 |
|---|---|---|
| FR-1 | 新建需求自动生成文档模板 | 新建 feature 需求后，requirement.md 文件存在且包含必填章节 |
| FR-2 | 模板内容与门禁规则同源 | 按模板填写的文档提交确认后门禁通过 |
| FR-3 | 模板提供填写示例 | 打开文档后看到章节下有示例 |
| FR-4 | 支持 6 种需求类型 | 每种类型生成对应专属模板 |
| FR-5 | 模板自动替换变量 | 文档标题显示实际 REQ_ID |

## 边界（不做什么） <!-- serves: FR-1 -->

- 不做用户自定义模板格式（下版本再做）
- 不做模板内容的 AI 生成（内容由人工填写）
- 不做历史需求的模板补全（只对新需求生效）

## 非功能需求 <!-- serves: FR-1 -->

- 性能：模板加载时间小于 100ms
- 兼容：已有需求不受影响，新规则不拦截旧文档

## 验收标准（整体） <!-- serves: FR-1 -->

端到端场景：PM 新建 Feature 需求 → 系统生成文档 → PM 填写 → 提交确认 → 门禁通过 → 推进到 design 阶段

预期结果：文档包含所有必填章节，门禁一次通过，推进成功

- 依赖门禁系统（需保持同步）
- 上线时间：2026-09-30
