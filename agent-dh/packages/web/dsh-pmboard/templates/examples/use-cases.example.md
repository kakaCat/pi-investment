## 场景详细描述 <!-- serves: FR-1 -->

### UC-1 PM 新建需求时自动获得文档模板

**角色**：PM（产品经理）

**前置条件**：
- 用户已登录系统
- 用户有创建需求的权限
- 项目看板已初始化

**主流程**（正常路径）：

1. PM 在项目看板点击左上角"新建需求"按钮 → 系统弹出需求创建表单
2. PM 填写需求基本信息：标题"优化搜索性能"、类型 feature、点击"创建"
3. 系统创建需求 REQ-001，自动进入 brainstorming 阶段 → 页面跳转到需求详情页
4. PM 点击右侧"文档"标签页 → 看到 requirement.md 已自动生成（绿色"已生成"标签）
5. PM 点击 requirement.md → 编辑器打开文件，看到章节骨架：
   - # 需求说明（REQ-001）
   - ## 目标用户与使用场景（三问：谁用 / 什么场景用 / 解决什么痛点）
   - ## 功能点
   - ## 边界（不做什么）
   - ...（其他章节）
6. PM 在骨架上直接填写内容，保存后点击"提交"
7. 系统校验通过（必填章节齐全），需求进入 design 阶段

**预期结果**：
- PM 无需手动创建 md 文件
- 无需记忆必填章节有哪些
- 打开文档就能看到结构和填写提示
- 节省 5 分钟准备时间

**异常分支**：

- **分支 A：权限不足**
  - 触发：用户无创建需求权限
  - 行为："新建需求"按钮置灰且 hover 提示"无权限"
  
- **分支 B：模板生成失败**
  - 触发：模板文件缺失 / 磁盘写满
  - 行为：文档清单显示 requirement.md "生成失败"，点击"重试"
  - 保底：用户可手动创建空白 md 文件（不阻塞后续工作）

**时长估计**：2 分钟（从点击创建到打开文档）

**依赖场景**：无（独立场景）
