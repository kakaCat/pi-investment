## UC-1 缺节被打回 <!-- serves: FR-5 -->

- **用例角色**：窗口 agent
- **前置条件**：feature 需求，requirement.md 已写但缺「边界（不做什么）」节
- **交互流程**：1. submit kind=requirement → 2. 前移校验跑必填节 → 3. 返回缺节清单
  → 4. agent 补节 → 5. 重交 → 6. 通过并登记产物
- **异常流**：步骤 3 清单为空但后端仍拒 → 校验器与门禁规则漂移，记 bug（check 门禁防线）
- **后置条件**：产物登记成功，需求可进设计确认
- **完成标志**：submit 返回 success 且 artifact 落台账

## UC-2 模板缺失降级 <!-- serves: FR-3 -->

- **用例角色**：窗口 agent（无感知）、人类用户（看告警）
- **前置条件**：某节点+类型组合无对应模板文件（如新增类型忘了建模板）
- **交互流程**：1. 节点转移成功 → 2. 钩子 getTemplate 得 null → 3. 跳过落盘
  → 4. 告警日志 + notes 产物登记
- **异常流**：无——本场景本身就是异常路径
- **后置条件**：转移成功（骨架是增益不是前置）；告警可查
- **完成标志**：告警日志出现且需求状态正常转移
