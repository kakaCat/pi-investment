# 类型档 · feature（需求分析）

- [ ] 先定**接口**：对外入口的输入 / 输出 / 错误语义写清（谁调用、给什么、回什么）。
- [ ] 定**数据契约**：新增或变更的字段、类型、必填性、默认值、版本兼容。
- [ ] 写清迁移与兼容路径：旧数据 / 旧调用方怎么办，能否回滚。
- [ ] 验收要能跑：给出可执行的判定命令或请求样例。
